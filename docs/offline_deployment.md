# Windows 离线交付准备

当前 0.1 是开发原型，正式离线验收尚未完成。

计划交付 PyInstaller 完整目录包，安装目录与项目目录分离，普通运行无需管理员。复制完整目录，勿单独移动 EXE。公司正式项目目录由公司本地配置，不使用云同步目录。

正式放行前必须执行：

1. 在 Windows 10/11 目标版本、中文用户名和空格路径下运行。
2. 使用无 Python 的干净测试机，断网完成全部模拟流程。
3. 在联网测试机由 IT 对实际主程序与计算子进程路径配置出站阻断，监测无未解释的联网行为。
4. 在另一台离线机器打开一致性备份并核对业务记录。
5. 验证取消、崩溃、升级、回退与全部适用 A01–A50。
6. 补齐依赖许可证、资源、Windows 完整依赖锁及最终校验值。

本应用代码不包含外部 API、遥测、下载模型或自动更新。BoTorch 可选编译路径已禁用，但整体发布包离线性质仍必须实测，不能仅据代码审查判断通过。

备份恢复使用「打开项目」选择备份 SQLite。未知数据库结构版本会拒绝打开，不会创建空项目替代旧文件。当前尚无升级迁移实现，不能宣称完成 A24。
