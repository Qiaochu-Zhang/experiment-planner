### 2. ICP 模板、字段、公式和精度

- 从规格提取原始 ICP 模板，保留规定的 8 个可控输入、4 项厚度测量和 3 个目标。
- 实现数值、整数、类别、固定值、布尔值等字段的基础校验；备注和缺失值独立保存。
- 实现公式白名单解析、依赖排序、循环依赖检查和基础单位校验，不执行模板中的任意 Python 代码。
- 按“初始厚度减剩余厚度”计算有符号 A、B，保留负值。
- 实现原始比值及三种分母处理策略：有效区域、稳定化、明确移除比值目标。
- 未设置分母策略时允许记录数据，但阻止包含比值目标的推荐。
- 实现十进制半数远离零取整、执行网格和显示精度处理；显示舍入不修改原值。
- 实现事后未知测量不能作为未来模型输入的检查。

**边界：** 完整模板表单、结构迁移、建模取整变换和全部角色组合尚未完成。

### 3. 测量不确定度

- 建立标准不确定度、SEM、区间、误差界限、非对称误差和未指定含义的数据结构。
- 实现差值标准不确定度、协方差及误差界限的计算。
- 实现共享来源的联合抽样，并在公式依赖链中复用同一原始样本。
- 未填误差保持未知，不自动当作零。
- 分母为零或其测量区间跨零时保留有效 A、B，并标记比值不稳定。
- 原始比值预测只报告样本分位数，不伪称其均值或方差一定存在。

**边界：** 一般公式的完整区间传播、非对称分布处理，以及相关误差进入全部模型的适配仍待补齐。能够记录某种误差，不等于所有模型都已使用该误差。

### 4. 模型与推荐

- 实现并实际拟合 GP-RBF、GP-Matérn 2.5 和真正的非 GP 贝叶斯线性模型。
- 实现 Bernoulli-logit 布尔概率模型，使用 Laplace 近似得到系数后验；输出合法概率及不确定性。
- 数值模型保留同一响应在候选点之间的联合不确定性，默认不同基础响应条件独立。
- 从共同的基础响应样本推导非线性目标，避免以均值之比代替比值分布。
- 接入 qLogNEHVI 多目标采集函数及 qLogNEI 单目标、加权推荐。
- 实现全范围、基于基准的单变量、双变量和交叉对照候选构造。
- 复测和新对照均计入本轮总数 n；候选不足时返回实际数量和原因，不放宽限制。
- 最终执行值经过合法性检查、去重和评分；已有待做条件参与下一轮推荐处理。
- 实现按响应排除无关输入，以及部分全域线性、正比和贝叶斯线性软单调先验。
- 不支持的配置组合明确拒绝，避免静默忽略先验或误差设置。

**框架边界：** 当前 Ax 管理实验、基础响应记录和业务编号映射；应用桥接层直接调用 BoTorch。完整 Ax Modular 自定义模型与推荐适配仍需补齐。

**模型边界：** GP 导数单调先验、局部范围先验、混合已知/未知观测噪声、输入位置误差、部分相关噪声及目标组合尚未全部适配。详见 [模型能力矩阵](model_capabilities.md)。

### 5. 数据保存、导入导出和恢复

- 每个项目使用独立 SQLite 数据库，并保存模板完整快照。
- 保存建议条件与实际条件；模型学习实际执行条件。
- 保存原始测量、派生值、状态、备注、修订历史和批次预测。
- 数据或配置修改后递增版本，阻止旧计算结果覆盖新版本。
- 实现 CSV/XLSX 导入预览、基础字段匹配、非法行检查和重复导入识别。
- 实现 CSV/XLSX/JSON 导出；Excel 文字备注按文字保存。
- 使用 SQLite 一致性备份接口；重启和备份恢复保留原记录与待做批次。
- 未知数据库结构版本明确报错，不将读取失败伪装成空项目。

**边界：** 完整列映射界面、全部单元元数据往返、旧版本数据库迁移和升级回退尚未完成。

### 6. 中文界面、后台计算与图形

- 建立最小中文桌面原型，支持新建、打开、关闭项目，录入、更正、回填、导入预览、导出和备份。
- 提供分母策略保存、模型选择、本轮总数、基准、变化模式和复测设置。
- 计算使用本地 spawn 子进程；取消任务不写入半批结果。

- 完成中文界面截图检查，见 [原型截图](images/prototype.png)。
