# 实验规划助手 0.1 开发原型使用说明

本版是 V1.1 需求的开发原型，用于合成案例与接口验证。尚未完成正式 Windows 离线交付验收，不可视为已通过全部 A01–A50。

## 打开与保存

安装开发环境后执行 `experiment-planner` 打开中文桌面原型。正式发布计划为双击 Windows EXE；当前 Windows 构建脚本仍需运行验证。

1. 点击「新建项目」，选择新的 `.sqlite` 文件路径。项目保存内置 ICP 模板完整快照。
2. 「录入实验」输入 8 项条件与 4 项厚度。测量留空表示未测；False 和数值零都不是缺失。
3. 每项测量可填写 ± 值、含义和备注。原型表单支持标准不确定度、SEM、确定误差界限、未指定；完整区间/非对称配置目前使用业务接口。
4. 点击「下一批实验」，先明确保存分母策略。epsilon 的单位为 nm，由实验用途决定，没有默认机台值。
5. 选择模型、总数 n、基准和变化模式；点击「计算并保存下一批实验」。计算在本机子进程进行，可以取消。
6. 推荐成功后记录为待做。选中记录，点击「更正选中实验 / 回填」，填写实际条件与测量。原建议及当时预测继续保存。
7. 「打开项目」恢复原记录与待做批次；打开时不会重新推荐。

## 计算口径

A = SiO2 初始厚度 − 剩余厚度；B = SiN 初始厚度 − 剩余厚度。保留负值。
默认目标为最大化 abs(A)、最小化 abs(B)、最大化 abs(A/B)，使用 Pareto 折中。

- 未设置分母策略时允许记录，但不能生成包含比值的推荐。
- 有效区域：abs(B) < epsilon 的样本在采集函数中视为不可行。
- 稳定化：使用 abs(A)/max(abs(B), epsilon)，另存原始比值；两者不是同一指标。
- 移除：明确停用比值目标，原始比值仍记录。
- 原始比值预测仅给样本分位数，不声明均值/方差存在。模型区间表示潜在响应，未包含未知的未来量测误差。

两个 GP 预设与非 GP 贝叶斯线性模型均本地拟合。默认跨响应独立，但保留同一响应在多个候选间的相关性。数据不足时标记初始化，预测为空。

单变量模式每点恰好改变一个原始参数；双变量默认最多改变两个。复测编号用逗号分隔，每个新安排都占 n。指定变化字段时必须选择基准。最终候选遵守执行精度、范围、线性约束和历史去重；有限候选池不足时返回原因，不放宽条件。

## 导入、导出与备份

CSV 使用 UTF-8，Excel 使用 XLSX。表头可使用模板内部名称或中文显示名称。
测量附加列支持 `_不确定度`、`_误差类型`、`_备注`、`_单位`、`_分布`、`_覆盖因子`、`_置信水平`。
误差类型内部代码为 std、sem、bounds、interval、asymmetric、unspecified。

导入先显示预览，只有点击保存才提交。非法行或单位不匹配使整个提交被拒绝。提供 `external_id` 或 `experiment_id` 可识别同一实验；复测必须有不同编号。同一外部编号内容冲突需要使用更正功能。没有编号时按完整行内容去重。

CSV/XLSX 导出使用原始完整精度，显示舍入不会改变原值。需要完整记录及模型预测时可导出 JSON；跨机器继续项目优先使用「一致性备份」创建新的 SQLite 文件，然后在另一台机器打开备份。

## 当前能力边界

详见 [验收结果](acceptance_results.md) 与 [模型能力矩阵](model_capabilities.md)。目前仅提供最小桌面原型，尚缺完整模板编辑、先验表单、映射表单和交互趋势页面。
GP 单调导数先验、局部范围先验、额外模型输入、混合已知/未知噪声、跨实验相关噪声、建模取整等组合会明确拒绝。贝叶斯线性模型支持全域软单调系数信息，不保证严格全域关系。

## 合成数据练习

开发环境可执行 `experiment-planner --demo /tmp/planner-demo.sqlite` 生成新的合成项目。它使用已说明的模拟公式与标准不确定度，不代表机台规律；仍需显式选择分母策略。

仅允许合成数据进入当前云端开发环境。真实实验数据在公司本机运行正式验收后的版本。
