## 安装与启动

在本目录创建独立环境，不与父目录旧工程共用可编辑安装：

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

Python 3.12 可替换首行版本号。Linux 使用 `python3.13 -m venv .venv` 和 `.venv/bin/python`。PyCharm 打开本目录，选择此解释器，以普通 Python Run 配置运行 `main.py`，不要在 Python Console 中运行整个程序。

## 模板与项目

“新建 / 复制 / 修改模板”可选择从空白开始、复制当前项目、打开本地模板文件或复制内置示例。空白草稿没有默认工艺字段。

“参数 / 测量 / 公式（增删改名）”提供字段表单：可定义名称、类型、单位、范围/离散值/固定值、备注及公式。内部名称改动同步更新已知引用；删除会提示连带移除的公式、目标、先验及约束。“全部属性”可编辑其他属性与扩展配置。精度、先验和目标仍有专用表单。

单位框可输入自定义名称。字段表支持 Shift 连选、Ctrl 多选、Ctrl+C 复制、Ctrl+V 粘贴和批量删除；跨输入/测量/公式区域粘贴保留共用属性，范围、公式等专属内容留空待填写，重名自动加后缀。文字输入可自由填写或指定固定/离散文字，保存为实验条件，不进入数值模型；自由文字用于推荐时需选择基准实验。

模板编辑器可直接导入/导出 Excel 模板定义，也可打开和保存 JSON。Excel 使用中文工作表填写字段、目标、先验、约束及模板设置；第 1 行提示必填条件与数值范围，第 2 行列名，第 3 行起填写，固定选项提供单元格下拉。内附填写说明，可先导入未完成草稿，再补齐和校验。示例见 [Excel 模板定义](examples/template_definitions/README.md)；更换实验时的模板设置解释见 [回答.md](回答.md) 第 28–30 节。

Excel 的布尔类型统一显示“是否”，取值下拉只显示“是 / 否”；旧文件的 bool、true/false 仍可导入。输入范围包含上下限，例如 0–10 可填写 0 和 10；上下限须不同，只允许一个值时设置固定值。可控输入、文字条件及模型输入的区别见 [回答.md](回答.md) 第 32–35 节。

至少配置一个输入、一个直接建模的响应以及有效目标后保存模板，再通过“从模板新建项目”使用它。可选单目标、多目标折中或加权目标；实验目标以当前模板为准。

空项目可直接更换结构。已有实验且结构不兼容时，编辑成果可以直接另存为模板，或用它新建项目；无需从头改一遍。兼容配置可在原项目保存并更新版本。原有实验不会被套用新的字段含义，新增参数也不会自动补造数据。

## 导入与日常操作

**条件重要度、实验批次与可信度**：在“实验记录”多选后点击“设置所选实验批次 / 日期”，填写批次名称、相对可信度及可选的实际实验日期。“批次可信度 / 近期权重”可集中调整各批次权重，并设置近期权重半衰期（天）：0 默认关闭，30 表示比最新有效实验早 30 天的记录时间权重为 0.5。批次未设置时可信度为 1；同名批次共用设置，新推荐自动归入“推荐批次 N”。设置用于后续预测、趋势图、推荐及重要度分析，支持撤销并需 Ctrl+S 保存。可信度是相对训练权重，不是准确率百分比。

进入“预测 / 趋势图 → 实验条件重要度”，按“下一批实验”选择的模型及种子分析已有实测数据，显示各参数的综合分数与逐响应分数，可导出 Excel/CSV。分数采用历史范围内的模型置换敏感度，相对合计 100；数据未变化、未进入模型或约束不允许单独变化的条件显示无法估计。它不代表因果效应或独立验证准确度。

**Excel / CSV 批量修改**：在“实验记录”导出文件，修改条件、原始测量、误差、备注、状态、`experiment_batch` 或 `performed_at`，再点击“导入 Excel / CSV 批量修改”。普通导入入口遇到新版导出文件也会预选批量修改模式；核对逐项变化后保存。身份与版本列须保留，已有测量留空表示清除，派生结果自动重算；无变化行跳过，不新增实验。可只保留待修改的行，整批可撤销。过期文件、其他项目和编号复用会被拒绝，需重新导出。旧版无身份列文件仍可新增导入，批量更正请先重新导出。

待做 / 进行中及部分结果中的未测响应现显示为“未测（预测均值 …）”，没有适用均值时显示预测中位数；读取推荐时保存的快照，不重新拟合、不写成实测值。修改条件后提示原预测不适用；初始化或没有该响应预测时保持“未测”。日期、权重含义和完整操作见 [回答第 67 节](回答.md)。

**上次预测与回填评分**：推荐实验自动保存预测；手动记录可在“实验记录”选择一条或多条，点击“预测并记录上次预测（所选 / 全部）”，未选择时处理全部记录，使用“下一批实验”当前模型和种子。批量实验点预测计算后也可点击“记录到原实验（用于回填评分）”。记录预测后按 Ctrl+S 保存；更正/回填或 Excel 批量修改测量时，自动对照原预测计算分数，不重新拟合或覆盖原预测。重新点击记录预测会主动替换评分依据，旧版本留在审计并可撤销。

“查看上次预测 / 回填评分”展示预测中心、95% 上下限、测量对照值、绝对误差、是否覆盖、区间宽度及 IS95，按指标/模型汇总 MAE、RMSE、覆盖率与平均 IS95，可导出 Excel/CSV。按你的要求将测量结果当作真实结果；`IS95=(U−L)+40×max(L−y,0)+40×max(y−U,0)`，越小越好，不是百分制。说明和 Excel 的“评分公式”页列出全部公式；是否响应另用 Brier 概率得分。条件或公式变化、未测或预测不可用时明确说明，不记作零分；预测时已有结果的记录单独标注。完整操作和口径见 [使用说明：上次预测与回填评分](src/experiment_planner/resources/help/使用说明.md#上次预测与回填评分)及 [回答第 70 节](回答.md)。

常用页默认有“导入 CSV / Excel”。核对列映射后，程序按**模板输入参数顺序**检查前 30%（向上取整，至少一项）：这些值全部为空时，该行为结束标记，该行及后续行不导入。例如 8 个输入检查前 3 个，11 个输入检查前 4 个。

0 和“否”不是空值。结束前的其他错误仍需修复。预览明确显示停止行、检查字段和待导入数量，确认后点击保存。文件表头缺少用于判断的输入列时会提示映射问题。内置示例文件位于 [导入示例](examples/import_templates/README.md)；自建模板可在“项目与模板 → 下载导入 CSV / Excel 模板”生成自己的空白输入表。Excel 第 1 行提示必填输入、单位和实际范围，第 2 行列名，第 3 行起填写；固定/离散/是否及状态/误差等列带下拉。仍支持旧版第 1 行列名的 Excel，CSV 格式不变。

允许同条件不同结果独立保存。实验表可单击、Ctrl 多选、Shift 连选或拖选，确认后删除所选实验。删除记录不参与当前训练、推荐和普通导出，原数据保留在审计中；旧批次保留，常见已保存修改可用 Ctrl+Z 撤销、Ctrl+Y 重做，删除后的空缺编号可复用。完整 SQLite 备份保留全部审计。

实验记录页的“统一设置误差”支持统一数值，也支持“基准误差 + 高可信实验”：一次为其他实验补齐基准 1σ、为勾选的高可信实验计算较小 1σ。可按响应或单位快速选择测量字段、读取已有共同 1σ、预览逐项变化并统一填写设置依据；组合模式自动将假设附加到测量备注，保留更小的高可信误差，其他实验默认仅补未知。跳过未测值、重算派生误差、整批撤销及 Ctrl+S 保存均保留。该功能修改当前记录，以后新增/导入的记录需另行设置。混合已知/未知误差的诊断会列出两类实验编号。详见 [回答.md](回答.md) 第 55–56 节。

该弹窗现增加“误差含义”选项：默认标准不确定度 1σ，也可选“误差界限 ±a（区间内均匀分布假设）”。例如 ±2 nm 填 2，按界限类型保存，模型用 `a/√3` 换算标准不确定度；GP 不将该界限作为预测硬约束。统一数值及高可信组合模式均支持，预览显示界限和换算值，高可信比较按同一标准尺度进行。详见 [回答.md](回答.md) 第 62 节。

“项目与模板 → 输入不确定度”（也可从编辑模板进入）可选择性考虑未来执行的输入波动，**总开关默认关闭**。开启后逐项勾选连续数值输入，以原单位填写正态标准差 1σ 或均匀最大偏差的半宽，未勾选项按确定输入近似。保存模板后按 Ctrl+S 保存项目；设置也随 JSON/Excel 模板保存。预测展示输入确定与含波动的两组结果，趋势图和推荐同步考虑波动。当前假设执行被限制在模板范围及线性约束内，历史输入仍按实际记录值训练，数值不自动优化。操作、边界及示例见 [回答.md](回答.md) 第 61 节。

推荐时设置总数、探索强度、专门探索名额及复测。总数包含复测；专门探索占用新条件位置，默认强度和名额都是 0。计算完成保存为待做记录，实验完成后回填对应编号。预测与趋势图的参数和响应来自当前模板，可导出当前预测与图线的完整 Excel/CSV 数据。精度页提供输入执行 digits、输入显示位数、测量/派生指标显示位数三个独立批量操作；显示设置不改变保存值和模型。

**批量实验点预测**：在“实验记录”按 Ctrl 多选或 Shift 连选，点击“复制所选条件到批量预测”，自动进入“预测 / 趋势图 → 批量实验点预测”。点击“按所选模型批量预测”，使用“下一批实验”当前模型及随机种子，一次拟合后预测全部所选条件；本页不绘图，也不会要求保存图片。表中每个来源实验一行，保留原始条件、预测均值/中位数与中央 95% 区间，点击“导出批量预测 Excel”可保存完整结果及明细。相同条件的不同实验分别保留，复制值不按执行精度重新取整，普通预测计算不修改实验记录。本页列表与报告在关闭/切换项目或更换模板后清空；可导出 Excel，或主动点击“记录到原实验（用于回填评分）”保存逐条预测快照后按 Ctrl+S 保存项目。所选历史实验仍按原规则参与训练，预测结果不是独立留出验证。操作见 [回答.md](回答.md) 第 66 节。

全范围、单变量和双变量推荐现默认优先覆盖所选变量，尽量让每个变量在整批实验中出现不同取值。单/双变量限制的是**每条新实验**改变几项，每条可以选择不同变量或组合；覆盖完成后按原优化/探索评分选点，探索强度为 0 也生效。受名额、约束、网格、历史去重或候选池限制而未变化的变量会明确列出；交叉布局保持指定组合。详见 [回答.md](回答.md) 第 64 节。

推荐完成后，在“下一批实验”点击 **“导出本批次 Excel（完整条件与预测）”**，导出最近一次已保存的推荐批次（包括复测）。Excel 主表每个实验一行，包含全部输入条件、实验编号、安排、预测均值/中位数及 2.5%/97.5% 上下限、可行概率；另附预测明细、字段单位/范围和批次说明。启用输入执行波动时，明细保留确定输入与含波动两组结果。初始化阶段可导出条件，预测标为暂无；原始比值均值及不可用区间留空并说明原因。导出使用推荐时快照，不重新训练或按显示位数取整。按 Ctrl+S 保存项目后，重新打开仍可导出；操作和旧批次兼容说明见 [回答.md](回答.md) 第 63 节。

模板编辑的控件和字段表有自动悬停说明；字段表读取当前备注，新说明框出现时旧框立即隐藏。离开变量与弹窗约 1 秒关闭，移入弹窗可以点击详细链接。通用详细帮助仍为静态文件，字段自身说明请写在模板备注中。滚轮只滚动窗口/表格，不修改下拉选项和数值框。

桌面程序使用临时工作副本，顶部“保存项目”或 Ctrl+S 才写回项目文件。关闭/切换项目时有未保存变化会询问“保存 / 不保存 / 继续编辑”；不保存恢复最后保存状态，新项目未保存不生成文件。新建和另存为可选择同名同路径项目并确认覆盖。模板各层编辑也会提示未保存变化；项目模板修改仍需最终保存项目。CLI/Python 记录服务继续按事务立即写入。

0.4.2 修复保存项目同步临时文件时的 `Bad file descriptor` 路径。预测页和常用工作台可整体滚动，条件名称自动换行，模板表格行高随字体调整；窗口缩小、最大化或全屏后可滚动查看内容。故障原因与布局验证见 [回答.md](回答.md) 第 36–37 节。

预测趋势图现可为一项或两项变量分别填写绘图上下限，留空使用模板范围，可一键恢复全范围。绘图范围只限定采样和显示，不修改模板或训练数据。GP 先验、错误点、训练点附近的不确定度与范围的影响，以及操作说明见 [回答.md](回答.md) 第 38–43 节。

推荐、预测或绘图失败时，在弹窗中点击“查看原始诊断”可展开异常内容和调用堆栈，点击“复制原始诊断”可复制全文。关闭弹窗后，窗口顶部同名按钮可重新查看最近一次失败；仅保留在当前窗口会话中。计算进程意外退出时显示进程编号、退出码及可取得的诊断。操作与边界见 [回答.md](回答.md) 第 49 节。

GP 训练失败的诊断现包含失败响应、实验编号、实际输入与允许范围、噪声模式、每次优化器停止消息、原始警告及 BoTorch 日志。数值拟合失败时最多进行三次有记录的尝试，后两次调整核参数初值和线搜索设置；恢复成功会在页面提示，过程保存在技术详情。模板范围包含上下限，恰好覆盖实验点本身合法；已有实验的项目仍需另存模板或新建项目才能更改输入范围。详见 [回答.md](回答.md) 第 53 节。

预测公式出现非有限样本时，结果页会显示对应指标、有效样本数及原因提示；全部不可用的区间明确标注，其他响应继续显示。部分样本有效时，区间明确标为“有限样本”统计，趋势图和导出保留相应说明；模型基础响应本身异常则报告响应名称与预测条件。修复“不能显示非法数值”的具体原因见 [回答.md](回答.md) 第 59 节。

## 接口与验证

```bash
python cli.py --help
python cli.py create local-data/project.sqlite --template local-data/template.json
python cli.py template local-data/project.sqlite
python cli.py recommend local-data/project.sqlite examples/batch.json
python cli.py predict local-data/project.sqlite examples/prediction.json
python cli.py import local-data/project.sqlite records.xlsx --commit
python cli.py import local-data/project.sqlite edited-records.xlsx --update --commit
python cli.py export local-data/project.sqlite records.xlsx
python cli.py importance local-data/project.sqlite --model gp_rbf_v1 --output importance.xlsx
python cli.py predict-records local-data/project.sqlite --ids 1,2 --model gp_rbf_v1 --commit
python cli.py scores local-data/project.sqlite --ids 1,2 --output scores.xlsx
python cli.py backup local-data/project.sqlite backup.sqlite
```

请求中的字段名应匹配所选模板。CLI 推荐默认预览，`--commit` 才写入；导入输出包含停止行和说明。GUI 的“计算并保存”会写入项目。

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q -p no:cacheprovider
python main.py --self-test local-data/self-test
```

自检输出目录须尚不存在。Linux 无桌面验证设置 `QT_QPA_PLATFORM=offscreen`。本版支持数据库版本 1 和 2；删除功能沿用版本 2 标记。能力与验证范围见上方文档，不以合成数据测试代替真实机台效果。
