# Python 版实验预测测试计划

日期：2026-09-20。范围仅为 `python-version`（用户提到的 `python-verison` 按现有目录名称处理）。

## 1. 需求与要回答的问题

依据 [项目需求 V1.1](docs/project_spec.md) 第 2、6、7、8 节、[功能对照](docs/coverage.md)、[模型能力](docs/baseline_model_capabilities.md) 和 [历史验证](docs/validation.md)。

本项目根据八个 ICP 可控参数预测有符号刻蚀量 A、B，再从同一批后验样本计算 `abs(A)`、`abs(B)`、原始选择比及稳定化选择比。三个数值模型为 GP-RBF、GP-Matérn 2.5、贝叶斯线性；原始厚度不能作为事后输入泄漏。95% 区间是潜在响应区间，不包含下一次量测误差。默认基础响应相互独立。

本轮回答：公式及预测语义是否正确；在没有见过的合成条件上，预测能否优于训练均值基线；区间是否覆盖真实潜在响应；哪些情形下不能信任预测。原有“能拟合、能出数”的测试不能单独回答这些问题。

## 2. 预先确定的检查矩阵

| 编号 | 检查 | 判据 |
| --- | --- | --- |
| P01 | 原有完整测试回归 | 全部通过；保存未修改代码时的原始输出 |
| P02 | 线性后验的独立解析解 | 用 NumPy 根据高斯线性回归公式计算均值、协方差，与实现比较；不调用生产代码计算期望值 |
| P03 | 数据筛选 | 按实际执行条件训练；失败、取消、待做不进入模型；某响应缺失不删除另一响应 |
| P04 | 比值与公式 | 用指定后验样本手算绝对值、稳定化、原始分位数、可行概率；原始比值不报告均值；预测与实测单位一致 |
| P05 | 输入、噪声、少样本 | 越界、不足两条、混合已知/未知误差应明确拒绝；未知误差不得补零 |
| P06 | 线性且数据充足 | 8 维、64 条训练、64 条独立测试，三个模型、5 个固定种子 |
| P07 | 小样本 | 与 P06 相同关系，只有 12 条训练；不因模型能拟合就认定可信 |
| P08 | 非线性和交互 | 64 条训练、64 条独立测试，检验线性模型失配与 GP 的适用性 |
| P09 | 超出训练覆盖区域 | 仍在模板合法范围内，训练每维归一化值 0.10–0.55，测试 0.70–0.95；区分合法输入与有数据支撑的预测 |
| P10 | 修复后的完整回归 | 新增科学性检查和原有测试均通过，保留缺陷复现与修复后证据 |

种子固定为 11、23、37、51、79。训练噪声与测试条件使用独立随机流；训练集合与测试集合不得重合，不用训练点重代入代替泛化验证。三个模型使用完全相同的数据；不根据测试结果调整超参数、挑选种子或改测试阈值。P06–P09 共 60 次拟合、每种场景每模型 320 个测试点。

合成函数在独立脚本中明确定义，不复用演示数据发生器；四个原始厚度分别加入独立 N(0, 0.2²) nm 误差，并通过实际录入、派生、存储和分析入口计算。A、B 的已知观测方差均为 0.08 nm²。固定潜在真值用于评估区间覆盖；不把带未来测量噪声的结果拿来判潜在区间校准。

## 3. 指标和判读规则

- A、B：MAE、RMSE（nm）、相对测试真值标准差的 NRMSE、R²、相对“训练观测均值”的均方误差技能分数 `1 − MSE_model/MSE_baseline`。技能分数 ≤ 0 表示不优于这个简单基线。
- 区间：2.5%–97.5% 后验分位数覆盖率、平均宽度；同时保存各随机种子的结果。使用 512 个样本，与应用默认入口一致。
- 比值：原始比值使用后验中位数计算绝对误差，不能以不存在的均值打分；稳定化比值单独评分，epsilon = 1 nm。
- 探索性合成筛查门槛：技能分数 > 0、NRMSE ≤ 0.25、95% 区间覆盖率 ≥ 85%，三项均满足才记为“本场景筛查通过”。85% 是用于发现明显过度自信的宽松报警线，不代表 95% 校准验收；过宽区间需要结合宽度判断。
- 这些门槛是本轮合成检查约定，不是用户的工艺允差。P07–P09 用于暴露适用边界，失败如实记录，不要求所有模型在所有关系上通过。有限种子和同一拟合内相关的测试点不能当成大量独立实验来声称统计保证。

不将“推荐条件合法、采集函数有值”解释为“推荐一定提升实际工艺”；多目标实验效率需要另做等预算前瞻对照。布尔概率在原有回归内检查，当前定量报告聚焦默认 ICP 数值响应，不声称已经完成布尔概率校准。

## 4. 执行与产物

在本目录、安装依赖的 Python 3.12 环境中运行：

```bash
QT_QPA_PLATFORM=offscreen python -m pytest -q
python scripts/validate_prediction.py --output docs/evidence/prediction-audit-2026-09-20/benchmark.json
```

Windows 的 pytest 命令可去掉前面的环境变量设置。当前仓库可复用父目录解释器 `../.venv/bin/python`，pytest 的 `pythonpath=src` 和脚本自身路径设置确保执行本目录代码；报告同时保存实际模块位置。

产物：本计划、可重复的测试与评估脚本、原始 JSON/JUnit/日志证据、[实验预测测试结果](实验预测测试结果.md)、[本次改动记录](实验预测测试改动记录.md)。已有历史证据不覆盖。本轮发现的确定性预测缺陷先复现，再作有限修复；模型适用性不足不靠隐藏数据或随意调整模型掩盖。

## 5. 真实实验如何验收（本轮未执行）

真实数据在本机进行：先核对单位、设备/材料/批次、实际条件和测量不确定度；按时间留出最后一批，复测及同批相关样本保持同组，禁止跨训练/验证泄漏。模型选择使用更早数据，最后一批只评估一次。分别报告 A、B 误差、相对常数/简单线性基线的改善、分母跨零比例和区间覆盖；预测与未来实测比较时须另加相应未来噪声。

由实验负责人先确定 A、B 可接受绝对误差（nm）、分母可分辨阈值及设备约束，再进行小批前瞻回填验证。没有真实历史数据、重复测量与这些工艺标准，本轮只能判断实现及合成场景表现，不能证明机台物理准确性。
