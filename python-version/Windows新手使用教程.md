# Windows 新手使用教程 · 0.3.0

本版支持标准 Python 3.12 和 3.13。为 `python-version` 文件夹单独创建环境，不使用自由线程版本，也不要复用父目录旧工程的环境。

## 1. 安装并打开

安装标准 Python，使用 PyCharm 打开本目录，创建对应解释器的 `.venv`。或者在终端创建环境：

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python main.py
```

使用 Python 3.12 时替换版本号。PyCharm 以普通 Run 配置运行 `main.py`，不要在 Python Console 中运行。若提示缺模块，核对安装依赖和运行程序是否使用同一个环境。

## 2. 创建完全自定义的模板

进入“更多功能 → 项目与模板 → 新建 / 复制 / 修改模板文件”，选择“从空白创建全新模板”。也可以从常用页定制加入模板入口。

1. 填写模板名称，点击“参数 / 测量 / 公式（增删改名）”。
2. 在“输入参数”添加实验前可设定的条件。内部名称填写英文标识，显示名称可用中文，选择类型、单位以及范围、离散值或固定值。
3. 在“原始测量”添加需要记录的结果，选择作为响应及是否直接建模。未测值在录入实验时留空。
4. 需要计算指标时，在“派生指标与公式”添加公式，使用字段内部名称引用。
5. 返回模板主界面，设置精度、先验和目标。单目标模式只选一项，多目标可选折中或加权。
6. 至少有一个输入、一个直接建模的响应和有效目标后，点击保存，选择模板文件位置。
7. 点击“从模板新建项目”，选择刚保存的模板，再选择一个新的 `.sqlite` 项目文件。

所有其他配置可在“全部属性”树中增删和修改，无需手写整段 JSON。无效公式、单位名称或未支持的模型组合会提示原因，不会当作可用配置保存。

## 3. 修改已有模板

模板起点可选择“复制当前项目模板”或“打开并修改本地模板文件”。可以修改参数名称、数量、类型、单位、取值、公式、目标和其他属性。

字段表单修改内部名称会同步更新已知引用；显示名称更改不影响数据标识。删除字段时先核对连带删除的公式、目标和关系。通过“全部属性”直接更改内部名称时，相关引用需自己一起调整。

编辑当前项目模板时，兼容的修改直接保存。空项目允许换结构；已有记录且结构不兼容时，可点击“另存模板文件”或“用此模板新建项目”。已经编辑的内容会保留，不用重新操作，也不会改写旧实验的含义。

## 4. 录入和导入

常用页点击“录入实验 / 复测结果”，填写当前模板所需输入和测量。未测值留空，不用零代替；填写误差时选择含义，更多误差属性在“详细误差”。相同条件可保存多次，每次有独立编号。

常用页默认有“导入 CSV / Excel”。选文件后用下拉框匹配列，点击校验并看预览。导入按模板顺序取前 30% 输入、向上取整，全部为空的行即为结束标记；只录入它以前的有效记录。例如 8 个输入检查前 3 个。标记行后即使还有数据，也不会继续导入。

空白字符算空，0 和“否”不算空。预览显示停止位置。缺少表头映射，或结束前还有错误时，先修改再提交。需要继续录入的实验之间不要插入符合结束条件的空行。程序读取 Excel 的活动工作表。

## 5. 推荐、回填与删除

“推荐下一批实验”选择总数、模型、变化模式、探索强度和专门探索名额，并勾选复测。总数 6、无复测、专门探索 2 时，2 个用于探索，另 4 个按常规评分选择。数据不足时会说明采用初始化策略。

推荐保存为待做记录。完成后在“查看与回填实验”选中对应记录回填。数据更改后，旧数据版本计算出的批次不能写回，应重新计算。

删除时用鼠标单选、Ctrl 多选、Shift 连选或拖动选择，再点“删除选中实验”确认编号。删除后不参与当前训练、推荐和普通导出，原内容保留在审计中，旧批次保留。删除后可用 Ctrl+Z 撤销、Ctrl+Y 重做，工具栏也有对应按钮；关闭项目或保存新推荐批次后撤销历史清空。空缺编号可复用，日常备份使用“一致性备份”。删除基准实验后，需要基准的模式应重选。

## 6. 通用帮助与工作台

悬停变量名称或设置，弹出简述和蓝色详细链接；离开变量与弹窗后约 1 秒关闭，移入弹窗可以继续点击。详细说明只介绍通用操作，不包含具体模板的参数清单。字段含义请查看当前模板名称和备注。

“自定义常用功能”可以增减导入、导出、备份、模板等入口，重启后保留；精度、先验、目标固定保留。其他功能在“更多功能”。
