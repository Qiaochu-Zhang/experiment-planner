# Windows 新手使用教程 · 0.2.1

本版支持标准 Python 3.12 和 3.13。建议为 `python-version` 文件夹单独创建环境，以下按 Python 3.13 举例。

## 1. 安装并打开

安装 Python 3.13 标准版，安装时启用 Python Launcher。安装 PyCharm 后选择 Open，打开 `python-version` 文件夹。进入项目解释器设置，新建 Python 3.13 的虚拟环境 `.venv`；不要选择自由线程版本，也不要复用父目录旧工程的环境。

在 PyCharm Terminal 中逐行执行：

```powershell
.venv\Scripts\python --version
.venv\Scripts\python -m pip install --upgrade pip
.venv\Scripts\python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python -m pip install -r requirements.txt
```

不使用 PyCharm 时，可先在本目录执行 `py -3.13 -m venv .venv`，再执行上面命令。想使用 3.12 时替换解释器版本即可。

在 PyCharm 右键 `main.py` → Run。使用普通 Python 运行配置，不要使用 Python Console 执行整个程序。若提示缺少模块，确认运行解释器与安装依赖所用解释器是同一个 `.venv`。

## 2. 创建项目与录入

点击“新建项目”，选择一个尚不存在的 `.sqlite` 文件。一个文件代表一个实验项目，保存按钮会直接写入数据库。

常用工作台点击“录入实验 / 复测结果”，填写工艺条件及前后厚度。未测的厚度留空，不填零。选择完成、部分结果等状态；± 误差需要同时选含义。高级误差可用“详细误差”逐项填写，均不需要编写 JSON。

同一条件可以录入多次、结果可以不同，每次生成自己的编号。导入表格时每次实际实验使用唯一 `external_id`。文件模板和逐列填写说明见 [导入模板](examples/import_templates/README.md)。

常用页默认有“导入 CSV / Excel”，选择文件后匹配列并检查预览。尾部空记录、列映射和误差提示的解释见 [回答.md](回答.md) 第 9–10 节。

需要删除记录时，进入“查看与回填实验”，单击一行，按住 Ctrl 选多行或 Shift 连选，也可拖动选择，点击“删除选中实验”并核对编号。取消会保留全部记录。删除后记录不再参与训练、推荐和普通导出，项目历史保留删除前数据，旧批次预测保留；当前没有一键撤销。已保存的基准和复测设置会清理对应编号，需要基准的模式请重新选择。

首次删除会升级数据库版本，该项目之后需用 0.2.1 或后续支持删除功能的版本打开；完整数据库备份仍包含删除审计。

## 3. 设置精度、先验和目标

- “推荐工艺精度”：执行模式选“小数位数”，填 0 表示整数、1 表示一位小数；也可设置步长或批量应用。显示位数单独设置，不改变原始测量。
- “先验关系定义”：点击添加，选择输入、响应、关系，填写系数、强度、来源。单调/弱影响先验须在目标页选择贝叶斯线性模型。
- “实验优化目标”：勾选要优化的响应，选择原值、绝对值或距指定值的距离，设置尽量大/尽量小；支持单目标、Pareto 多目标、显式加权。

新版默认 **SiO2 刻蚀量尽量大，SiN 刻蚀量接近零，刻蚀量比值尽量大**，第一和第三个目标不取绝对值。旧项目不会自动切换；目标页有“应用新版 ICP 目标”按钮。

比值目标需先设置分母策略：有效区域、稳定化或移除。前两种还要填正数 epsilon（nm）。按实际测量口径选择；稳定化在分母恰好为零时明确使用 +epsilon，原始比值仍为未定义。

## 4. 生成下一批

点击“推荐下一批实验”。选择总数 n、模型、条件变化模式、探索强度、专门探索名额。可通过按钮勾选允许变化的参数和需要复测的旧实验。

例如总数 6、不安排复测、专门探索 2：两个新条件专门探索，四个按常规评分选择。探索强度为 0 时常规评分保留贝叶斯优化；调大时增加可行候选的不确定性加分。总数包括复测，探索名额不能超过扣除复测后的新条件数。

单/双变量模式需选基准。交叉布局通过两个下拉框及新值输入框设置，不支持额外探索名额。合法候选不足时只返回实际可用点并说明原因，不会重复填满。

点击“计算并保存下一批实验”；程序完成后将结果保存为待做记录。真正做完实验，在“查看与回填实验”选择新记录再回填结果。若后台计算期间改了数据，该次结果不能写入，需重算。

## 5. 查看预测和帮助

“预测与趋势图”可从选中实验复制条件，也可直接逐项填写。通过按钮选择趋势变量与指标；留空趋势变量只预测。图表与主要说明使用中文，技术详情保留原始诊断用于复核。

鼠标在变量名或设置上停留后，会显示简要说明和蓝色“详细说明”链接。离开变量与弹窗后约 1 秒关闭；在关闭前移入弹窗或返回变量则继续显示，方便点击链接。点击可定位到程序随附的说明文件；也可用常用工作台的说明按钮打开。帮助完全离线，但说明文字不会自动随模板修改。

## 6. 定制工作台和新模板

“导入 CSV / Excel”默认已在常用页，旧配置升级时也会添加一次。“自定义常用功能”可增减导入、导出、备份等入口，重启后保留，用户取消导入后不会再次强制添加。精度、先验、目标固定在常用页。其他操作在“更多功能”。

“更多功能 → 项目与模板 → 编辑项目模板 → 全部属性”可用树形表单增删、修改字段、公式、范围和约束。双击某个值编辑，选择类型，使用按钮添加列表项或属性。内部字段与类型枚举仍用英文代码，中文标题填 label；不必输入 JSON 的引号或括号。

保存已有项目模板会增加版本、重算派生值。字段类型、单位、范围等结构改变需点击“新建模板 / 从当前模板复制”，保存新 JSON 文件后“从模板新建项目”。这样不混用旧实验含义。日常备份请使用“一致性备份”。
