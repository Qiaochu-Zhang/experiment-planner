# CSV / Excel 实验记录导入模板

适用：Python 源码版的内置 **SiO2 / SiN ICP** 项目。核对日期：2026-09-21。

## 下载和选择

| 文件 | 用途 |
| --- | --- |
| [实验记录导入模板.csv](实验记录导入模板.csv) | CSV 空白模板，只有表头，从第 2 行开始填写。UTF-8 带 BOM，方便 Excel 识别中文。 |
| [实验记录导入模板.xlsx](实验记录导入模板.xlsx) | Excel 空白模板，带表头批注、单位／范围提示和选项下拉框。 |
| [实验记录填写示例_合成数据.csv](实验记录填写示例_合成数据.csv) | 两行合成填写示例，用来对照格式。 |
| [实验记录填写示例_合成数据.xlsx](实验记录填写示例_合成数据.xlsx) | 与 CSV 示例内容相同的 Excel 示例。 |

**正式录入请用空白模板。示例不是实际测量或推荐工艺，只在练习项目里导入。** 两种模板的 27 列相同，选一种填写即可，不需要导入两遍。

在 GitHub 打开文件后，点击 **Download raw file（下载原始文件）**；也可以下载整个仓库 ZIP，在 `python-version/examples/import_templates/` 中找到文件。不要把网页另存为文件后改成 `.xlsx`。

## 怎么填写和导入

1. 复制一份空白模板，改名为自己的文件，例如 `2026-09-21实验记录.xlsx`。
2. 保留第 1 行表头，从第 2 行起每行填写一次实验。八个实验条件都要有值；没测的厚度留空。
3. 单元格只填数值，不写 `nm`、`W`、`±` 等字符。例如厚度填 `100`，对应不确定度列填 `1`，误差类型列填 `std`。
4. 在 Excel 中把鼠标停在表头上，可查看批注；状态、误差类型、分布列提供英文选项下拉框。下拉和数值提示覆盖第 2–10001 行；更多行仍可导入，依靠程序校验。
5. 保存为 `.xlsx`，或 **CSV UTF-8（逗号分隔）**。不要保存为旧版 `.xls`。
6. 打开软件中的目标项目 → 点击“导入 CSV / Excel” → 选择文件。
7. 映射框保留 `{}`，这些表头可以自动识别，不必手工映射。
8. 点击“校验并预览”，检查条数、条件、测量值和误差设置，没有错误后点击保存。

空白模板直接预览应是 **0 条记录**；填写完成后，预览条数应等于你填的实验行数。导入只保存记录，不会自动拟合或刷新历史预测；下一次预测／推荐时才使用新数据。

## 各列填什么

### 实验编号、状态和备注

| 列名 | 必填吗 | 填法 |
| --- | --- | --- |
| `external_id` | 可选，建议填 | 自己编的唯一编号，例如 `EXP-001`；避免使用容易丢失前导零的纯数字编号。不是软件里的内部实验编号。 |
| `status` | 可选 | 使用下面列出的英文状态；留空默认 `completed`（完成）。 |
| `note` | 可选 | 整次实验的中文备注，不参与数值建模。 |

`status` 可选值：

| 填入值 | 中文含义 |
| --- | --- |
| `completed` | 完成；有效测量可参与训练。 |
| `partial` | 部分结果；已经有的有效响应可参与训练。 |
| `running` | 进行中；不参与训练。 |
| `pending` | 待做；不参与训练。 |
| `failed` | 失败；不参与训练。 |
| `cancelled` | 取消；不参与训练。 |

状态单元格不能直接填“完成”等中文。一次实验只填写一个 `external_id`，不同实验不要复用；完全相同的记录重复导入会去重。同编号数据发生变化时，软件会提示冲突，要在记录页更正，导入不会直接覆盖。

### 八个实验条件

| 列名 | 单位 | 内置允许范围 |
| --- | --- | --- |
| `Cl2` | sccm | 0–100 |
| `BCl3` | sccm | 0–100 |
| `Ar` | sccm | 0–100 |
| `ICP` | W | 100–1500 |
| `RF` | W | 0–100 |
| `腔室压力` | 模板记作 mT | 5–50 |
| `电极温度` | °C | 0–40 |
| `刻蚀时间` | s | 10–300 |

这八列每条实验都要填，范围包含两端。填写**实际执行的条件**。没有另设整数限制时可带小数。范围是内置模板的输入规则，不代表最佳工艺窗口。

### 四项原始测量

| 列名 | 单位 | 意思 |
| --- | --- | --- |
| `SiO2初始厚度` | nm | 刻蚀前 SiO2 的厚度。 |
| `SiO2剩余厚度` | nm | 刻蚀后 SiO2 的厚度。 |
| `SiN初始厚度` | nm | 刻蚀前 SiN 的厚度。 |
| `SiN剩余厚度` | nm | 刻蚀后 SiN 的厚度。 |

未测的留空，不填 `0`、`未测`、`NA` 或横线；`0` 表示确实测得零。只拿到部分结果时，状态填 `partial`。两项对应厚度都存在，软件才能计算该材料的刻蚀量。

模板不需要填写刻蚀量、比值或模型预测列；这些结果由软件计算。

### 不确定度、误差类型和分布

每项厚度都有以下三列，共 12 列。下表以 `SiO2初始厚度` 为例，其他三项的填法相同。

| 列名 | 填法 |
| --- | --- |
| `SiO2初始厚度_不确定度` | 填 ± 后面的非负数值，单位 nm；例如 `0.5`。不知道就留空，不要用 0 冒充未知。 |
| `SiO2初始厚度_误差类型` | 填 `std`、`sem`、`bounds` 或 `unspecified`；含义见下表。 |
| `SiO2初始厚度_分布` | 通常留空；确定误差界限且采用均匀分布假设时填 `uniform`。 |

| 误差类型 | 白话含义 | 分布列怎么填 | 是否影响预测模型 |
| --- | --- | --- | --- |
| `std` | 标准不确定度 1σ | 留空 | 有有效误差值时，传播到刻蚀量后作为测量噪声使用。 |
| `sem` | 多次测量均值的标准误 | 留空 | 使用填入的 SEM，不自动从重复次数计算。 |
| `bounds` | 确定误差界限 | 留空 | 用于边界计算和比值稳定性判断，默认不作为已知测量噪声使用。 |
| `bounds` | 确定误差界限，并明确采用均匀分布 | `uniform` | 按“界限 ÷ √3”换算标准不确定度后参与建模。 |
| `unspecified` 或空白 | 不知道误差含义 | 留空 | 不把 ± 数字自动当作标准差；按未知误差处理。 |

示例：测得厚度 `100 ± 1 nm`，若“±1”是标准不确定度，厚度列填 `100`，不确定度列填 `1`，类型填 `std`，分布留空。若“±1”是误差界限且确实假设均匀分布，类型填 `bounds`，分布填 `uniform`。

**不要为了让误差进入模型，随意把误差界限改成 `std` 或猜填 `uniform`。** 对刻蚀量而言，初始厚度和剩余厚度的误差都需要能够转换，才会得到已知标准不确定度。同一个响应的训练数据混用已知／未知误差时，当前模型会报能力限制；导入成功不代表这些数据已经满足所有建模条件。

本模板只提供上述常用误差设置，不含置信区间覆盖因子、非对称误差或共享误差来源列。需要其他类型时先核对 [参数与操作白话说明](../../参数与操作白话说明.md) 和实际导入支持范围，不要仅更改类型名称。

## 常见问题

- **不要在表头上方加标题、单位行或说明行。** 程序把第 1 行作为表头、第 2 行起作为数据。
- **不要夹杂空行或把不用的整行预填状态／备注。** 程序会尝试解析读到的每一行；没有完整八个条件会报错。删除多余行；仅清空内容可能留下 Excel 行格式，仍被读到。
- Excel 模板仅有“实验数据”一个工作表。当前软件读取保存时的**活动工作表**；若自己添加了其他工作表，导入前切回“实验数据”再保存。
- Excel 公式不会在导入时自动计算。请把需要的结果粘贴为纯数值，不在测量列填写 `=...` 公式。
- 保留表头文字，不要自行把 `Cl2` 改成 `Cl2 (sccm)`；改名后必须提供对应的字段映射。单位以本文和表头批注为准。
- Excel 的下拉和数值校验是填写辅助，复制粘贴可能绕过它；以软件的预览和保存校验为准。
- 这些文件是**实验记录表格**，应使用“导入 CSV / Excel”。“从模板新建”读取的是项目规则 JSON，不能读取 CSV／Excel。
- 自定义项目的字段、范围或单位与内置 ICP 模板不一致时，需要按自己的项目调整表格和映射。可以先从该项目导出记录作为格式参考。

更完整的参数解释见 [参数与操作白话说明](../../参数与操作白话说明.md)，安装启动见 [Windows 新手使用教程](../../Windows新手使用教程.md)。
