# CSV / Excel 实验记录导入模板

适用：Python 源码版的内置 SiO2 / SiN ICP 项目。0.4.1 更新，2026-10-10。自定义实验请从自己的项目点击“项目与模板 → 下载导入 CSV / Excel 模板”，生成实际字段、单位、范围和下拉选项。

| 文件 | 用途 |
| --- | --- |
| [实验记录导入模板.xlsx](实验记录导入模板.xlsx) | Excel 空白导入表：第 1 行填写提示，第 2 行列名，第 3 行起填写。必填、单位、范围、批注和限定选项下拉。 |
| [实验记录填写示例_合成数据.xlsx](实验记录填写示例_合成数据.xlsx) | 新格式 Excel，两行合成记录。 |
| [实验记录导入模板.csv](实验记录导入模板.csv) | 保留旧版中文列名的 CSV 空表：第 1 行列名，第 2 行起填写，UTF-8 带 BOM。 |
| [实验记录填写示例_合成数据.csv](实验记录填写示例_合成数据.csv) | 旧格式 CSV 的相同两行合成记录，用于兼容和填法对照。 |

**正式录入用空白表。示例仅用于练习，不是真实测量或推荐工艺。** 新版 Excel 有 51 列，含各字段备注、测量单位、覆盖因子和置信水平；旧 CSV 保留 27 列常用内容。两种示例的条件、测量和误差相同，任选一种，不需要重复导入。

## 填写和导入

1. 复制空白模板，改名为自己的文件。Excel 在“导入数据”页第 3 行起填写，每行一次实验；CSV 第 2 行起填写。保留列名，不在列名里添加单位。
2. 每条记录所有输入参数必填，包括固定输入。测量未做可留空，零表示确实测到零；数值格只填数字，不写 `nm`、`W`、`±` 等字符。
3. 看列名上方的黄色说明，必填提示为红色。固定/离散值、是否、状态、单位、误差类型和分布有下拉，输入范围等有数值校验；选中格子或悬停列名可查看说明。
4. 保存为 `.xlsx`。需要 CSV 时使用 CSV 空表；如果将新版 Excel 转成 CSV，要先删除第 1 行填写提示，只保留列名和数据。不要保存为 `.xls`。
5. 打开目标项目 → “导入 CSV / Excel” → 选择文件 → 核对列对应关系 → “校验并预览”。没有错误后确认导入，桌面点击“保存项目”写回文件。

下拉和数值校验覆盖 Excel 第 3–10002 行，共 10000 条；更多记录仍可导入。复制粘贴可能绕过 Excel 校验，最终以软件预览为准。空表预览是 0 条记录。旧 Excel 第 1 行列名的文件仍支持；程序读取活动工作表，保存前切回“导入数据”。“填写说明”供阅读，隐藏的“_填写选项”不需编辑。

导入按当前模板输入顺序检查前 30%（向上取整、至少一项）。这些输入全空时，该行及后续行不导入；内置八个输入检查前三项，不包括编号、备注和测量。连续实验间不要插入结束行。0 和“否”不算空值，预览错误和停止位置使用 Excel 的实际行号。

## 字段说明

`external_id` 是可选外部编号，建议填写，例如 `EXP-001`。每次复测使用不同编号；同编号相同内容重复导入会去重，同编号内容不同会报冲突，要在实验页更正。`note` 是整条记录的备注，每个输入/测量也可填写对应的 `_note`。

`status` 可留空，默认为 `completed`；使用下拉中的英文值：

| 值 | 含义 |
| --- | --- |
| `completed`、`partial` | 完成、部分结果；有效响应可参与训练。 |
| `pending`、`running` | 待做、进行中；不参与训练。 |
| `failed`、`cancelled` | 失败、取消；不参与训练。 |

八个必填输入的内置范围如下，均含边界；填写实际执行值，不必落在推荐取整网格上。范围是允许规则，不是最佳工艺窗口。

| Excel 列名 | 显示名称 / 旧 CSV 列名 | 单位 | 范围 |
| --- | --- | --- | --- |
| `cl2_sccm` | Cl2 | sccm | 0–100 |
| `bcl3_sccm` | BCl3 | sccm | 0–100 |
| `ar_sccm` | Ar | sccm | 0–100 |
| `icp_w` | ICP | W | 100–1500 |
| `rf_w` | RF | W | 0–100 |
| `pressure_mt` | 腔室压力 | 模板记作 mT | 5–50 |
| `electrode_temp_c` | 电极温度 | °C | 0–40 |
| `etch_time_s` | 刻蚀时间 | s | 10–300 |

四项原始测量为 `sio2_initial_nm` / `sio2_remaining_nm` / `sin_initial_nm` / `sin_remaining_nm`，对应 SiO2/SiN 的初始和剩余厚度，单位 nm。未测留空，不写“未测”“NA”或横线；只拿到部分结果可选 `partial`。两项厚度都有值才可计算该材料刻蚀量。刻蚀量、比值和模型预测由软件生成，不填写在导入表中。

每项测量后有单位、不确定度、误差类型、分布、覆盖因子、置信水平、备注列。以下以 `sio2_initial_nm` 为例：

| 后缀 | 填法 |
| --- | --- |
| `_unit` | 下拉选模板单位，留空使用模板单位；不在此处进行单位换算。 |
| `_uncertainty` | 非负数字，单位与测量相同；未知留空，不用 0 冒充未知。 |
| `_uncertainty_kind` | `std` 标准差 / `sem` 均值标准误 / `bounds` 对称界限 / `interval` 区间 / `unspecified` 未知。 |
| `_distribution` | 明确假设时填 `uniform` 均匀或 `normal` 正态，否则留空。 |
| `_coverage_factor` | 正数；正态 interval 若需换算标准误差，与置信水平至少填一个。 |
| `_confidence` | 严格在 0 与 1 之间，如 `0.95`；不写 `95` 或百分号。 |
| `_note` | 测量备注。 |

`std/sem` 有有效误差数值时可用于标准误差传播；`bounds + uniform` 按界限 ÷ √3 换算；`interval + normal` 需要覆盖因子或置信水平换算。只写 ± 数字不代表已知标准误差。未知含义、未声明转换条件的误差按未知处理。自定义模板中的文字/类别/是否测量不附数值误差，误差类型只能留空或 `unspecified`。

不要为让误差进入模型随意猜类型或分布。一个响应混用已知/未知误差时，当前模型有能力限制；导入成功不代表已经满足所有建模要求。导入不自动重算历史预测，下一次预测/推荐使用新数据。非对称误差和共享来源不由该表的单个误差数值列表达。

本文件是实验记录表，入口是“导入 CSV / Excel”；定义新实验字段、公式和目标需用另一套 [模板定义 Excel](../template_definitions/README.md)。更多解释见 [回答.md](../../回答.md) 第 28–31 节与 [参数说明](../../参数与操作白话说明.md)。
