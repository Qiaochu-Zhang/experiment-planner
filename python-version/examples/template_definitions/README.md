# Excel 模板定义示例

这些文件定义输入参数、测量、公式和优化目标。通过“新建 / 复制 / 修改模板 → 打开并修改本地模板文件”，或模板编辑器的“导入 Excel 模板”打开。编辑完成后保存，使用“从模板新建项目”。

- [空白模板定义.xlsx](空白模板定义.xlsx)：只有中文表头和填写说明，可直接填自己的字段。
- [模板定义示例.xlsx](模板定义示例.xlsx)：数值输入 speed、文字条件 sample、测量 quality 和派生指标 double_quality。仅展示软件用法，数据含义可自行改写。

工作表“输入参数、原始测量、派生指标与公式”每行一个字段；名称在所有表中不得重复。数值输入填写范围、离散值或固定值中的一种；文字输入不作为数值模型输入。原始测量默认直接建模，派生指标默认由基础响应预测按公式计算。单位可自由输入，同名自定义单位按同一量纲检查，不自动解释复合单位或换算不同单位名。

“优化目标”指定响应或指标及尽量大/尽量小。“模板设置”可填写 name、optimization.mode、ratio_policy.mode 等路径；加权目标的权重和尺度用 JSON 数组，顺序对应有效目标。“其他属性”可留空，用于保留扩展配置。详细填写方法见 Excel 内“填写说明”。

字段暂缺范围、公式或目标时可先导入草稿继续编辑，最终保存需要有效配置。模板定义表与 [实验记录导入表](../import_templates/README.md) 分别用于定义字段和录入实验，不混用。
