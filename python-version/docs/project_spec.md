## 1. 项目目标与确定的技术路线

开发一款面向实验人员的中文桌面软件。使用者不需要编程，可以建立实验模板、导入历史数据、录入测量结果、选择下一轮实验组数，并获得下一批建议条件。

软件使用 Ax 组织贝叶斯优化，利用本机实验数据拟合模型。用户可区分原始测量、辅助记录、被建模结果和优化目标，并用公式与先验知识表达具体实验。真实实验数据、预测结果、项目状态和日志均在公司 Windows 电脑上处理和保存。

| 决策项 | 本项目采用的方案 |
| --- | --- |
| 产品形式 | 单机中文桌面软件，双击启动 |
| 开发方式 | 在 AWS Ubuntu 编写代码、运行模拟案例和核心测试 |
| Windows 交付 | 在 Windows 环境安装依赖、测试并构建 Windows 包 |
| 正式运行 | 公司 Windows 本机计算，不连接 AWS 执行预测 |
| 界面 | PySide6 / Qt Widgets |
| 优化框架 | Ax；通过其 BoTorch 接口调用模型与采集函数 |
| 数据保存 | SQLite 本地数据库；本地备份与导出 |
| 文件交换 | Excel / CSV 导入导出；JSON 模板 |
| 初期计算设备 | CPU；默认不要求 GPU |
| 模型管理 | 默认GP，可选经验证的非GP模型；支持关系先验、派生目标和预测不确定度 |
| 运行网络 | 无运行时下载、外部 API、自动上传或云端日志；部署时限制应用出网 |
| 数据边界 | AWS、GitHub、云端开发工具只接触允许外发的代码、模板示例和模拟数据 |

Ax 的公开接口支持“请求候选条件—回填结果—继续实验”的循环，本项目在此基础上实现界面、模板及记录管理。[Ax 入门教程](https://ax.dev/docs/tutorials/getting_started/)

**交付包是能够本地建立和拟合模型的软件。每个项目的实际模型根据该项目的数据生成，无需联网下载“刻蚀专用模型”。**

## 2. 初始模板：SiO₂ / SiN ICP刻蚀优化

以下8个输入、4项厚度测量和3个目标按实验人员最新要求设置，替换原角度、电压、O₂、时间模板。给定范围作为软件搜索边界；本文不额外推定机台允许步长、总流量或混气组合限制。

### 2.1 可控输入参数

| 内部名称 | 显示名称 | 数值范围，含边界 | 单位 | 默认角色 |
| --- | --- | --- | --- | --- |
| cl2_sccm | Cl2 | 0–100 | sccm | 可控输入、参与推荐 |
| bcl3_sccm | BCl3 | 0–100 | sccm | 可控输入、参与推荐 |
| ar_sccm | Ar | 0–100 | sccm | 可控输入、参与推荐 |
| icp_w | ICP | 100–1500 | W | 可控输入、参与推荐 |
| rf_w | RF | 0–100 | W | 可控输入、参与推荐 |
| pressure_mt | 腔室压力 | 5–50 | mT | 可控输入、参与推荐 |
| electrode_temp_c | 电极温度 | 0–40 | °C | 可控输入、参与推荐 |
| etch_time_s | 刻蚀时间 | 10–300 | s | 可控输入、参与推荐 |

压力显示单位保留用户的“mT”。实现单位系统时按真空工艺语境将其作为mTorr的显示别名，并在建立正式项目时核对机台口径，不把它解释为磁场单位或静默换算数值。

模板不预设设备步长或取整位数。用户可分别指定执行精度和显示精度。尚未提供的总流量、混气配比和机台联锁限制留作可配置规则，不能假称已有完整设备约束。

### 2.2 原始测量与辅助记录

| 内部名称 | 显示名称 | 单位 | 测量时点 | 默认用途 |
| --- | --- | --- | --- | --- |
| sio2_initial_nm | SiO2初始厚度 | nm | 刻蚀前 | 原始测量、辅助记录，参与刻蚀量计算 |
| sin_initial_nm | SiN初始厚度 | nm | 刻蚀前 | 原始测量、辅助记录，参与刻蚀量计算 |
| sio2_remaining_nm | SiO2剩余厚度 | nm | 刻蚀后 | 原始测量，参与刻蚀量计算 |
| sin_remaining_nm | SiN剩余厚度 | nm | 刻蚀后 | 原始测量，参与刻蚀量计算 |

四项厚度均可录入数值、不确定度与备注。默认不将它们直接列入待优化的输入参数，也不把刻蚀后才能测得的厚度作为预测新实验所需的输入。

### 2.3 被建模的结果与优化目标

定义有符号刻蚀量：

- A = SiO2刻蚀量 = SiO2初始厚度 − SiO2剩余厚度，单位nm。
- B = SiN刻蚀量 = SiN初始厚度 − SiN剩余厚度，单位nm。
- S = abs(A / B)，无量纲；仅在比值具有可计算意义时给出数值。

| 用户指定的结果变量 | 目标定义 | 引擎中的目标含义 |
| --- | --- | --- |
| SiO2刻蚀量 A | 绝对值尽量大 | 最大化abs(A) |
| SiN刻蚀量 B | 绝对值接近0 | 最小化abs(B)，目标值0 |
| 两种刻蚀量之比的绝对值 S | 尽量大 | 最大化abs(A/B)，按第2.5节处理零分母 |

完整保存A、B的正负号。不得把“最大化abs(A)”偷换成“最大化A”，不得把“B接近0”写成单纯最小化B。若剩余厚度大于初始厚度，应显示负刻蚀量及其测量不确定度；不能自动截为零或改成正值。

“初始厚度不影响刻蚀量”作为本模板采用的场景假设保存：初始厚度只参与计算A、B，默认不作为它们的模型输入。它不是软件证明的物理结论；如果后续发现厚度或耗尽效应重要，应修改项目的模型输入角色并重新拟合。

预测新条件时，可以直接预测A、B；若还要预测剩余厚度，需要本轮初始厚度，并据“初始厚度−预测刻蚀量”计算。未提供初始厚度时，不伪造剩余厚度预测。

### 2.4 三目标的处理方式

初始模板默认采用三目标Pareto推荐，展示候选条件之间的折中，不自动把三个目标相加或只保留选择比。

软件还应允许用户明确切换为：

1. 选择其中一个指标作为主要目标，另一些作为约束或仅记录；
2. 指定各目标的权重和归一化尺度，使用加权方案；
3. 对SiN刻蚀量设置接近零的允许区间，再优化其余指标。

权重、目标阈值、Pareto参考点和归一化规则都要保存版本并在界面可查。没有用户定义时不能擅自把“希望接近0”变成硬性允许阈值。三个目标具有函数依赖，预测时应保留这种关系。[Ax 多目标优化](https://ax.dev/docs/recipes/multi-objective-optimization/)

### 2.5 SiN刻蚀量接近零时的选择比

原始指标S必须保留，但不能把B=0产生的除零、无穷大或NaN送入模型，不能用一个任意极小数作分母并宣称获得极佳选择比。

需要区分：

- 实测B明确非零：可以显示原始比值，同时报告其可靠性。
- B的测量区间包含0或小于量测分辨能力：显示“比值不稳定/分母无法分辨”，保留A、B，不能把该实验当作失败或舍弃其他有效测量。
- 后验分布在零附近有概率质量：原始比值的均值或方差可能不存在，有限次采样产生一个数字并不证明这些统计量有效。

模板保存原始三目标；首次执行含比值的优化前，软件必须让使用者明确选择并保存分母处理策略及有单位的阈值epsilon：

| 策略 | 计算含义 | 必须提示的影响 |
| --- | --- | --- |
| 有效区域内的原始比值 | 在abs(B)≥epsilon的区域评价abs(A/B)，其余标为该比值目标不可行 | 排除了小分母区域，影响“接近0”的折中 |
| 稳定化比值 | S_stable = abs(A) / max(abs(B), epsilon) | 是另一个有限指标，不等同于原始S |
| 暂时移除比值目标 | 用户明确选择只优化abs(A)、abs(B)，原始S仍记录 | 修改了参与优化的目标集合 |

epsilon由量测分辨率、不确定度及实验用途设置，不能默认为机器精度。稳定化模式同时展示原始S和S_stable，并显示实际优化的是哪一个。有效区域模式在采集函数内处理不可行样本，不能只丢掉这些样本再将条件均值冒充整体期望。

未选择策略时允许建项目、录入、计算厚度差和分别预测A与B；含比值的三目标推荐提示“需要设置分母处理方式”，不默默更换目标。

不同设备、材料层次或量测口径的数据默认不自动合并。跨场景共同建模必须在字段和模型中明确相应因素并验证适用性。

## 3. 模板、实验项目和模型的关系

| 对象 | 含义 | 生命周期 |
| --- | --- | --- |
| 实验模板 | 字段角色、单位、范围、精度、公式、先验、不确定度、目标和模型预设 | 可复用、复制和发布新版本 |
| 实验项目 | 使用某一模板版本开展的一次优化活动 | 独立保存数据、待做实验和进度 |
| 模型预设 | 模型类型、核函数、先验、采集函数等组合 | 随软件发布并记录版本 |
| 已拟合模型 | 模型预设结合某个项目数据后的结果 | 数据更新后重新拟合或刷新 |
| 推荐批次 | 某次请求产生的一批条件、基准、变化变量和解释图 | 关联当时的数据版本、模型版本和实验编号 |

例如，“SiO2 / SiN ICP刻蚀模板”可以创建“结构片A优化”和“结构片B优化”两个项目；两者的测量结果、优化进度和模型默认彼此独立。

模板编辑器属于本项目需要开发的功能。用户在界面填写参数后，软件将其转换为 Ax 配置。

### 3.1 模板管理规则

1. 提供内置模板、复制模板、新建模板、修改和导入导出功能。
2. 新建项目时保存模板内容的快照，不能只保存一个可变的模板名称。
3. 修改公共模板产生新版本，已有项目继续使用原来的快照。
4. 已有项目改变变量、单位或指标定义时，必须执行明确的迁移或创建新项目，不能静默混用历史数据。
5. 模板可以包含业务参数，不允许嵌入任意 Python 代码并执行。
6. 对无法用当前模板字段表达的规则，给出具体提示，由开发者增加支持。
7. 公式、关系先验、字段角色和不确定度口径修改后产生新版本，保留原始测量并按新版本重新计算、拟合。
8. 普通备注默认不进入模型；标记为模型先验的结构化知识才按已实现的规则生效。

## 5. 实验人员的操作流程

1. 打开软件，选择初始ICP模板、自建模板或已有项目。
2. 核对8个可控输入、原始测量、辅助记录、派生公式和目标；设置精度、关系先验及不确定度口径。
3. 导入历史数据或录入4项厚度测量，软件保留原值并计算A、B及比值的有效状态。
4. 查看派生指标、误差传播和异常提示；首次启用比值目标时设置分母策略。
5. 选择默认GP或其他已支持模型；指定本轮n组、是否复测、全范围或基于指定条件的单/双变量变动。
6. 勾选是否生成趋势图，软件在模板允许范围内计算候选。
7. 查看实际返回数量、相对基准变化、预测结果、预测区间、目标折中和趋势图，再保存/导出实验安排。
8. 实验后按编号录入实际执行条件、4项厚度及不确定度，可以逐字段填写备注。
9. 更正或新增原始数据后，所有受影响的派生指标及模型自动失效并重新计算；重启后继续原项目。

| 先验与误差 | 输入—输出关系、适用范围、置信强度、不确定度类型和相关性 |

普通用户通过表单输入规则，不必编写Python。高级模型设置不能使结构化先验被静默忽略。计算在后台运行；取消或重复点击不能破坏项目或产生冲突批次。

## 6. 模板、字段、公式与不确定度

### 6.1 字段角色必须独立配置

“原始测量”“进入模型”“用作目标”不是同一个属性，不能让用户只能三选一。

| 属性 | 可选内容 | 含义 |
| --- | --- | --- |
| value_type | 浮点、整数、类别、布尔、文字 | 数据本身是什么类型 |
| source | 用户录入、仪器测量、公式计算 | 数值从哪里来 |
| measured_at | 实验前、实验后、未知 | 推荐时是否已经可知 |
| use_as_model_input | 是/否 | 是否作为响应模型的预测输入 |
| is_control_input | 是/否 | 是否可被选点算法改变 |
| is_auxiliary_record | 是/否 | 是否为辅助记录，仍可被公式引用 |
| is_response | 是/否 | 是否为用户希望建模/预测的结果 |
| model_base | 是/否 | 是否直接建模，或从基础响应样本推导 |
| objective_role | 无、目标、约束、仅跟踪 | 如何影响推荐 |

例如：LER直接测得时可以同时是“原始测量”和“模型响应”；厚度差可以是“公式计算”和“模型响应”；初始厚度是“原始测量＋辅助记录”，仍参与差值计算，但默认不作为刻蚀量模型输入。

角色选择是业务建模假设，不是因果证明。“不作为模型输入”也不表示该字段在计算公式中没有影响。

默认禁止将未来实验后才知道的量作为预测该实验的输入。公式若引用未来未知量，必须能由已建模的基础响应推导，或明确要求补充实验前可知的条件；不能拿未知实测值填成零来完成预测。

### 6.3 实验记录与导入格式

每组实验保存唯一编号、批次、建议条件、实际条件、测量原值、派生指标、状态、时间、备注以及所用模板/公式/先验/模型版本。

每个数值单元保存value、unit、uncertainty、note和数据来源。Excel平铺导入可使用“SiO2初始厚度”“SiO2初始厚度_不确定度”“SiO2初始厚度_误差类型”“SiO2初始厚度_备注”等列，先映射预览再提交。

同一字段支持模板默认不确定度和逐行覆盖。数据库保留导入原文和规范化值，不能只保存带“±”的字符串。单位转换同时应用于数值、不确定度和阈值。

缺少某一材料的必要厚度时，其刻蚀量及依赖它的比值标为不可计算，其他有效数据继续保存。模型按实际支持的缺失输出能力使用数据；不能为了凑齐三目标而用零或预测值填充缺失测量。

### 6.4 公式编辑器与派生指标

本版必须支持加、减、乘、除、括号、abs、min、max及按指定位数round；可增加比较运算生成布尔指标。采用白名单表达式解析，不能直接eval任意Python代码。

计算前校验：

- 字段是否存在，量纲是否兼容，目标是否为支持的类型。
- 公式依赖是否为有向无环图，禁止循环引用。
- 缺失值、除零和非法运算返回明确的无效状态，而不是零。
- 公式、单位、舍入规则变更后，重算依赖指标并使旧拟合缓存失效。
- 每个派生指标保留公式版本、来源字段、全精度计算值及不确定度传播方法。

初始模板按“4个原始厚度→2个有符号刻蚀量→绝对值目标和比值目标”的顺序计算。原始厚度不能被派生值覆盖。

辅助字段可参与计算，却不自动进入模型输入。用户可选择直接测量作为响应，也可选择派生指标作为响应和目标。作为模型输入的派生字段只能依赖推荐前已知的信息。

实际观测的S、预测S及稳定化S_stable是不同记录，必须有不同来源和标签。预测新条件时，不能简单用abs(预测均值A/预测均值B)冒充比值的预测期望。

### 6.5 备注与布尔量

- 支持整组实验备注、每个输入值备注、每个测量/派生结果备注，以及模板字段说明。
- 文字备注默认不进入模型，不通过云端AI解析；需要生效的知识改填结构化先验。
- 输入允许True/False，例如某辅助步骤是否开启；输出允许True/False，例如是否出现某种现象。
- 导入支持显式映射“是/否、True/False、1/0”，不能把任意非空字符串当成True。
- 缺失布尔值独立保存，不能把“未测”当作False。
- 布尔输入使用离散编码；Boolean的变化算一个原始参数变化，不能套用小数位取整。
- 布尔输出如果只记录，不强迫建模；如果选择预测或优化，应使用Bernoulli/分类概率模型，输出P(True)及概率不确定度。
- 不能将普通GP回归的任意实数直接显示为事件概率，也不能对True/False套用“±1 nm”。单一类别样本不足时用明确的先验/初始状态，不伪报有充分证据的0%或100%。
- 本版需要实现并验证布尔结果所需的本地概率模型适配；它不是Ax数值目标接口的自动能力。

### 6.6 测量不确定度录入与传播

#### 6.6.1 “±1 nm”必须说明含义

| 输入含义 | 模型/计算处理 |
| --- | --- |
| 标准不确定度或1σ | 按该测量结果的标准差u处理 |
| 均值的标准误SEM | 直接作为均值观测的不确定度，不重复除以sqrt(n) |
| 95%区间或扩展不确定度 | 保存置信水平和覆盖因子；在对应分布假设下换算 |
| 允许误差界限±a | 保存为界限；仅在明确采用均匀分布时使用u=a/sqrt(3) |
| 上下误差不同 | 保存上下界及分布/区间含义，使用相应传播方法 |
| 只填±1而未选类型 | 保留记录，提示补充含义，不能自动宣称σ=1 |

例如50±1 nm，若1 nm表示1σ，则u=1 nm；若表示均匀误差的半宽，则u=1/sqrt(3) nm；若表示正态近似95%区间半宽，可约为1/1.96 nm。这里的换算依赖明确假设，不能通用套用。[NIST B类不确定度说明](https://physics.nist.gov/cuu/Uncertainty/typeb.html)

#### 6.6.2 差值和比值传播

对D=H0−H1：

$$
u_D^2=u_{H0}^2+u_{H1}^2-2\,\mathrm{Cov}(H0,H1)
$$

两次厚度测量独立、且各有1 nm标准不确定度时，刻蚀量标准不确定度为sqrt(2) nm，约1.414 nm。若两个±1 nm仅表示确定的误差界限，差值的最坏情况界限为±2 nm，不能与1.414 nm混用。

对于一般派生指标g(z)，一阶近似为：

$$
u_g^2 \approx \nabla g^\mathsf{T}\Sigma\nabla g
$$

协方差矩阵Sigma描述共享量测来源及相关性。相同原始字段被多个公式引用时必须保留依赖，不能把同一误差当成多个独立误差重复抽样。[NIST 不确定度合成](https://physics.nist.gov/cuu/Uncertainty/combination.html)

abs在零附近、比值的小分母和取整等非线性情况优先使用符合所选误差含义的蒙特卡洛或区间传播，不能无条件套线性公式。比值分布不稳定时遵守第2.5节，不强制输出一个有限标准差。

用户未提供相关性时，可以使用“独立假设”作为显式模型选项，并在结果中说明。已知共用仪器偏置或批次系统误差时必须保留相关性；重复测量并不自动消除系统误差。

#### 6.6.3 进入模型的接口

- 原始测量不确定度经传播得到A、B等基础响应观测的不确定度，送入相应噪声模型。
- Ax某接口要求SEM时传标准误；BoTorch的train_Yvar要求方差时传u²，禁止混用标准差与方差。
- 已提供的测量误差与额外实验重复性噪声需分开建模，不能把相同来源重复加两次。
- 未填误差表示未知，不表示零；采用模型估计噪声或已说明的设置。
- 标准固定噪声GP不自动给出新条件的测量噪声。未来实测预测区间应采用明确的未来量测误差设置，缺少时只给潜在响应区间并标注。
- 相关观测、非高斯误差及布尔结果需要对应适配；不能把完整协方差静默压成独立噪声并声称已经全部利用。
- 若不确定度附在可控输入本身，它属于输入位置误差；需额外的输入扰动积分/模型适配，不能塞进输出噪声参数。未支持时明确标记未计入预测。

BoTorch区分已提供的观测方差和需要推断的噪声；本项目需要负责上述数据转换与能力匹配。[BoTorch 噪声模型](https://botorch.org/docs/models)

### 6.7 指定位数取整：执行、数据变换和显示分开

| 设置对象 | 功能 | 对计算的影响 |
| --- | --- | --- |
| 推荐输入的执行精度 | 按指定位数或步长选择设备设置值 | 改变合法候选集合，量化后重新评分和校验 |
| 输入数值“尽量整齐”偏好 | 接近最优评分的候选中优先易设置的数值 | 明确设置容差/代价，不能随意事后改值 |
| 输入/输出的显示精度 | 表格和图中保留指定位数 | 默认只改变显示，数据库和拟合仍保留全精度 |
| 数值数据的建模变换 | 用户明确要求使用取整后的输入或结果 | 保留原值和变换值，记录规则及版本后重新拟合 |
| 派生目标中的round | 用户明确以取整指标作为目标 | 按真实取整函数计算，处理非光滑目标，不能只改显示 |

位数d可取整数：d=0表示整数，d=1表示0.1，d=2表示0.01，d=−1表示10，d=−2表示100。步长形式为10^(−d)，还应保存网格起点；步长和位数冲突时提示用户选择。

必须使用一致的十进制舍入规则，例如明确的“四舍五入、半数远离零”，在正负数、导出和界面中保持一致。不能依赖不同语言的默认round恰好一致。

执行精度用于候选时，先形成合法网格或对候选进行显式量化，再检查边界、固定项、变化数量、输入约束、去重并重算预测/评分。不能输出未重评估的取整数值。

对已有实验输入进行建模取整可能合并不同实际条件，必须保留原始条件和合并提示，不能误判为同一实验重复导入。显示SiN刻蚀量为0.0不代表全精度值为零，选择比必须使用对应的全精度原值或用户明确选择的取整目标。

## 7. 模型、关系先验与选点策略

### 7.1 默认GP，并提供真正的非GP选择

| 预设ID | 界面名称 | 本版要求 |
| --- | --- | --- |
| gp_rbf_v1 | 默认GP / RBF | 默认数值响应模型，支持噪声、不确定性及联合采样 |
| gp_matern25_v1 | GP / Matérn 2.5 | 另一种核假设；接口与上述一致 |
| bayesian_linear_v1 | 贝叶斯线性回归 | 非GP概率模型，作为可选择的基线；需要实现本地BoTorch适配 |
| bernoulli_response_v1 | 布尔响应概率模型 | 为选择预测的布尔输出提供概率及不确定性，不冒充数值GP |

贝叶斯线性回归至少覆盖数值、明确编码的类别/布尔输入、观测误差、多个基础数值响应，以及从基础响应计算派生目标。适配器需提供候选间联合分布或可用的联合样本，不能把预测标准差设为零凑接口。

布尔响应模型与所选数值模型可组成一个混合响应系统。具体选用的Bernoulli似然模型及近似推断方式在M2记录和测试，不能仅用False=0、True=1的普通回归替代。

每个预设登记模型类、核/特征、先验、噪声、采样、采集函数和优化设置。建立“字段类型×先验类型×目标变换×不确定度类型×选点方式”的能力表；不支持的组合说明具体原因，不能静默忽略用户知识或换算法。

软件启动时默认选择GP。没有数据时采用受约束的初始化策略，并标明尚未进入数据驱动的GP推荐阶段。

### 7.2 基础响应建模与派生目标预测

初始ICP模板优先联合组织两个有符号基础响应A、B的模型，再从同一组后验样本得到abs(A)、abs(B)和比值。不能将原始4个厚度、2个差值、比值全部当作互相独立的观测重复训练。

默认可采用两个条件独立的数值响应模型，但要明确这一跨输出独立假设，保留每个响应在不同候选点之间的相关性。有已知跨输出误差或响应关联时，选用支持相关性的适配，不能宣称独立模型已经利用该信息。

非线性目标的预测统计按“联合采样→逐样本计算公式→统计”得到：

- E[abs(A)]通常不等于abs(E[A])。
- E[abs(A/B)]通常不等于abs(E[A]/E[B])，且原始比值矩可能不存在。
- 比值和abs(B)共用B样本，不能为两个目标重新生成互不相关的B。
- 若预测剩余厚度并给出了本轮初始厚度误差，也应传播该误差，不把初始厚度视为无误差常数。

对于本版默认三目标，使用支持目标变换和可行性处理的多目标采集函数适配，优先验证qLogNoisyExpectedHypervolumeImprovement路线。单目标可采用qLogNoisyExpectedImprovement。与这些接口的实际连接、目标方向、参考点及有限性都需测试。[BoTorch 多目标方法](https://botorch.org/docs/multi_objective)

取整、分母截断和布尔比较可能导致目标不光滑。根据实际表达式选择兼容的采集函数优化器或合法候选池搜索，不能默认任何用户公式都能通过梯度优化。

### 7.3 本地训练、版本与切换

交付包包含模型实现及依赖，用户数据在本机拟合；不下载远程权重。不要求打包Ax全部模型，支持范围以注册表和实际验收为准。

数据、字段角色、公式、舍入变换、不确定度、先验或目标变更后，拟合缓存失效。切换模型保留原始实验和旧推荐，按新配置重拟合，保存模型及数据版本。原推荐当时的预测与新模型重预测分别保存。

跨平台数值结果采用合理容差校验；不要求每个随机候选逐位一致。高级模型适配依赖Ax/BoTorch扩展接口，应固定版本并进行升级回归。[Ax 模型扩展](https://ax.dev/docs/tutorials/modular_botorch/)

### 7.4 关系先验知识输入

本版提供结构化“输入字段—输出/派生响应—关系类型”表单，每条保存来源、文字说明、适用范围、置信强度、启用状态及版本。

| 关系类型 | 数学含义与实现要求 |
| --- | --- |
| 正比/负比 | 指在其余条件固定时接近y=a·x，a的符号明确；与一般单调关系分开 |
| 线性正/负影响 | 可带截距，记录系数估计或系数先验；与通过原点的正比分开 |
| 单调增加/减少 | 在指定范围对该输入的响应导数倾向为正/负，不要求是直线 |
| 无关/不依赖 | 该响应的模型不使用此输入；按输出分别排除特征 |
| 弱影响倾向 | 软偏好较小的作用强度，不宣称严格无关 |

具体规则：

1. **作用对象必须明确。** 对有符号A的先验不自动等同于对abs(A)的先验；对B的先验不自动等同于对abs(A/B)的先验。
2. **默认软先验。** 正比可用带符号系数的均值/趋势及残差模型表达；因为允许残差，不能声称得到严格比例或全域单调保证。
3. **单调信息需要实际建模。** 可采用导数虚拟观测等经过验证的专用实现。增大长度尺度本身不能约束导数正负。[GP单调信息研究](https://proceedings.mlr.press/v9/riihimaki10a.html)
4. **硬不依赖按响应隔离。** 若Cl2对某响应被设为无关，只从该响应的模型特征中移除，不能同时从其他响应的模型或物理条件记录中删除。
5. **严格关系需要专用实现。** 如用户选择严格y=a·x，则函数结构必须满足该关系；无法保证的严格设置应明确不可用，不能用软先验代替后显示“已严格执行”。
6. **先验不是额外真实测量。** 虚拟信息单独存储，不增加实际实验次数，不写入实测记录。
7. **范围与强度可配置。** 局部关系不能自动推广到整个搜索空间；先验与数据矛盾时显示诊断，由用户修改、禁用或保留，不暗中改写。
8. **公式必须一致。** 对派生指标输入的先验需通过依赖关系处理或专门的联合约束适配，不能破坏A、B、比值的定义。
9. **选择非GP模型时检查兼容性。** 相应模型没有实现该先验时阻止误用，并说明原因；不能只保留一条备注就称“先验已参与计算”。

本版必须完成正比/线性软先验、单调软信息、按输出不依赖的输入与建模验收；更强的全域硬形状保证不应冒充已具备的能力。初始模板不预置“哪种气体对哪种刻蚀量一定正相关”等未经用户提供的关系。

“初始厚度仅作为辅助测量、不作为刻蚀量模型输入”是字段/场景假设；它不禁止初始厚度参与差值及误差传播，不是令差值公式对初始厚度的导数为零。

## 8. 推荐、对照与趋势解释流程

1. 读取模板、字段角色、公式依赖、量测不确定度、关系先验、模型及目标配置。
2. 根据原始测量重算有效派生响应，标记小分母、缺失数据和噪声口径问题。
3. 校验比值优化策略、模型兼容性及模板限制，生成计算版本。
4. 读取本轮n、复测配额、基准条件、允许变化的输入和精度规则。
5. 构造合法搜索子空间；初始化、GP和非GP推荐都必须遵守同一边界与变动规则。
6. 拟合基础响应模型，保留已提供的不确定度与有效先验。
7. 对基础响应联合预测，从样本计算派生目标、目标折中、可行性和评分。
8. 形成批量建议；执行必要的合法量化、重新评分、去重和配额检查。
9. 给每组建议生成实际执行值、与基准的差异、预期结果、预测区间及有效性标记。
10. 用户勾选时生成条件趋势图，明确固定参数、数据支持区域和限制。
11. 原子保存整批建议及相应版本；实验完成后回填真实条件与测量，再继续循环。

### 8.1 数量、复测与不足额返回

- n表示本轮计划执行的总实验数；新条件、基准复测、其他复测及新安排的对照都占用这个总数。
- 待做和进行中的条件纳入推荐，避免重复；明确指定的复测例外。
- “预计返回n组”不保证任意限制下都能返回n组。候选不足或初始化受限时显示实际数量和原因。
- 不足额时不能偷偷改变冻结变量、扩大模板范围、解除精度或补随机点。
- 批量策略权衡改善机会与不确定性，界面不把所有未知区域点称为“更优条件”。

### 8.2 实际条件、备注与回填

保留建议条件和实际执行条件；实际条件改变时按实际条件建模，保留与原建议的关联。用户可对整组及每个输入/测量值添加文字备注。

缺失、失败、取消和分母无法分辨分别记录。比值不可用不等于A、B不可用，也不等于整个实验失败。结果修订触发公式重算、误差重算和模型失效。

### 8.3 恢复与重建

程序可以从有效业务记录重建Ax状态，但必须保留编号映射、待做计划、基准、选择的变量、精度、先验、公式、目标及随机设置。

没有新数据而已有待做批次时，重启显示既有批次，不自动重算。重新计算是明确动作；旧批次保留，用于追溯当时的决策。

### 8.4 基于已有条件的单变量或双变量变动

用户可选择一条已有实验的实际条件作为基准，或输入一套完整合法的基准条件；只比较可控输入，辅助测量和备注不计入变化数量。

| 模式 | 规则 |
| --- | --- |
| 全范围探索 | 在模板边界及全部约束内改变可控输入 |
| 单变量变动 | 每个新条件相对基准恰好改变1个原始可控参数；其他全部固定 |
| 双变量变动 | 默认每点最多改变2个，用户可选“恰好2个”；其他固定 |
| 指定变量 | 用户点选可变化的1个或2个变量 |
| 自动选择变量 | 在符合数量限制的变量子集中搜索，输出每点实际变化的变量 |
| 交叉对比布局 | 可请求“基准、仅A变、仅B变、A与B同时变”的组合，对比交互 |

变化按原始参数计数：一个布尔变化算一个，一种类别切换算一个；one-hot编码列数不能用于计数。连续值比较使用与单位/执行精度一致的明确容差。

先限制搜索子空间，再优化评分；不能先做8维自由推荐，最后把其他6维改回基准而不重新评价。执行量化后再次检查变化数量，避免“变化被取整抹掉”或额外变量变化。

基准不在当前模板范围内时提示选择合法基准，不偷偷移动它。每个候选保存baseline_id、变化变量、原值、新值及差值。

交叉对比模式需明确基准是否重新测量；新安排的基准和对照都占n的配额。双变量自由搜索不自动等于完整二维网格或四组合设计；用户请求完整布局却配额不足或组合非法时明确提示。

### 8.5 推荐时可选的趋势图

| 图形 | 展示内容 |
| --- | --- |
| 一维条件曲线 | 某输入变化时基础响应/派生目标的预测，带不确定性带 |
| 二维响应面/等高线 | 两个输入与结果关系，叠加推荐点、基准和合法区域 |
| 基准对照图 | 原条件、新条件、实际变化项及预测变化范围 |
| 三目标折中图 | abs(A)、abs(B)、原始/稳定化比值的Pareto关系 |
| 历史进展图 | 实测结果、预测与实测对照、误差棒和待做位置 |

图中必须标注：

- 横纵轴、单位、指标公式或简称。
- 当前固定的其余条件；单/双变量模式默认以所选基准固定。
- 推荐点编号、基准、相关实测点及模板边界。
- 区间是潜在响应可信区间、未来测量预测区间，还是数据误差棒。
- 分母不稳定、数据稀疏和不可行区域，不把它们画成确定的最佳区。

只把符合固定条件的实测点作为该条件切片的直接对照。其他实验可以投影展示，但必须标明其余条件不同，不能让实验人员误以为都测在同一条曲线上。

趋势图用于理解和核对模型，不证明因果或机台安全。图形计算、字体和PNG/SVG导出全部本地完成；图形可关闭，界面偏好保存到项目。图形采用最终执行值和同一版本的模型，不能显示取整前另一组条件的预测。

### 8.6 每组推荐的输出内容

- 8项执行参数及单位、所用精度和备注位置。
- 基准、变化变量、安排类型、批次和实验编号。
- A、B两个有符号刻蚀量的预测均值与区间。
- abs(A)、abs(B)及当前比值目标的预测统计；非高斯或比值不稳定时给出分位数、条件或不可计算说明。
- 对可定义且有限的目标给出预测期望，不把中位数标成均值；不存在可靠有限均值/方差时不编造数值。
- 输出限制满足情况、多目标折中和量测不确定度使用情况。
- 对布尔响应给出事件概率及适当的不确定性。
- 可选趋势图、数据/公式/先验/模型版本。

未来测量区间只有在未来噪声设置可用时才给出；否则说明当前区间只表示潜在响应的不确定性。仍处于初始化阶段且无法给出数据驱动预测时，明确显示“预测尚不可用”，不能用伪造期望补齐表格。

## 10. 本地存储与一致性设计

### 10.1 数据位置

- 程序目录保存可执行文件、依赖和内置只读资源。
- 默认用户数据根目录采用 %LOCALAPPDATA%\ExperimentPlanner，或公司指定的本地非同步目录。
- 每个项目使用独立目录和 project.sqlite。
- 不把真实数据放在代码仓库、安装程序目录或默认云同步目录中。
- Linux开发环境只使用模拟项目目录，通过同一存储接口调用。

### 10.2 数据库建议内容

| 表/记录 | 内容 |
| --- | --- |
| project | 元数据、schema v2模板快照、公式/先验/精度/目标版本及数据版本 |
| experiments | 实验编号、建议与实际条件、状态 |
| observations | 原始全精度测量、字段角色、数值/布尔类型、不确定度及逐字段备注 |
| derived_values | 计算值、公式版本、来源、传播误差和比值有效状态 |
| knowledge_priors | 输入—响应关系、范围、强度、来源和启用状态 |
| uncertainty_groups | 共享误差来源、相关性假设及支持的协方差信息 |
| batches | n、基准、允许变化变量、变化数量、精度、复测及不足额原因 |
| engine_snapshots | Ax序列化状态、软件及预设版本、对应数据版本 |
| prediction_snapshots | 基础/派生预测、均值或分位数口径、误差来源和对应图形配置 |
| change_log | 用户修改、状态变化和版本迁移记录 |

SQLite中的有效业务记录作为事实来源。Ax状态可以作为绑定数据版本的快照保存到同一数据库，避免数据库和独立JSON文件更新不同步。

计算在写事务之外执行；提交结果前再次确认数据版本。如果用户在计算期间修订了数据，旧任务结果不能覆盖新状态。

备份使用一致性备份接口或在明确关闭数据库后进行，不能简单复制正在写入的数据库主文件而遗漏相关状态。[SQLite 在线备份说明](https://www.sqlite.org/backup.html)

### 10.3 离线升级

升级前自动创建一致性备份，记录数据库结构版本。新程序不得覆盖用户数据目录。旧Ax快照不能恢复时，可以从有效业务记录重建并校验；不能把读取失败解释为“空项目”。

发布包保留迁移说明和回退方法。数据已迁移后，回退应恢复对应备份，不能直接让旧程序修改不兼容的新数据库。

## 12. Windows离线运行与数据保护

### 12.1 应用设计要求

- 不含运行时外部API、自动升级、云端统计和远程错误上报。
- 模型、字体、图标、图表和帮助内容所需资源随包交付。
- 不使用依赖在线CDN或远程网页的图表和帮助组件。
- 正式运行不执行pip安装，不下载模型或缺失资源。
- 应用日志默认记录状态、错误码和版本，不自动输出完整实验数据。
- 用户可主动导出数据；软件不后台上传导出文件。
- 普通运行不要求管理员权限。部署网络规则可能需要管理员或公司IT执行。

这是一组产品和部署要求，不以“Ax本身能本地运行”代替整个应用的离线验证。

### 12.2 Windows出网限制

对实际发布的EXE建立出站阻断规则；如存在独立计算子程序，也必须覆盖。目录包使用固定位置，升级或移动后需核对规则是否仍覆盖实际可执行文件。

以下PowerShell仅用于管理员部署示例。路径是占位示例，必须替换为实际安装路径；本文没有生成该EXE或在公司电脑执行命令。

~~~powershell
$plannerExe = 'C:\CompanyTools\ExperimentPlanner\ExperimentPlanner.exe'
New-NetFirewallRule -DisplayName 'ExperimentPlanner Offline Outbound' -Direction Outbound -Program $plannerExe -Action Block -Profile Any
~~~

微软的防火墙接口支持按程序建立出站阻断规则。验收还需确认实际生效的策略、子进程和更新后的路径，不能只检查命令是否执行成功。[Microsoft New-NetFirewallRule](https://learn.microsoft.com/en-us/powershell/module/netsecurity/new-netfirewallrule?view=windowsserver2025-ps)

### 12.3 数据边界

- 公司Windows上的实际实验文件、数据库、Ax状态、日志及备份均按实验数据管理。
- 云端开发仅使用模拟数据；必要的代码本身也应属于允许外发的内容。
- 真实数据放在云端开发工具无法读取的位置，不能仅依赖.gitignore。
- .gitignore帮助防止误提交，但不阻止软件读取文件、系统同步或备份上传。
- 应用出网限制不控制其他同步软件和系统服务；数据目录需配合公司现有文件与网络管理。
- 离线只说明数据传输方式，不自动表示数据库已经加密；如有本地加密要求，另列为部署配置。
