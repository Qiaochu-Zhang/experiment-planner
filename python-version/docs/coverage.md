# V1.1 功能对照与已知限制

本 Python 版改变启动和交付方式，实验含义以 [项目说明](project_spec.md) 为准。F01–F25 仍是需求，以下表格说明实际代码，而非重新定义或缩减需求。

| 需求 | 本版代码 / 可用入口 | 仍有的限制 |
| --- | --- | --- |
| F01 项目管理 | SQLite 独立项目；GUI / CLI 创建、打开、关闭 | 未验证所有目标平台 |
| F02 模板管理 | 内置模板、JSON 导入导出、复制、GUI 编辑、版本与项目快照 | 使用 JSON 编辑器；结构改变需新项目，未实现迁移 |
| F03 字段类型 | 数值、离散、类别、固定值、布尔和文字备注 | 复杂配置通过模板 JSON |
| F04 单/多目标 | Pareto、单目标、显式权重与尺度、绝对值/距离目标 | 配置通过模板 JSON；非任意目标组合均已验收 |
| F05 限制 | 范围、执行网格、线性输入约束、基础响应阈值约束 | 任意组合约束、派生输出约束未适配 |
| F06 导入 | CSV/XLSX、GUI 映射/预览、单位/类型检查、去重 | 所有不确定度元数据尚不能完整表格往返 |
| F07 回填 | 实际条件、部分结果、失败/取消、测量和备注、更正日志 | — |
| F08 推荐 | n 组、初始化、待做、全范围/单变量/最多或恰好双变量、变量子集、不足额原因 | 有限候选池，不承诺全局最优 |
| F09 复测与对照 | 复测编号、基准/单 A/单 B/AB 交叉布局均计入 n | 尚无专用对照结果图 |
| F10 模型 | GP-RBF、GP-Matérn 2.5、贝叶斯线性 | Ax 管理实验，应用层直接调用 BoTorch，非完整 Ax Modular 适配 |
| F11 预测 | 每批保存后验统计；GUI / CLI 任意合法条件预测 | 潜在响应区间；未来量测噪声、任意额外输入未适配 |
| F12 趋势 | 本地一维曲线、二维着色切片，固定条件/版本、PNG 保存及 GUI 显示 | 非交互响应面；无 Pareto/进展/专用对照图；尚未自动生成批次图 |
| F13 恢复 | SQLite 保存数据、模板、批次、待做和版本；按业务数据重新拟合 | 不保证跨依赖版本模型快照兼容 |
| F14 备份 | SQLite 一致性备份，打开备份恢复 | 跨 Windows 主机未实际验收 |
| F15 离线 | 安装好 Python 与依赖后本地计算，无运行时模型/字体下载 | 用户要求 Python 环境，EXE/无 Python 启动不适用；出网阻断/离线干净机未验收 |
| F16 先验 | 响应级无关、线性/正比软先验；线性模型单调/弱影响信息 | GP 导数、局部范围、严格形状、布尔系数先验未适配 |
| F17 精度 | 执行精度与显示精度分离；十进制半数远离零 | 建模取整、整齐数值软偏好未实现 |
| F18 不确定度 | 差值传播、共享来源/协方差、联合采样、已知噪声接口 | 一般公式区间/非对称分布、混合已知未知噪声、跨实验相关似然未完成 |
| F19 派生公式 | 白名单解析、依赖图、单位/循环检查、派生目标 | 预测依赖必须可由模型基础响应得到 |
| F20 字段角色 | 独立角色配置、禁止事后测量输入泄漏 | 额外实验前测量/派生输入未接入引擎；剩余厚度条件化预测未完成 |
| F21 备注 | 整组、参数、测量备注与 field_notes 保存 | 派生指标无专用备注表单 |
| F22 布尔 | True/False/缺失区分、Bernoulli-logit 概率后验 | 模型按布尔响应自动组合，非任意 GP 数值当概率 |
| F23 ICP | 8 个原范围输入、4 项厚度、3 项原方向目标 | 没有凭空添加机台约束 |
| F24 非线性 | 同一基础后验样本计算绝对值和比值，保存分母策略 | 基础响应默认独立，未适配跨响应协方差 |
| F25 追溯 | 更正、模板版本、依赖重算、旧批次保留、过期任务禁止提交 | 数据库结构升级迁移未实现 |

原仓库的 [模型能力报告](baseline_model_capabilities.md) 和 [原验收报告](baseline_acceptance_results.md) 为开发背景，不能作为 Python 版新增功能的测试证据。本版证据见 [validation.md](validation.md)。

A01 的“无 Python 启动发布包”由本次用户请求改为在 Python 环境启动。A19–A24、A50 中的目标平台、离线监测、非编程人员人工操作、升级/跨机恢复仍需实际验证。不能由 Ubuntu 测试推断全部需求完成。
