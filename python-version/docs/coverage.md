# 0.3.0 功能与已知边界

| 功能 | 当前实现 |
| --- | --- |
| Python 环境 | 标准 CPython 3.12、3.13；实际测试见 [验证记录](validation.md)。 |
| 常用工作台 | 精度、先验、目标固定入口，导入 CSV / Excel 默认显示；旧配置一次性补充入口，之后尊重用户取消。 |
| 可视化模板 | 从空白、当前项目或本地文件开始；字段表单增删改名并同步引用，完整属性树编辑其他设置；空项目支持结构替换，已有记录可另存修改或直接新建项目。 |
| 帮助 | 离线文档按钮，变量和表头悬停简述及蓝色可点击详细链接；离开变量和弹窗约 1 秒关闭，移入弹窗可以继续点击。 |
| 中文 | 主要界面、输入错误、后台警告摘要、预测和批次说明、趋势图；技术详情保留原始诊断。 |
| 目标 | 新默认 A 最大、B 接近零、A/B 最大；单目标、Pareto、显式加权；旧绝对值目标兼容。 |
| 探索 | 强度调节常规评分，专门名额明确分配，保存评分与类型，约束/去重/待做集合共同生效。 |
| 复测 | 同条件独立记录、不同测量、独立 Ax trial；不先自动平均。 |
| 自定义单位 | 可编辑单位名称，同名自定义单位视为同量纲；不猜测不同名称间的比例或复合单位关系。 |
| 取整 | 显示与执行精度分离，执行 digits/step/origin；float 实际记录保留执行偏差。 |
| 数据 | SQLite 版本、回填、更正、CSV/XLSX 映射预览；前 ceil(输入数×30%) 项全空时停止，保留此前有效行，0/否有效；去重及完整备份。 |
| 删除 | 鼠标单选/多选删除并确认，整批原子提交；排除当前模型/推荐/导出，保留删除审计、旧批次及稳定编号；支持删除后重新导入。 |
| 模型 | GP/RBF、GP/Matérn、贝叶斯线性；基础响应与派生后验样本处理。 |

仍有以下边界：

- 详细说明是通用静态文件，不收录具体工艺字段；导入按模板前 30% 输入全空时停止，混合误差限制仍保留，见 [回答](../回答.md)。
- 删除当前没有一键撤销；首次删除升级数据库版本为 2，旧版本不能再打开该项目，0.2.1 可读取新旧两种数据库。完整备份保留已删除记录和审计，普通导出只含未删除实验。
- 初始厚度等额外实验前测量及派生模型输入尚未适配；跨响应/跨实验相关噪声、已知与未知噪声混合、输入位置误差、建模取整尚未接入。
- 局部范围先验、严格比例、严格全域形状约束未实现；单调和弱影响仅线性模型支持。
- 输入组合约束支持明确的线性约束，输出约束支持基础响应阈值，非任意派生约束。
- 已有记录且字段结构、单位、范围、离散值或固定值不兼容时，需另存模板或新建项目；程序保留修改并提供直接操作，不自动改写旧实验。空项目可直接保存新结构。
- 比值分母阈值由用户按测量口径设置；原始比值不声明有限均值。带符号稳定化的零处约定为 +epsilon。
- 候选池是有限搜索，不保证全局最优或遍历所有组合。探索策略已作合成与行为验证，不等于真实机台效率已经证实。
- 原始机器字段名、公式和技术诊断保留英文标识；不修改数据协议。高级误差类型等在属性树使用枚举文本填写。
- 本轮 Windows/macOS 人工操作和自由线程 Python 不在实际验证声明内。历史验收材料不作为本版本通过证据。
