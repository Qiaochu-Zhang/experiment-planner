# 0.4.2 功能与已知边界

| 功能 | 当前实现 |

| 常用工作台 | 精度、先验、目标固定入口，导入 CSV / Excel 默认显示；旧配置一次性补充入口，之后尊重用户取消。 |

| 窗口布局 | 常用工作台与预测页可整体滚动，条件区域单独滚动；长字段名称换行，模板字段表行高随字体变化。覆盖普通、小窗口、最大化、全屏、恢复及放大字体，证据见验证记录。 |
| 中文 | 主要界面、输入错误、后台警告摘要、预测和批次说明、趋势图；技术详情保留原始诊断。 |

| 条件重要度 | 历史条件上的模型置换敏感度，逐响应归一化及等权综合，支持类别分组和约束过滤；无法识别的条件不强行打分，后台可取消、Excel/CSV 可导出。不是因果分析或独立验证。 |

| 输入不确定度 | 默认关闭，可按连续数值输入单独选择正态 1σ 或均匀半宽；传播至预测、趋势图和推荐的平均目标，保留输入确定时的对照。配置可保存、撤销、JSON/Excel 模板交换，预测导出同时保留两种口径。 |

仍有以下边界：

- 可信度是用户指定的相对建模假设，不是准确率。近期权重不是时变模型，缺失日期不衰减，旧记录使用保存时间近似；权重下限 1e-6，历史噪声按权重缩放，不对未给定的未来测量噪声作保证。重要度只描述模型在历史取值范围内的敏感度，默认 8 次置换、最多分析 256 条条件，受相关性、约束、先验、样本与模型影响；结果仅在窗口保留。
- 详细说明是通用静态文件，不收录具体工艺字段；导入按模板前 30% 输入全空时停止，混合误差限制仍保留，见 [回答](../回答.md)。
- 常见已保存修改（含删除）可撤销/重做；关闭项目或保存推荐批次清空会话历史，外部文件和批次不纳入撤销；首次删除升级数据库版本为 2，旧版本不能再打开该项目，0.2.1 可读取新旧两种数据库。完整备份保留已删除记录和审计，普通导出只含未删除实验。
- 初始厚度等额外实验前测量及派生模型输入尚未适配；跨响应/跨实验相关噪声、已知与未知噪声混合、历史输入位置误差训练、建模取整尚未接入。
- 输入不确定度当前仅描述未来执行波动：支持有上下限、参与建模的连续输入；整数、离散、固定值、类别、文字及排除建模的输入暂不支持。总开关关闭时保留原算法；不提供历史逐条误差覆盖、输入相关系数或自动拟合误差。假设原始扰动独立且实际执行在模板范围/线性约束内，使用条件分布而非端点裁剪；若范围仅限制推荐设定而实际会越界，此假设不适用。线性约束中的字段必须参与数值模型，约束过紧无法采样时明确报错。
- 推荐使用扰动后平均有向目标；输出约束要求有限输入采样点全部通过，仍由后验采样评估，不是全范围或指定置信水平的可行保证。8/16/32 个输入采样点默认 16，精度与运行时间取舍明确，不能据此宣称真实机台效果已验证。
- 局部范围先验、严格比例、严格全域形状约束未实现；单调和弱影响仅线性模型支持。
- 输入组合约束支持明确的线性约束，输出约束支持基础响应阈值，非任意派生约束。
- 已有记录且字段结构、单位、范围、离散值或固定值不兼容时，需另存模板或新建项目；程序保留修改并提供直接操作，不自动改写旧实验。空项目可直接保存新结构。
- 比值分母阈值由用户按测量口径设置；原始比值不声明有限均值。带符号稳定化的零处约定为 +epsilon。
- 候选池是有限搜索，不保证全局最优或遍历所有组合。探索策略已作合成与行为验证，不等于真实机台效率已经证实。
- 原始机器字段名、公式和技术诊断保留英文标识；不修改数据协议。高级误差类型等在属性树使用枚举文本填写。
- Excel 的提示和数据验证可被复制粘贴绕过，最终以软件校验为准；`modeling.base_responses` 和 `context_assumptions` 是说明性元数据，实际模型读字段角色与输入设置。修改模板设置的属性路径后，原行附带的 Excel 下拉仍对应导出时的属性，需自行核对。
- 本轮 Windows/macOS 人工操作和自由线程 Python 不在实际验证声明内。历史验收材料不作为本版本通过证据。
