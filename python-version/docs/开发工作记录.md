本次采用直接维护中文文档的方式：已有中文文件继续作为中文版本，英文说明补译为中文，不另建内容重复、容易失去同步的文档副本。代码、命令、字段名、依赖名称和文件路径保留原文，避免翻译后不能执行或无法查找。
