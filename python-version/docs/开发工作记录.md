## 七、输入框深色背景修复

修复日期：2026-09-16。

- 用户反馈输入框为暗色，虽不影响输入，但阅读不方便。检查发现原界面仅指定主窗口和表格的浅色背景，其他控件继承系统配色，可能与系统深色主题混用。
- 原工程和 `python-version` 同步增加统一浅色主题：使用 Fusion 控件样式，明确设置白色输入背景、深色文字、提示文字、选中高亮、下拉列表、工具提示及禁用状态的配色。
- 主题在主窗口初始化时应用，覆盖实验录入弹窗以及 Python 版模板、导入映射和预测等页面。
- 验证结果：原工程已有界面测试 1 项通过；Python 版已有界面测试 2 项通过。另在离屏环境模拟深色系统配色，检查输入控件背景和文字颜色，并查看录入弹窗截图，显示正常。
- 本次只调整界面样式，没有修改实验数据、公式、模型或推荐逻辑；没有重新运行完整模型测试，也未将离屏结果视为 Windows 实机验收。
- 使用 Git 获取更新后，需要关闭并重新启动应用，新的配色才会生效。
