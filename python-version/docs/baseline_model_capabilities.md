# 0.1 模型能力与适配范围

此表说明实际实现，不缩减 V1.1 必须完成的功能。未适配组合在引擎入口明确拒绝。

| 能力 | GP-RBF / GP-Matérn 2.5 | 贝叶斯线性 | 布尔响应 |
| --- | --- | --- | --- |
| 概率实现 | SingleTaskGP，RBF / Matérn ν=2.5 | 高斯系数后验，BoTorch Model 适配 | Bernoulli-logit，Laplace 系数后验 |
| 候选间相关性 | 保留 | 共享系数联合后验 | 共享 logit 系数样本 |
| 多个基础响应 | 按响应独立组织 | 按响应独立组织 | 与数值模型组合 |
| 类别/布尔输入 | 显式 one-hot / 0,1 | 同左 | 同左 |
| 全部已知标准误差 | train_Yvar=u² | 方差加权似然 | 不适用数值误差 |
| 全部未知误差 | GP 估计噪声 | 明示经验残差估计及少样本限制 | Bernoulli 似然 |
| 混合已知/未知噪声 | 未实现，拒绝 | 未实现，拒绝 | 不适用 |
| 按响应不依赖输入 | 从该响应排除特征 | 同左 | 同左 |
| 全域线性/正比软先验 | 系数趋势均值 + GP 残差，强度影响均值贡献 | 高斯系数先验；正比同时作用截距 | 未适配 |
| 全域单调/弱影响软信息 | 导数虚拟观测未实现，拒绝 | 线性系数有符号/零均值先验，置信强度控制精度 | 未适配 |
| 局部先验、严格形状 | 未适配，拒绝 | 未适配，拒绝 | 未适配，拒绝 |
| 联合非线性目标 | 共用基础样本 | 共用基础样本 | 概率样本参与公式 |
| Pareto 推荐 | qLogNEHVI，合法候选池逐次选取 | 同左 | 混合数值/布尔推荐已验证 |
| 单目标/加权 | qLogNEI（真实调用已验证） | 同左 | 同左 |

模型数据仅取完成/部分结果的有效响应，按实际条件训练；失败/取消记录不填零。一个响应缺失不会删除另一个响应已有的观测，但本轮所有目标基础响应不足两条时整轮进入初始化。

初始化使用受限有限候选池。模型驱动阶段在同一池中的最终执行值上评分，待做条件进入采集函数；不承诺全局最优。采样数、随机种子、数据版本和参考点存入批次。

默认独立响应不利用跨输出/跨实验协方差。误差传播模块可保留同一原始来源与用户协方差，但相关观测到模型的完整适配仍待实现。不能将已保存相关性称为已用于独立似然。

原始比值只给样本分位数；稳定化比值另存 `selectivity_stable`。预测原始比值、实测原始比值、稳定化指标来源明确区分。

## 框架边界

当前 Ax 负责实验、trial、基础响应数据与业务编号映射；独立应用桥接层直接调用 BoTorch 模型和 qLog 采集函数。尚未注册为 Ax Modular BoTorch 自定义 Generator/Adapter，这是 M0/M2b 的剩余集成项，不能称为完整 Ax 原生优化策略。

BoTorch 0.18.1 的可选 qLog C++ 扩展默认尝试运行时编译；本项目版本门控适配显式选择其自带 Python 路径，避免正式运行依赖编译器。升级版本必须重新检查适配。

接口依据：[BoTorch 模型与噪声](https://botorch.org/docs/models)、[多目标采集函数](https://botorch.org/docs/multi_objective)、[Ax Modular BoTorch](https://ax.dev/docs/tutorials/modular_botorch/)。实际调用以已安装版本源码和集成测试为准。
