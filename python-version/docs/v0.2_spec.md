# 0.2 算法与界面规范

本文保留 0.2 算法规范；后续通用模板编辑与导入行为以 [通用操作说明](../src/experiment_planner/resources/help/使用说明.md) 和 [版本记录](../版本改动记录.md) 为准。

本文件取代旧项目说明中与本轮变更冲突的默认目标、探索策略和界面要求；其他科学计算限制保留。

## 目标及旧项目

新内置模板版本 2：A 最大化、|B| 最小化、A/B 最大化。原始比值使用 `selectivity`。旧项目快照仍可有 `selectivity_abs=abs(A/B)`，程序根据比值公式识别绝对值或带符号口径。

统一的观察值和张量函数处理稳定化：带符号形式为 `A / (sign(B) * max(abs(B),epsilon))`，零处 sign 约定为 +1；旧绝对值模板仍为 `abs(A)/max(abs(B),epsilon)`。原始比值字段单独保留。有效区域模式使用 `abs(B) >= epsilon` 的样本可行约束；展示原始无条件比值分位数，评分内部作有限保护。

## 探索设置

`BatchRequest.exploration_strength`：有限数值 0–100，默认 0。`exploration_count`：非负整数，默认 0，不得超过 n−len(repeat_ids)。交叉布局不允许非零探索名额。

数据足够时，对有向目标变换后的后验样本定义：

- `s_j = max(std(历史条件目标 j 的后验样本), 1e-8)`；64 个历史样本参与尺度估计。
- `u(x) = mean_j(std(目标 j 在 x 的后验样本) / s_j)`；128 个候选样本。
- `p(x)`：满足所有已配置输出约束的候选样本比例。
- 常规位置评分：`log_acquisition(x) + exploration_strength * p(x) * log1p(u(x))`。
- 专门探索评分：`p(x) * log1p(u(x)) * d(x)`。无待做条件时 `d=1`；否则 d 为编码输入到最近待做点的欧氏距离 / sqrt(编码维数)，截断至 [0,1]。

先选择专门探索名额，每次加入待做集合；再选择常规位置，并使用更新后的 BoTorch X_pending。多目标基础评分为 qLogNEHVI，单目标/加权为 qLogNEI。强度 0、名额 0 时保持原选择逻辑，不额外做探索样本估计。

目标尺度由当前模型和数据估计，不是物理容差。该策略明确偏向可行且不确定的候选，但不保证单次实验更好，也不保证所有选择均比旧策略更有效。输出约束是概率性评价，输入约束是硬校验。

初始化时没有可用模型：预留名额标记 exploration，其余标记 initialization，全部由合法初始化候选产生。名额不足返回 shortfall，不放宽范围、不使用重复条件补足。

批次保存：请求两个参数、`exploration.algorithm`、后验样本数、目标尺度和实际探索数；候选保存 arrangement、log_acquisition、selection_score、normalized_uncertainty、selection_feasibility。零强度且无专门探索时，探索统计未计算，后两项为默认占位，不应当作正式预测；实际预测可行概率以 prediction 为准。

## 桌面

主导航：常用功能、更多功能。常用页固定包含精度、先验、目标；可自定义其余入口。偏好保存在本机 QSettings，不改实验数据。

精度表、先验表、目标勾选与优化方式、交叉布局下拉框、预测条件表单、导入列对应表支持鼠标与键盘输入。完整模板用有类型的树形编辑器编辑，保留未知属性，支持属性组、列表增删和空值。

推荐默认设置保存至模板 batch_defaults，默认模型保存至 optimization.default_model_preset，打开项目时恢复。模板更新继续受版本与结构迁移限制。新模板由界面保存为 JSON，再从模板新建项目。原始 JSON 只在可选技术详情中展示。

帮助文件位于 `src/experiment_planner/resources/help/使用说明.md`，随 wheel 安装。变量名、表头和设置的悬停弹层提供简述及蓝色可点击链接，帮助对话框定位对应主题，并可打开具体文件。自定义字段优先显示模板备注。

错误与主要警告用中文；第三方原始诊断保留在技术详情。绘图标题、图例和坐标名称使用中文及内置中文字体。
