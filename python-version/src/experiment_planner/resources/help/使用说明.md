# 实验规划助手 0.2.1 · 变量与操作说明

更新日期：2026-09-29。此文件随程序安装，可离线阅读。

## 使用说明

先创建或打开项目；录入实验后设置目标和分母策略，再推荐下一批。

支持标准 CPython 3.12、3.13（不包含自由线程构建）。在常用工作台新建项目后，先录入实验，再设置精度、先验与目标。下一批实验页面设置推荐参数，计算后会自动保存为待做记录。实验完成后选择对应记录回填。

常用工作台固定提供“推荐工艺精度”“先验关系定义”“实验优化目标”。“导入 CSV / Excel”默认加入常用页，旧配置升级时添加一次；以后仍可取消勾选。其他常用按钮可以勾选定制，重启后保留。更多功能页提供完整实验表、推荐、项目与模板、预测与趋势图。

帮助不依赖网络。悬停在字段名称、表头或设置上，弹出的简要说明有蓝色“详细说明”链接；点链接可跳到本文相应条目。“打开说明文件”可用本机软件打开这份 Markdown。

鼠标离开原变量与帮助弹窗后约 1 秒关闭；返回原变量或移入弹窗会取消关闭计时，可以继续点击蓝色链接。本说明是随程序提供的静态文件，修改项目模板不会自动改写这里的文字。

## 删除实验记录

在“查看与回填实验”中，单击选一行，Ctrl 多选不连续行，Shift 连选或拖动选择多行，点击“删除选中实验”，核对编号后确认；取消则不做修改。

删除后从当前实验表、训练、推荐和普通 CSV / Excel / JSON 导出中移除，删除过的条件不再占用历史候选去重位置（若还有同条件的未删除记录，仍会排除）。原始数据保留在删除审计中，既有批次及预测不变，内部编号不复用；同一导入记录可以重新导入为新编号。完整数据库备份保留审计，目前没有一键撤销删除。

已保存的推荐默认设置会清理被删除的基准/复测编号；需要基准的模式请重选基准。删除会更新项目数据版本，基于删除前数据算出的批次不能写回，需要重新计算。

0.2.1 支持旧数据库。首次删除时数据库版本变为 2，旧版程序会拒绝打开，防止误把删除记录用于训练；该项目此后需用支持删除标记的版本打开。数据库版本与模板版本不同。

## 推荐工艺精度 digits

digits=0 表示整数，1 表示一位小数，−1 表示十位；执行精度和显示精度不同。

执行模式可选“不限制”“小数位数”“指定步长”。小数位数 0 为整数，1 为 0.1 网格，−1 为 10 的网格；起点默认 0。指定步长支持 0.5、5 等设备粒度。表单会同时设置 mode 和 digits，不需要编辑 JSON。

显示小数位数只影响记录表格。实际回填的 float 条件可保留偏差，例如建议 20、实际 20.3；模型使用实际值。int 类型输入则要求整数，不自动四舍五入。数据类型可在“全部属性”设置，已有有数据项目的结构变更需从新模板创建新项目。建模取整 modeling_rounding 尚未支持。

点击“应用到所有工艺参数”可以批量设置 digits，随后仍可逐行调整。范围、固定值和其他约束仍然有效。

## 先验关系

为某个输入和基础响应指定已有经验，选择关系、系数、强度并填写来源。

点击“添加先验”，依次选择输入、基础响应和关系，填写系数、强度和来源，再保存。可以停用或删除某条关系。

无关 independent：从该响应模型中移除该输入，不会冻结实际工艺条件。线性 linear / 比例 proportional：在线性模型中使用系数先验，在 GP 中叠加软线性趋势。单调 monotonic / 弱影响 weak：目前仅支持贝叶斯线性模型；不是严格全域形状保证。正负系数表示方向，单位为响应单位 / 输入单位；例如 nm/s。强度必须为正数，不是置信度百分比。

默认工艺先验为空。普通备注不是先验。局部范围、严格比例和跨输出相关噪声尚未适配，界面保存会检查所选模型的能力。请在目标页选择匹配的默认模型。

## 实验优化目标

可选择多个目标；新版默认最大化 SiO2 刻蚀量、SiN 接近零、最大化带符号比值。

A = SiO2 初始厚度 − 剩余厚度；B = SiN 初始厚度 − 剩余厚度。新版默认三个目标是最大化 A、最小化 |B−0|、最大化 A/B。A 和 A/B 不取绝对值，负值与正值不会被当成同一结果。

勾选响应，选择“原值 / 绝对值 / 距指定值的距离”以及“尽量大 / 尽量小”；选择距离时填写目标值。多目标 Pareto 寻找折中，不设置目标权重。加权模式为每个实际参与目标填写非负权重和正归一化尺度；单目标必须只保留一项。

旧项目使用数据库里的模板快照，打开时不会自动改目标。“应用新版 ICP 目标”按钮将 A 的绝对值目标改为原值，并新增/使用 selectivity = A/B；旧的 selectivity_abs 指标可保留供历史查阅。保存前可检查表格。

新模板或其他公式通过“全部属性”编辑：派生指标中设置 name、中文 label、单位和 expression；如需独立建模设置 is_response=true、model_base=true，由其他响应推导则 model_base=false。目标必须能由基础响应及其派生公式得到。

## 探索强度

0 保留常规贝叶斯优化评分；越大，对可行且不确定的候选增加的评分越多。

范围 0–100，默认 0。常规位置的评分为：

`评分 = log(贝叶斯预期改善) + 探索强度 × 预测可行概率 × log(1 + 标准化目标不确定性)`

代码使用 BoTorch 的 qLogNEHVI（多目标）或 qLogNEI（单目标/加权）作为第一项。强度为 0 时保留原评分。增大强度会增加可行且后验不确定的候选的相对得分，并保留预期改善项，因此并非简单随机选点，也不保证每个选中点都离历史点更远。

标准化不确定性使用 128 个候选后验样本估计目标标准差，除以历史条件的目标样本标准差，再对目标取平均。标准化尺度至少为 1e-8，并保存到批次中供追溯。这里的不确定性取自潜在响应，不是把观测噪声越大的条件视为越值得探索。探索与优化的权衡是一种明确实现的评分规则，尚不等于真实机台效率得到验证。

## 专门探索名额

从扣除复测后的新条件名额中预留探索点；例如总数 6、无复测、探索 2，另 4 个按常规评分选择。

本轮总数 n 包括复测。新条件名额 = n − 明确复测数；专门探索名额不得超过新条件名额。总数 6、无复测、专门探索 2，生成 2 个探索点和 4 个常规评分点。总数 7、复测 1、专门探索 2，则另外 4 个为常规评分点。常规点仍受探索强度影响；要原始贝叶斯评分可把强度设为 0。

专门探索优先选择：可行概率 × log(1 + 标准化不确定性) × 与待做条件的距离因子。没有待做条件时距离因子为 1；有待做条件时使用归一化输入空间中的最近距离（除以维数平方根并截到 0–1）。每选出一个探索点就加入待做集合，减少同批集中在一起。之后常规位置也把这些点纳入待做集合。

数据不足时，所有新条件处于初始化阶段，不声称执行了模型优化；预留的探索点仍会标注。交叉布局是指定的实验组合，不可同时设置非零专门探索名额。合法候选不足时返回实际数量和缺额原因，不重复填充。输出约束通过模型概率处理，不保证真实结果可行。

## 比值分母策略

分母接近零时可限制有效区域、使用稳定化比值或移除比值目标。

比值默认要求明确选择策略，保存后才能推荐。

- 有效区域：要求 |B| ≥ epsilon；区域外样本参与不可行评价，内部对分母作数值保护。显示原始比值的无条件分位数，并单独给出可行概率。
- 稳定化：新版采用 A / B_safe，其中 B_safe = sign(B) × max(|B|, epsilon)。B 恰好为零时约定 B_safe = +epsilon，界面和文档明确保留这个约定。此指标与原始 A/B 不相同，原始零分母仍是未定义。旧绝对值模板保留 |A| / max(|B|,epsilon)。
- 移除：比值不参与优化，原始比值仍可记录和预测。

采用带符号比值时，负分母会改变比值符号；程序不会偷偷取分母绝对值后当作 A/B。原始比值后验只报告样本分位数，不声明有限均值或方差。

## 分母阈值 epsilon

单位 nm，必须大于零；根据测量分辨率和误差选择，不是探索比例。



## 数值模型

可选高斯过程 RBF、Matérn 2.5 或贝叶斯线性；单调和弱影响先验仅在线性模型中支持。

默认高斯过程 RBF，还可选 Matérn 2.5、贝叶斯线性。A、B 分别建模，当前使用跨响应独立假设；同一响应不同候选点间的相关性保留。所有有效完成/部分记录参与对应响应的拟合，重复条件不先删除或自动求平均。

每个基础响应至少有两条有效记录才启动模型推荐；这是最低运行门槛，不代表八维空间预测已经可靠。已知测量误差以方差进入模型，未知误差不当作零；同一响应混合已知和未知误差目前会报能力限制。

## 本轮实验总数

本轮最多生成的实验记录数，包括新条件、复测和交叉布局。



## 条件变化模式

全范围不限制变化项数；单/双变量相对基准；交叉布局生成指定的单 A、单 B、AB 组合。



## 基准实验

单变量、双变量或冻结部分参数时，用所选实验的实际条件作基准。



## 允许变化的参数

选中的参数可以变化，其余保持基准值；全不选表示不限制参数名单。



## 复测实验

再次执行所选已完成或部分结果实验的条件，新建记录，保留原实验及不同测量结果。



## 候选池大小

在合法、未重复的条件中最多保留多少个候选供评分，默认 128；不是实际实验数。



## 随机种子

相同数据、设置和计算环境下用于复现候选与抽样，不是工艺参数。



## 测量不确定度

填写 ± 值时选择标准不确定度、均值标准误、区间或误差界限；未知不确定度不等于零。

标准不确定度 std、均值标准误 sem 直接提供标准尺度。误差界限 bounds 只有明确 uniform 分布才换算标准差 amount/√3；正态区间 interval 需 normal 分布以及覆盖因子或置信水平。非对称 asymmetric 填写 lower/upper 非负偏差，不是端点。详细字段可点击“详细误差”逐项输入，文本枚举在树中用键盘填写，不需要 JSON 标点。

source 是共享误差来源标识，不是普通仪器备注；跨实验或跨响应共享来源的相关似然尚未适配，请勿给独立误差随意使用同一来源。

## 可视化模板编辑

常用设置使用专用表单；其他属性可在树形编辑器逐项增删、修改，无需手写 JSON。

“编辑项目模板”提供精度、先验、目标三张表；“全部属性”打开保留所有字段的树形编辑器。双击修改值，类型可选文本、数值、整数、开关、未设置、属性组、列表。选择组或列表可添加子项，选择条目可删除。内部字段名称用字母开头的英文字母、数字和下划线，中文名称填 label。数值类型值如 float/int/category/bool/text、测量时点 before/after 等保留机器枚举，可用键盘填写。

通过“新建 / 复制模板”在界面编辑后保存 JSON 文件；通过“从模板新建项目”选择该文件。已有项目中可修改公式、目标、精度、角色等，保存递增模板版本并重算派生值。字段结构、单位、范围、离散集合或固定值改变时，当前版本要求另建项目，避免静默混用旧实验。

还可在全部属性中设置 input_constraints：每项含 coefficients 属性组（参数名到数值系数）、op（<= 或 >=）、rhs（阈值）；outcome_constraints：基础响应 metric、op、bound。只能配置已实现的能力，未知高级模型组合不会因出现在模板中就自动支持。

“保存为本项目的推荐默认设置”会保存总数、探索设置、候选池、随机种子、模式、基准、变量、复测名单和默认模型。交叉布局的两个参数及新值也随默认设置保存。

## 同条件重复实验

允许相同工艺条件对应不同结果；每次真实实验使用独立编号，导入时使用不同 external_id。

同条件、不同结果允许录入。每次实际实验保存为独立记录，Ax 中相同配方共享 arm，但每次运行保留独立 trial 和测量。复测新建待做记录，完成后回填新记录，不覆盖原记录。

导入以 external_id（或 experiment_id）识别实验。同编号、同内容跳过；同编号、不同内容报冲突，需要更正同一次实验或为真正的另一次实验另用编号。未填编号时按完整记录内容去重。因此不同次真实实验即使结果相同，也建议用不同外部编号。

普通新条件推荐会排除所有未删除历史记录的条件和同批已选条件；这种候选去重不删除实验数据。需要重复的条件应明确安排复测或手动新增。

## 自定义常用功能

勾选要显示在常用工作台的功能，设置会保存在当前电脑。

点击“自定义常用功能”，勾选录入、回填、推荐、预测、导入、导出、备份、新模板等入口。精度、先验、目标固定保留。选择保存在当前电脑的应用设置中，不改变实验数据库，也不会覆盖其他项目的数据。

导入 CSV / Excel 默认勾选。升级旧配置时补充一次该入口；之后手动取消勾选会被尊重，重启不会反复添加。

## 预测与趋势图

模型给出潜在响应分布；区间不包含未知的未来量测噪声，原始比值只报告样本分位数。

预测条件采用逐项输入表单，也可从选中实验复制。趋势图通过选择按钮指定一至两个变量和指标，留空变量时只预测。预测输出先展示中文结果，原始字段、版本和依赖库诊断可打开“技术详情”。

512 个后验样本用于估计预测均值和 2.5%、50%、97.5% 分位数。绝对值、比值等指标在每组样本上计算后汇总，不能用“均值的比值”代替比值分布。可行概率是满足已配置输出条件的样本比例，不是准确率。图中的中央 95% 区间是潜在响应区间，不包含未知未来量测误差。

## Cl2 流量

氯气流量，单位 sccm；允许范围由项目模板定义。



## BCl3 流量

三氯化硼流量，单位 sccm；是可控模型输入。



## Ar 流量

氩气流量，单位 sccm；是可控模型输入。



## ICP 功率

电感耦合等离子体功率，单位 W；允许值受范围和执行精度约束。



## RF 功率

射频功率，单位 W；不等同于 ICP 功率。



## 腔室压力

反应腔压力，单位 mT；范围由模板定义。



## 电极温度

电极温度，单位 °C；范围由模板定义。



## 刻蚀时间

刻蚀持续时间，单位 s；模型将其作为工艺输入。



## SiO2 初始厚度

实验前厚度，单位 nm；参与刻蚀量计算，默认不直接作为模型输入。



## SiN 初始厚度

实验前厚度，单位 nm；参与刻蚀量计算，默认不直接作为模型输入。



## SiO2 剩余厚度

实验后测量厚度，单位 nm；不能作为未来实验的已知输入。



## SiN 剩余厚度

实验后测量厚度，单位 nm；缺失时保留为空。



## SiO2 刻蚀量 A

初始厚度减剩余厚度，保留正负号；新版默认目标直接最大化 A。



## SiN 刻蚀量 B

初始厚度减剩余厚度，保留正负号；默认目标最小化 |B|，使其接近零。



## 刻蚀量比值 A/B

新版带符号比值，不取绝对值；负比值与正比值具有不同的优化含义。



## 旧版刻蚀量比值绝对值

旧项目可能保留 |A/B|；打开旧项目不会自动更改目标，可在目标设置中应用新版目标。



## 中文提示与技术详情

输入校验、名额说明和主要计算提示使用中文。模型数值稳定、收敛和依赖弃用提示在后台汇总为中文，原始诊断保存在技术详情中，便于复核。模板内部字段和程序接口代码不翻译，以保持文件兼容。
