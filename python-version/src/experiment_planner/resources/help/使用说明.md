# 实验规划助手 · 通用变量与操作说明

本说明介绍软件的一般功能，不收录任何具体实验模板的参数清单、工艺含义或默认目标。模板是独立的配置：可以从空白创建，也可以复制或修改已有模板。本文件随程序提供，修改模板不会自动改写本文。

## 使用说明

先创建模板或选择已有模板，再创建项目。项目保存模板快照、实际实验记录、推荐批次及修订历史。录入或导入真实实验后，选择模型和目标，计算下一批，实验完成后回填结果。

常用页提供精度、先验和目标设置，并预设录入、回填、推荐、导入和预测入口。其余操作位于更多功能页。所有计算与数据存储在本地进行。

## 输入参数与字段名称

输入参数是在实验前可以设定的条件。每个参数可定义内部名称、显示名称、数据类型、单位、范围、离散取值或固定值，以及字段说明。

- 内部名称：以英文字母开头，只使用字母、数字和下划线，用于公式、导入映射和程序存储，不能重复或使用公式函数的保留名称。
- 显示名称：给使用者阅读的名称，可以用中文；修改它不改变历史数据的内部字段。
- 类型：数值、整数、类别或是否。文字内容应使用测量备注等字段，不能作为可控输入。
- 取值：数值可设上下限、离散集合或固定值；类别使用离散集合或固定值；是否参数有两种值。
- 单位：从单位框选择；无量纲可用 1。也可键盘输入自定义单位名称。同名自定义单位按同一种量纲校验，不同名称不会自动换算；程序不推导自定义复合单位的关系。

“参数 / 测量 / 公式（增删改名）”提供添加、修改和删除。用该表单修改内部名称时，会同步修改公式、目标、先验、约束和推荐变量名单中已知的引用。备注文字和自定义扩展属性不会自动改写，请自行核对。“全部属性”是原始属性编辑器，直接改名时需要同时调整相关引用。

删除字段前会列出受影响的字段；依赖它的公式会一并移除，相关目标、先验和约束也会清理。可以继续添加字段，再重新选择目标并保存。

## 原始测量

原始测量是每次实验实际记录的结果或背景测量。未测值留空，零表示真实数值为零。可附单位、不确定度和备注，也可指定实验前或实验后测量。

数值、整数和是否型测量可选为响应；文字、类别测量用于保存信息，不能直接作为数值优化目标。是否型响应预测的是概率。当前引擎以可控输入作为模型输入，不支持将任意实验前测量或派生指标直接接入输入模型。

## 派生指标与公式

公式使用内部字段名引用已有输入、测量或其他指标。支持加减乘除、比较以及 abs、min、max、round 等已实现函数；不支持幂运算。程序检查字段引用、单位、循环依赖和表达式安全性；不执行任意代码。

“直接建模”决定该指标是否作为基础响应独立拟合；不直接建模的指标可由基础响应的后验样本推导。选择目标前应明确其依赖关系。缺少测量时保留缺失状态，不用零补齐。

## 可视化模板编辑

在“新建 / 复制 / 修改模板”选择起点：从空白创建、复制当前项目、打开本地模板文件，或复制内置示例。空白草稿没有任何预置工艺字段。

从空白开始时，依次添加至少一个输入参数、一个可建模响应，选定至少一个优化目标，然后保存。新增响应默认加入目标候选，之后可以更改方向或取消选择。单目标模式要求恰好启用一个目标，多目标可选折中或加权。

精度、先验、目标有专用表单；字段增删改名有单独表单；其他配置在“全部属性”树中通过鼠标和键盘编辑。属性组和列表可逐项增删，原有扩展属性会保留。草稿允许分步骤完成，最终保存统一检查字段、公式、目标及模型能力，不能保存无法执行的无效配置。

保存为模板文件后，可通过“从模板新建项目”使用它。已打开项目中的修改保存到项目的模板快照，不会自动覆盖来源文件。

空项目可直接替换输入和测量结构；已有实验记录的项目可直接修改兼容配置，例如显示名称、精度、公式和目标。如果改动字段内部名称、单位、类型、范围或字段数量使历史记录不兼容，程序保留本次编辑，提供“另存模板文件”或“用此模板新建项目”。此过程无需重新编辑，也不会猜测旧实验新增参数的数值或悄悄改变旧数据含义。

## 推荐工艺精度 digits

执行精度规定推荐条件的网格，显示精度只影响表格外观。执行模式有不限制、小数位数和指定步长。

允许值 = 网格起点 + 整数 × 步长，还需满足范围及约束。例如步长 5、起点 2，网格为 …、2、7、12、17…；起点不是搜索下限，也不是第一条实验值。

小数位数对应步长 10 的负 digits 次方。起点为 0 时，digits=0 为整数，1 为一位小数，−1 为十位。非整数起点会平移网格。可批量设置数值参数的位数，之后逐项调整。

实际回填的数值型输入允许记录执行偏差；整数型输入要求整数，不自动四舍五入。显示位数不改变原始数据、训练或导出。建模前整体取整尚未实现。

## 先验关系

为输入和基础响应设置已有知识，填写关系、系数、强度和来源。普通备注不会作为先验进入模型。可新增、修改、停用或删除。

无关关系移除对应响应的输入特征；线性和比例关系提供软趋势。单调和弱影响先验目前仅支持贝叶斯线性模型。强度必须为正，不是置信百分比；系数单位为响应单位除以输入单位。局部范围、严格比例和严格全域形状约束尚未适配。

## 实验优化目标

从当前模板的响应和指标中勾选一项或多项，选择原值、绝对值或距指定值的距离，以及尽量大或尽量小。希望接近指定值时，使用距离最小化。

多目标折中保留各目标之间的权衡；单目标只能启用一项；加权方式需要为每个有效目标配置非负权重和正归一化尺度，权重不能全部为零。目标定义及方向以当前模板为准，本软件不固定某一种实验的优化目标。

加权的具体计算是 `S = Σ(w_i × t_i / s_i)`：t_i 为目标变换后的数值，最大化保持正号，最小化取负号；w_i 为非负偏好权重，s_i 为正的归一化尺度。尺度不是测量误差，也不是目标上限；程序不会自动从数据估计尺度。权重无需合计为 1，但不能全为零。

例如两个目标分别是累计量最大化和损伤绝对值最小化，权重 0.7、0.3，尺度 50、5，则 `S = 0.7 × 累计量/50 − 0.3 × |损伤|/5`。尺度设置后才能解释偏好；所有权重设为 1 并不保证原单位的变化同等重要。切换加权、尚未保存配置时，权重和尺度各默认显示 1，应根据可接受的折中修改。

Pareto 模式不使用加权栏，也不等权相加：各有优势的条件组成折中集合，算法评估其预期超体积改善。单目标和加权使用一个总分的预期改善评分，均考虑后验不确定度与约束。本软件用 qLogNEHVI（Pareto）及 qLogNEI（单目标/加权），在有限合法候选池中选择批次；不保证全局最优。Pareto 未显式设参考点时，使用训练条件目标后验均值的逐项最小值减 0.1 × max(该目标跨度, 1)，随批次保存。

默认值来自当前项目模板的 optimization.mode 和 default_model_preset；内置示例和空白草稿的初始优化方式为 Pareto、模型为 GP/RBF。已有项目使用已保存配置。优化方式、数值模型、允许变化模式、先验强度和探索设置各自作用不同。

## 数值模型

支持高斯过程 RBF、高斯过程 Matérn 2.5 和贝叶斯线性。各基础响应分别使用有效的完成或部分结果记录；同条件复测逐条保留，不自动平均。缺少足够有效结果时，下一批采用初始化策略，不能声称已经模型优化。

当前数值响应支持全部误差已知或全部误差未知的情况；同一个响应混用已知与未知误差尚未适配。跨响应和跨实验的相关误差也存在能力限制，配置不支持的组合会明确提示。

- GP/RBF：高斯过程给未知响应函数设概率分布，以 RBF 距离核关联相近条件，假设曲线非常平滑。每个输入的长度尺度由数据拟合，长度尺度很大时该输入的预测影响很弱。适合平滑的非线性响应与较小数据集。
- GP/Matérn 2.5：改用 Matérn ν=5/2 核，允许比 RBF 少一些平滑的变化，可用于比较局部弯折的响应面；仍不自动保证单调、严格比例或任意突变。
- 贝叶斯线性：拟合截距与各输入的加性线性系数，用正态系数先验和数据得到系数后验。适合近似线性或检查趋势；默认没有平方项、交互项。

GP 使用边际似然拟合核和噪声。误差全已知时使用标准不确定度的平方；全未知时 GP 估计噪声，线性模型用经验残差方差。是否型响应另用 Bernoulli-logit / Laplace 概率模型。基础响应分别拟合，跨响应采用条件独立假设。同一响应保留预测点之间的相关性。

统计模型学习实际输入与模板所定义响应之间的关系，不自带物理速率或机台规律，不会自动把累计量除以时间。有效记录只有一个输入取值时，结果会提示无法识别其影响；技术详情包含训练覆盖范围。

## 本轮实验总数

总数包括新条件、指定复测和交叉布局记录。新条件名额等于总数减去复测数；专门探索名额占用新条件的位置，不在总数之外额外增加实验。

## 探索强度

0 保留常规贝叶斯优化评分；正值给可行且不确定的候选增加评分，范围 0–100。越大越倾向尝试不确定但可能有收益的条件，不等于固定探索百分比，也不是目标权重。

## 专门探索名额

从扣除复测后的新条件中明确预留探索位置。例如总数 6、无复测、专门探索 2，另 4 个使用常规评分。常规点仍受探索强度影响。

候选不足时输出实际数量及缺额说明；不以重复点凑满。数据不足时采用初始化，不伪称已优化。交叉布局是明确指定组合，不支持额外专门探索名额。

## 条件变化模式

全范围搜索允许在约束内变化所有选定参数。单变量相对基准改变一项；双变量相对基准最多改变两项，可勾选恰好两项。交叉布局选择两个不同参数及新值，产生单独变化和同时变化的组合，可附基准复测。

## 基准实验

以所选实验的实际条件作为比较基准。限制允许变化的参数时，其他参数保持基准值。删除基准后，需要基准的模式必须重新选择。

## 允许变化的参数

通过按钮勾选参数。空名单表示不限制；有名单时只在相应条件模式下变化这些参数，其他参数由基准固定。参数名称以当前模板为准。

## 复测实验

复测已有完成或部分结果的实验条件，生成独立待做记录。回填复测结果时保存到新编号，不覆盖来源实验。复测占用本轮总名额。

## 候选池大小

最多保留多少个合法候选供评分，默认 128。它是搜索规模，不是要实际进行的实验次数。增大候选池会增加计算量，有限候选搜索不保证全局最优。

## 随机种子

控制候选生成和模型抽样的可重复性。在相同数据、配置和计算环境下有助于复现；不同平台的浮点结果不保证逐位相同。

## 比值分母策略

当模板选择了比值指标时，需要明确接近零的分母如何处理：只在有效区域使用原始比值、使用带符号稳定化分母，或移除比值目标。原始比值与稳定化指标应分开解释。

此项需配合当前模板的比值定义及单位使用；不是所有模板都需要比值设置。自定义指标必须符合当前引擎支持的公式和基础响应关系。

## 分母阈值

有效区域和稳定化需要一个正阈值，选择依据是测量分辨率与不确定度。它不是探索强度或探索比例。单位按当前引擎对相应响应的换算口径确定，不能仅改显示文字就假定数值完成换算。

## 测量不确定度

填写 ± 数字时应说明含义。标准不确定度和均值标准误可直接提供标准尺度；误差界限需要分布假设；正态区间需要正态分布及覆盖因子或置信水平。仅填写数值而不说明含义，可能仍被视为未知误差。

未知误差不是零。同一响应一部分记录已知、一部分未知时，当前模型会提示不支持混合；应按真实测量依据补齐，不要编造零值。所有误差未知时，模型使用已实现的噪声估计方法。

“详细误差”可编辑更多属性。共享来源标识表示相关误差来源，不是普通仪器备注；当前引擎不支持的相关误差不能靠填写来源名称自动接入。

## 导入与结束标记

常用页默认提供 CSV / Excel 导入。先核对表头和列对应关系，再看预览，点击保存写入。表头既可使用内部名称，也可使用唯一的显示名称；名称不一致时用下拉框映射。

按模板的输入参数顺序，取前 30% 并向上取整，至少一项。例如 8 个输入检查前 3 项。这些单元格全部为空、空字符串或只有空白字符时，当前行作为结束标记；它和之后的行都不导入，只保留之前通过校验的记录。即使后面还有数据，也不会越过结束标记继续读。零和否属于有效值，不是空。

范围只计算输入参数，不包含测量、外部编号或备注列；文件列顺序可以改变，程序先做映射。若用于判断结束的输入列没有正确匹配，会提示表头问题，不会误判为正常结束。

CSV 的完全空行也会结束；Excel 读取活动工作表。预览显示停止位置和检查字段。结束前仍有缺项、非法数值或冲突时，需要修正后提交，不会忽略错误。文件直接结束时，则导入已有的有效记录。

## 同条件重复实验

允许相同条件的不同次实验分别保存，也允许结果不同。每次真实实验使用独立编号，不先去重或平均。

导入时同一外部编号且内容相同会跳过；同编号内容不同提示冲突。没有外部编号时按完整记录内容去重。不同次真实实验建议使用不同外部编号。

普通新条件推荐排除未删除历史条件和本批已选条件；复测是独立安排。删除过的导入记录可以重新导入，并按最小空缺规则获得内部编号，可能与删除前相同。

## 删除实验记录

在实验表中单击选一行，Ctrl 多选、Shift 连选或拖动选择多行，点击“删除选中实验”，核对编号后确认。取消不改变记录。

删除后不再参与当前训练、推荐和普通导出；原始内容保留在删除审计，旧批次和预测也保留。清理已保存的基准及复测默认引用，空缺编号可复用，可用 Ctrl+Z 撤销删除；完整数据库备份包含审计。

删除会更新项目版本，旧数据上的计算不能写回。首次删除将数据库版本更新为 2，之后使用支持删除标记的版本打开；数据库版本与模板版本是不同概念。

## 自定义常用功能

勾选常用入口并保存在本机。精度、先验、目标固定保留，其余入口可以增减。导入默认勾选，旧配置升级时只补充一次；后来手动取消会被保留。

## 预测与趋势图

通过参数表单输入条件，或从选中实验复制实际条件。选择趋势变量及响应后可生成趋势图。可选字段来自当前模板，不固定某一实验的名称。

预测基于模型的潜在响应分布，512 个后验样本用于汇总数值与分位数；区间不包含未提供的未来测量误差。非线性公式在各组样本上计算再汇总，不能用“均值代入公式”代替完整分布传播。原始比值仅报告样本分位数，不保证有限均值和方差。

## 帮助、保存与备份

通用操作的悬停简述包含蓝色详细链接。模板特有变量的标签、输入和表头不自动弹出通用说明框；字段含义请看模板和备注。鼠标离开变量和弹窗后约 1 秒关闭；进入弹窗或返回变量取消关闭计时。详细链接打开通用章节，字段自身的含义以模板名称和备注为准。

界面主要错误与计算提示使用中文，技术详情保留内部标识和原始诊断。模板文件保存配置；项目数据库保存实验与历史；普通表格导出只含未删除记录；完整备份保留整个数据库。进行下一批计算、回填或修改前，确认当前打开的是目标项目。


## 显示位数与保存机制

在“推荐工艺精度”中分别设置工艺输入、原始测量和派生指标的显示小数位数 display_digits。0 为整数，2 为两位小数，负数为十位等，范围 −12～12；原始精度表示未设限制。它只改变表格及预测文字，不改变原始测量、派生计算、模型或导出值。执行 digits 决定新推荐条件的设备网格，是不同设置。图线保留计算值，坐标刻度由绘图库自动选择。

项目的 SQLite 文件是保存依据；录入、更正、删除、确认导入、模板和批次保存成功后立即提交事务，失败回滚。未确认的表单和预览尚未写入。项目模板是快照，修改不会自动覆盖来源 JSON。后台计算使用开始时的数据快照；旧版本推荐不能写回已修改的项目。默认推荐设置需单独保存，常用入口配置保存在本机。

## 撤销、重做与编号复用

Ctrl+Z / Ctrl+Shift+Z 撤销上一步，Ctrl+Y / Ctrl+Shift+Y 重做下一步；大小写都支持。工具栏也有按钮。可用于已保存的录入、更正、回填、删除、一次导入和兼容项目模板修改（包括精度、目标、先验、默认设置）。最多保留本次打开期间 50 步；关闭/切换项目、保存新推荐批次会清空历史，撤销后新修改会清空重做。文字输入焦点内只撤销文字；弹窗使用原有文字编辑机制；计算中请先取消或等待。

项目撤销/重做立即写入数据库、保留审计并递增数据版本，不回退版本号。导出、备份、后台计算、推荐批次、外部模板文件保存、项目开关和常用入口定制不纳入项目撤销。其他窗口修改项目后不能用旧历史覆盖。

新增记录使用活动记录中最小的空缺正整数，删除后可复用，现存编号不重排。若删除末尾 12，下次从 12、13、14 继续；若 13 仍存在就跳过。手动录入、导入和推荐批次共用规则。审计和旧批次保存历史含义，结合版本和时间识别历史编号；新记录有内部 UID，来源引用附 UID，避免把重用编号当成永久身份。

## 下载导入模板与导出预测数据

打开项目后，在“项目与模板 → 下载导入 CSV / Excel 模板”生成当前模板的空白输入表，也可将此入口加入常用页。CSV 用 UTF-8 BOM；Excel 默认活动页“导入数据”供填写，另有名称、单位、范围、备注和误差说明页。从第 2 行填真实记录；每次复测用不同 external_id，输入完整，未测测量留空，派生值由程序重算。不要在记录中间留符合导入结束规则的空行。

完成预测或绘图后，在预测页点击“导出预测 / 图线 Excel 数据”。可导出 XLSX/CSV，每个点与指标一行，包含完整条件、模型、数据/模板版本、后验中位数、2.5%/97.5% 分位数、适用的均值、单位和可行概率。单变量、双变量图和单条件预测均支持；原始比值均值为空。导出使用当前结果缓存，不重新拟合、不按显示位数取整；数据修改后旧图仍按原版本导出，关闭项目清空结果。

## 趋势图的数学含义

趋势图是固定表单其他输入、改变选定一项或两项的条件切片。其采样点符合模板执行网格与约束，曲线表示模型潜在响应的中位数和中央 95% 区间；不会自动识别速率单位。响应单位和公式由模板决定；记录编号不进入训练，也不是工艺时间。

时间等输入的切片平坦可能来自取值无变化、数据不足、输入共同变化无法区分效应、无关先验、被关闭的模型输入、切片远离数据导致 GP 回到均值或显示位数较粗。不能由统计平坦曲线推出物理无关。先核对模板公式、单位、输入名单、有效训练记录及覆盖范围，安排其他条件相同的多时间实验/复测，再比较模型与区间。程序不会为了符合直觉强行加入斜率。
