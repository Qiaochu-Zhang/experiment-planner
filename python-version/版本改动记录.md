# 版本改动记录

## 0.3.0 · 通用模板与导入结束判断

基线：`b82dda8`。改动范围仍为 `python-version`。

- 导入先匹配表头，再按模板输入顺序检查前 30%（向上取整、至少一项）。全空即停止，该行及后续不导入；空白字符算空，零和否不算空。CSV 真实空行及 Excel 格式尾行均支持，预览与命令行显示停止行和检查字段。结束前的错误仍阻止提交，缺少结束判断列会提示表头问题。
- 新增空白模板起点，不携带默认工艺字段；可复制当前项目、修改本地模板文件或复制内置示例。字段表单支持输入、测量与派生公式的增删、类型、单位、名称及取值编辑；其余属性由完整属性树编辑。
- 字段表单的内部改名同步更新已知公式、目标、先验、约束和推荐变量引用；删除前显示连带影响，清理相关定义。属性树允许分步骤完成草稿，最终保存校验模板及目标是否可由基础响应得到。
- 空项目允许直接修改结构；已有记录且结构不兼容时，可保留编辑成果直接另存模板或用它创建项目，不自动改写旧实验。
- 支持自定义单位名称作为独立量纲标签，同名可做单位一致性检查，不同名称不自动换算；保留原有单位处理。
- 通用帮助移除具体工艺参数和专属目标条目，自定义字段跳转到通用字段说明。预测默认指标来自当前模板。完善无显示名称和固定类别/是否输入的处理。
- 清理 Markdown 中的外部发布和链接说明；更新教程、回答、导入说明及功能边界。双版本测试、安装包和界面检查结果见 [验证记录](docs/validation.md)。

## 0.2.1 · 实验删除与界面操作补充

日期：2026-09-29。上一代码基线：`f3a5393`。本轮改动限于 `python-version`。

- 实验表增加“删除选中实验”，支持鼠标单选、Ctrl 多选、Shift 连选和拖动选择。中文确认框显示条数与编号，默认取消。
- 删除作为一个事务提交，保留原始数据和删除审计；当前实验列表、训练快照、Ax 跟踪、候选排除及普通导出仅使用未删除记录。旧批次、旧预测和完整备份保留，内部编号不复用，删除后允许重新导入同一外部编号/内容。
- 删除递增数据版本，旧计算不能写回；已保存的基准与复测默认设置同步移除相应编号，必要时更新模板版本。需要基准的模式由用户重选。
- 首次删除把数据库版本更新为 2，防止旧程序误用删除记录；0.2.1 支持数据库版本 1 和 2。当前没有一键撤销删除，原始数据可在项目历史中查看。
- 悬停简述改为离开变量与弹窗后 1 秒关闭；进入弹窗或返回变量取消关闭计时，蓝色详细链接保持可点击。表头从一个变量移到另一列也会启动关闭计时。
- 导入 CSV / Excel 默认加入常用功能，旧用户配置自动补充一次；其他定制保留，用户之后取消勾选不会被重启覆盖。
- `回答.md` 保留前六问，新增步长/网格起点、静态说明更新、导入结束机制、混合已知/未知误差四个回答。这四项只解释实现，没有更改导入空行处理、自动生成说明或混合噪声算法。
- 更新 README、Windows 教程、参数说明、随程序帮助、功能边界及验证报告。新增事务回滚/版本、删除后模型与导出、审计恢复、鼠标选行、取消操作、帮助延时、常用配置升级回归，具体结果见 [验证报告](docs/validation.md)。

## 0.2.0 · 历史改动

日期：2026-09-29。上一代码基线：`1440f2a`。本轮按用户要求同时更新 Python 源码、算法、中文界面、测试与文档。

## 环境与交付

- Python 版本约束从 `>=3.12,<3.13` 改为 `>=3.12,<3.14`，源码版本号更新为 0.2.0。
- 保留 Ax 1.3.1 / BoTorch 0.18.1，PySide6 下限改为 6.8.1；采用标准 CPython，不声明自由线程支持。
- 安装包新增离线中文帮助文件，保留内置字体和模板，可独立复制源码使用。

## 界面

- 增加“常用功能”和“更多功能”两层导航；预设精度、先验、目标、推荐、录入、回填、预测按钮，其他按钮可通过勾选自定义并保存到本机。
- 精度改为逐参数模式/位数/步长/起点/显示位数表单，支持批量设置。
- 先验改为可增删的选择表单，包含输入、基础响应、关系、系数、强度、来源和启用状态。
- 优化目标可勾选一项或多项，设置变换、方向、指定值、权重和归一化尺度；可选择默认模型及分母策略。
- 新增完整有类型的模板属性树：通过鼠标和键盘增删、修改字段、范围、公式、约束、误差及其他属性，保留未知配置。可新建/复制模板、导出 JSON、从模板新建项目。
- 交叉布局、预测条件、趋势变量选择和导入列映射改为表单或选择按钮；常规操作不要求手写 JSON。
- 变量名称、表头、设置提供悬停简述及蓝色详细链接；程序可定位和打开同一份离线 Markdown 说明。
- 主要错误、警告摘要、推荐/预测输出和趋势图使用中文；原始数据字段及依赖库诊断保存在“技术详情”。统一 Qt 应用与翻译对象的生命周期，退出前释放界面对象，修复解释器清理阶段的偶发崩溃。

## 模型与数据

- 新内置模板版本为 2：最大化 A、最小化 |B|、最大化 A/B；取消第一和第三目标的绝对值。
- 新版比值字段为 `selectivity`；旧 `selectivity_abs` 模板仍按原公式工作。打开旧项目不自动迁移，目标表单提供“应用新版 ICP 目标”按钮。
- 统一实测派生、后验和采集函数的带符号比值稳定化；保留分母符号，零处明确用 +epsilon。原始比值与稳定化比值分开；自定义比值基础响应的 nm/um 在比值与可行性处理中按标准单位换算。
- 新增探索强度 `exploration_strength`（0–100，默认 0）：给常规 qLog 采集评分增加按可行概率调节的标准化不确定性加分。
- 新增专门探索名额 `exploration_count`（默认 0）：扣除复测名额后显式分配探索点，按不确定性、可行性及与待做条件的距离选择，再执行其余常规评分选择。初始化和交叉布局分别处理。
- 新设置可保存为项目推荐默认值。批次保留算法标识、尺度、评分、实际名额和候选安排类型，支持审计和恢复。
- 同条件、不同测量继续作为独立实验保存并训练；Ax 同配方共享 arm、每次运行独立 trial 的修复保留，新增界面和算法联动回归。

## 测试与文档

新增带符号目标独立数值核对、零/负分母、单位换算、强度评分、三个模型的精确名额与待做去重、数据库备份恢复、表单保存、旧目标切换、模板属性保留、帮助链接定位、常用项持久化及重复录入测试。

README、Windows 教程、参数说明、回答文档、功能限制和验证报告更新到 0.2；旧项目说明及旧预测审计材料明确标为历史版本，保留原始证据。详细验证数量、命令和环境见 [验证报告](docs/validation.md)。

本版保留原有能力边界：不支持跨响应相关噪声、已知/未知误差混合、额外实验前测量作为输入、严格/局部形状先验等组合；字段结构变化仍通过新模板新项目完成。新探索规则尚未证明真实机台收益。
