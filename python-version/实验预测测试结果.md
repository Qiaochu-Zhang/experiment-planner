# 实验预测可信度测试结果

日期：2026-09-20。范围：仅 `python-version`。依据：[测试计划](实验预测测试计划.md)、[全部改动记录](实验预测测试改动记录.md)。

## 1. 结论：有条件可用，不能直接认定真实实验预测可靠

**默认两个 GP 在本轮数据覆盖充分、低噪声的合成场景中表现较好，可以作为继续验证的实验规划工具；小样本、模型关系不匹配及训练范围外预测都有明显限制。没有真实机台数据，本轮不能证明实际刻蚀预测准确。**

本轮发现并修复两处会影响预测数值含义的代码缺陷：有效区域策略把截断选择比误显示为原始选择比；自定义公式的预测路径遗漏 nm/um 换算。修复后 79 项回归全部通过，但统计评估仍明确暴露以下风险：

- 非线性真值用贝叶斯线性拟合时，A 的 RMSE 为 **5.811 nm**，标称 95% 区间只覆盖 **2.5%** 的真值，属于明显过度自信。
- 在模板允许范围内、但远离训练数据时，GP-RBF 与 GP-Matérn 对 B 的 95% 区间覆盖仅 **40.0% / 44.1%**；原始比值甚至不如简单常数基线。
- 仅 12 条线性训练样本时，本轮两个 GP 表现尚好，贝叶斯线性对 B 的相对误差未通过约定门槛。不能据此推断任意八维工艺只需 12 条数据。

## 3. 数据与评估方法

八维归一化坐标 `x0…x7` 按 Cl2、BCl3、Ar、ICP、RF、压力、温度、时间排序，对应模板完整范围。独立合成真值（单位 nm）为：

```text
线性：A = 10 + 20*x0 + 35*x3 + 12*x7
      B = 1 + 6*x4 + 3*x1

非线性：A = 线性A + 12*sin(2*pi*x0) + 16*(x3-0.5)*(x7-0.5)
        B = 线性B + 2*sin(2*pi*x4) + 2*(x1-0.5)^2
```

这两组函数人为指定，**不是 ICP 刻蚀物理模型，也未作为知识先验告诉拟合模型**。模型仍使用全部八个输入。

每次生成 64 或 12 条训练记录、64 条独立测试条件；种子为 11、23、37、51、79。四个原始厚度分别加入独立、标准差 0.2 nm 的正态测量误差，经实际业务入口录入、计算差值并保存到 SQLite，再由 `analyze` 拟合与预测。A、B 的已知测量方差为 0.08 nm²。真值不进入训练数据。

每个场景/模型下合并五次的 320 条测试预测，同时保留每次结果。训练和测试条件不重合，随机流独立；三个模型共享相同数据。训练充分、少样本、非线性三个场景均在全范围随机采样；外推场景的训练每维位于 0.10–0.55，测试位于 0.70–0.95，仍在模板合法范围内。

以下预测均使用默认 512 个后验样本。覆盖率检查的是无未来量测噪声的潜在真值；不能把这些区间直接用于声称下一次带噪声实测有 95% 概率落入其中。

## 4. A、B 预测误差和区间覆盖

RMSE 单位为 nm，越小越好。“覆盖率”是 2.5%–97.5% 分位区间包含真值的实际比例。表中“通过”仅表示符合预先确定的合成筛查：优于训练均值基线、NRMSE ≤ 0.25、覆盖率 ≥ 85%，不等于工艺验收或严格 95% 校准。

| 场景 | 模型 | A RMSE | B RMSE | A 覆盖率 | B 覆盖率 | A/B 筛查 |
| --- | --- | ---: | ---: | ---: | ---: | --- |
| 线性，64 条训练 | GP-RBF | 0.123 | 0.093 | 90.6% | 94.7% | 通过 / 通过 |
| 线性，64 条训练 | GP-Matérn 2.5 | 0.117 | 0.087 | 91.9% | 96.6% | 通过 / 通过 |
| 线性，64 条训练 | 贝叶斯线性 | 0.132 | 0.111 | 90.0% | 94.4% | 通过 / 通过 |
| 线性，12 条训练 | GP-RBF | 0.239 | 0.210 | 95.3% | 95.0% | 通过 / 通过 |
| 线性，12 条训练 | GP-Matérn 2.5 | 0.233 | 0.207 | 98.1% | 96.9% | 通过 / 通过 |
| 线性，12 条训练 | 贝叶斯线性 | 0.351 | 0.561 | 98.4% | 97.8% | 通过 / 未通过 |
| 非线性，64 条训练 | GP-RBF | 0.320 | 0.136 | 96.3% | 92.2% | 通过 / 通过 |
| 非线性，64 条训练 | GP-Matérn 2.5 | 0.300 | 0.151 | 98.1% | 95.9% | 通过 / 通过 |
| 外推，64 条训练 | GP-RBF | 1.174 | 2.311 | 99.4% | 40.0% | 未通过 / 未通过 |
| 外推，64 条训练 | GP-Matérn 2.5 | 0.833 | 2.152 | 100.0% | 44.1% | 未通过 / 未通过 |
| 外推，64 条训练 | 贝叶斯线性 | 0.699 | 0.398 | 68.1% | 80.0% | 未通过 / 未通过 |
| 非线性，64 条训练 | 贝叶斯线性 | **5.811** | **0.906** | **2.5%** | **12.2%** | **未通过 / 未通过** |

关键判读：

1. **线性且训练覆盖充分时，三个模型均通过这组检查。** 两个 GP 的 A、B 误差明显低于 1 nm，但这些绝对数值只对应当前指定函数和噪声。
2. **高覆盖率不代表精度高。** 12 条训练时，贝叶斯线性的 B NRMSE=0.288，大于 0.25；其 B 区间平均宽度为 1.874 nm，两个 GP 约为 0.819/0.855 nm。
3. **线性结构失配时会严重过度自信。** 非线性场景中，贝叶斯线性 A 的区间平均宽度仍只有 0.442 nm，远小于其 5.811 nm 的 RMSE。实现中已知测量噪声直接进入线性似然，后验系数协方差由输入、先验和观测方差决定，不能自动包含遗漏的非线性关系误差。本轮未擅自增加另一种噪声模型。
4. **“在模板范围内”不代表“在训练覆盖范围内”。** 外推时 GP 的 B NRMSE 分别达 4.749/4.423；A 虽然覆盖率高，但 NRMSE 分别为 0.388/0.275，且区间平均宽度增至 3.614/4.828 nm。贝叶斯线性外推也未通过全部判据。
5. **汇总值可能掩盖某次训练失败。** 非线性 RBF 对 B 的五次覆盖率为 76.6%、93.8%、92.2%、100%、98.4%；外推 RBF 对 B 为 0%、0%、100%、100%、0%。小范围、有限种子的结果不能当成每个真实项目都可复现的保证。

MAE、R²、NRMSE、基线 RMSE、技能分数、区间宽度及各种子结果均保存在 JSON 中。本轮所有 A/B 的总体技能分数为正，但其中多项仍未通过区间/精度门槛；**仅比训练均值好不够证明可靠**。

## 5. 选择比预测

原始 `abs(A/B)` 不声明有限均值，以后验中位数评估。稳定化指标使用 `abs(A)/max(abs(B), 1 nm)` 的后验均值；两者是不同指标。下表误差为无量纲 MAE。

| 场景 | 模型 | 原始比值中位数 MAE | 稳定化比值均值 MAE | 原始比值区间覆盖 |
| --- | --- | ---: | ---: | ---: |
| 线性 64 | GP-RBF | 0.161 | 0.160 | 96.9% |
| 线性 64 | GP-Matérn 2.5 | 0.151 | 0.149 | 97.8% |
| 线性 64 | 贝叶斯线性 | 0.196 | 0.193 | 96.3% |
| 线性 12 | GP-RBF | 0.418 | 0.439 | 96.9% |
| 线性 12 | GP-Matérn 2.5 | 0.421 | 0.438 | 97.5% |
| 线性 12 | 贝叶斯线性 | 0.911 | 0.978 | 97.8% |
| 非线性 64 | GP-RBF | 0.187 | 0.189 | 94.1% |
| 非线性 64 | GP-Matérn 2.5 | 0.209 | 0.210 | 97.5% |
| 非线性 64 | 贝叶斯线性 | 1.459 | 1.460 | 13.1% |
| 外推 64 | GP-RBF | 2.562 | 2.817 | 40.0% |
| 外推 64 | GP-Matérn 2.5 | 2.314 | 2.603 | 56.9% |
| 外推 64 | 贝叶斯线性 | 0.259 | 0.255 | 81.9% |

外推时两个 GP 的原始比值技能分数分别为 **−17.43、−10.67**，比“始终预测训练观测比值中位数”更差。比值会放大分母预测误差，不能仅凭 A 的预测不错来信任选择比。

以上留出函数的真实 B 均大于 1 nm，不能替代接近零分母的统计校准。零、负值、跨零/低于 epsilon 等语义由已有误差测试及新增指定后验样本检查覆盖；尤其新检查包含 B=0.1、−0.2、2、−4 nm。实际工艺中 B 接近量测分辨率时，仍应标记原始比值不稳定，并根据量测用途显式选择分母策略。

## 6. 已修复缺陷及直接影响

| 缺陷 | 修复前证据 | 修复后含义 |
| --- | --- | --- |
| 有效区域中原始比值被截断统计替代 | 四个样本的原始比值中位数应为 6.5，程序为 2.5；97.5% 分位数应为 37.75，程序为 3.925 | 原始比值、稳定化比值、可行概率分别保留；有限保护只用于相关优化计算 |
| 预测公式遗漏 nm/um 换算 | `1000 nm − 0.5 um` 应为 500 nm，程序为 999.5 nm | 预测和实测公式采用同样的长度换算，并支持链式读取换算后指标 |

两处均先用独立断言复现，再修复；不是通过修改预期值让测试变绿。对默认全 nm 模板，第二处不影响原有基础模型拟合。旧批次保存的历史预测不会自动改写，如需更正结果应重新预测。

## 7. 当前使用判断与下一步

- 可以把两个 GP 作为本版后续本地验证的起点；优先在历史数据覆盖的条件附近试验，检查每轮实际误差，不能从这四组函数推断某个模型在真实工艺中一定更好。
- 贝叶斯线性仅在有数据支持近似线性关系时使用；区间很窄也可能是模型假设不适用。当前程序没有自动失配或外推报警，本轮没有新增这些功能。
- 需要真实历史数据按时间/批次留出验证，并由实验人员先确定 A/B 误差允差及可分辨分母阈值，再做少量前瞻实验。具体步骤已写入测试计划；真实数据保留在公司本地，不需要上传开发环境。
- **本轮未验证**真实机台效果、推荐相对于随机/人工方案的等预算收益、所有先验与未知噪声组合、布尔概率校准、跨输出相关性、Windows/PyCharm 人工流程和完整离线部署。现有回归覆盖其中若干软件流程，不代表这些科学效果已经通过。

## 8. 复现

安装依赖后，在 `python-version` 中执行：

```bash
QT_QPA_PLATFORM=offscreen python -m pytest -q
python scripts/validate_prediction.py --output local-data/prediction-audit-new.json
```

输出 JSON 必须使用尚不存在的文件。当前仓库可将 `python` 替换为 `../.venv/bin/python`。完整当次命令、文件清单和证据索引见[改动记录](实验预测测试改动记录.md)。
