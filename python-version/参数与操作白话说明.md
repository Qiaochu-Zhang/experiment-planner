# 参数与操作白话说明 · 0.3.0

通用逐项说明位于随程序安装的 [变量与操作说明](src/experiment_planner/resources/help/使用说明.md)。工作台说明按钮、变量悬停中的蓝色链接和本页指向同一份内容，离线也可使用。

| 想做什么 | 界面入口 | 关键区别 |
| --- | --- | --- |
| 推荐条件取整数 | 常用 → 推荐工艺精度 | 执行模式为小数位数、digits=0；显示小数位数不会改变数据。 |
| 添加工艺经验 | 常用 → 先验关系定义 | 选择输入/响应/关系并填系数、强度、来源；普通备注不会进入模型。 |
| 多目标优化 | 常用 → 实验优化目标 | 从当前模板选择响应或指标，配置方向、变换和优化方式。 |
| 调整探索倾向 | 推荐下一批 → 探索强度 | 0 保留常规贝叶斯评分；正值增加可行候选的不确定性加分。 |
| 明确安排探索点 | 推荐下一批 → 专门探索名额 | 是新条件名额中的一部分，不是复测名额或抽样次数。 |
| 相同条件再做一次 | 录入实验，或推荐页勾选复测 | 保留为独立实验及独立测量，不自动平均。 |
| 删除一条或多条实验 | 查看与回填实验 → 鼠标选行 → 删除选中实验 | Ctrl 多选、Shift 连选；确认后移出当前训练/推荐/导出，保留删除审计。 |
| 导入 CSV / Excel | 常用 → 导入 CSV / Excel | 默认显示；前 30% 输入全空时结束并排除本行和之后内容。 |
| 自定义常用页 | 常用 → 自定义常用功能 | 选择保存在当前电脑；精度、先验、目标固定保留。 |
| 新建或修改模板 | 更多 → 项目与模板 → 新建 / 复制 / 修改模板文件 | 从空白、当前模板或文件开始；字段表单增删改名，全部属性编辑其余设置。 |
| 预测结果与告警 | 预测 / 推荐结果区 | 中文主要说明；原始字段与依赖诊断在技术详情。 |

n 包括复测、交叉组和新条件。新条件数 = n − 指定复测数；专门探索不再额外增加总数。初始化阶段所有新条件尚未进行模型优化，不能宣称其中某些是贝叶斯最优点。

模板若使用比值指标，应明确分母策略；稳定化指标与原始比值分别保留。其计算口径需匹配当前模板与响应单位。

目标权重、先验强度、探索强度和专门探索名额分别是不同设置。详细公式及保存字段见 [算法与界面规范](docs/v0.2_spec.md)。

鼠标离开变量和帮助弹窗约 1 秒后简述消失，移入弹窗可以点击蓝色详细链接。详细说明目前是静态文件，不随模板自动生成。步长/网格起点、模板说明更新、导入结束机制及混合误差提示的完整回答见 [回答.md](回答.md) 第 7–10 节。

空项目可直接更换结构；已有记录且结构不兼容时，程序保留编辑内容并提供另存模板或直接新建项目的按钮。具体字段含义来自模板备注，通用帮助不再收录默认工艺的参数条目，模板变量不再自动弹出说明框。


本次新增：精度页可分别设置测量和派生指标的显示位数；Ctrl+Z/Z 与 Ctrl+Y/Y 可撤销/重做常见已保存操作；删除后的空缺编号可复用；项目与模板页可下载当前模板的 CSV/Excel 导入空表；预测页可导出当前预测和图线的完整 Excel/CSV 数据。

加权总分 `S = Σ(w_i × t_i / s_i)` 中，t_i 为方向统一后的目标，w_i 为偏好权重，s_i 为归一化尺度；Pareto 不使用加权栏。模型、默认配置、保存和撤销边界、时间趋势的完整解释见 [回答.md](回答.md) 第 12–18 节，以及程序“变量与操作详细说明”的对应章节。
