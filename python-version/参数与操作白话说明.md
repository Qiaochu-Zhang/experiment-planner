## 1. 先认识这个软件

可以把它理解成一本会计算的实验记录本：你告诉它以前用了什么条件、测到了什么结果，它再估计其他条件的结果，并建议下一轮做哪些实验。

| 名词 | 白话解释 |
| --- | --- |
| 项目 | 一份 `.sqlite` 文件，装着这一组实验的记录、模板、推荐批次和修改历史。 |
| 实验条件／输入／变量 | 做实验之前可以设置的东西，例如气体流量、功率、温度、时间。 |
| 测量值 | 仪器实际测出来的数据，例如刻蚀前后的厚度。 |
| 派生指标 | 用测量值算出来的数，例如“初始厚度减剩余厚度”。 |
| 基础响应 | 模型直接学习和预测的结果。内置模板是两种材料各自的刻蚀量。 |
| 目标 | 你希望什么结果变大、变小，或者接近某个数。 |
| 推荐 | “下一步值得做哪些条件”；会考虑可能改善结果的机会和模型的不确定性。 |
| 预测 | “如果做这组条件，模型估计结果会是多少”；不是已经测到的事实。 |
| 基准实验 | 用来比较的旧条件。变化几项，都是与这组条件比较。 |
| 复测 | 用同一组条件再做一次，产生一条新记录。 |

内置模板的三个目标是：SiO2 刻蚀量的**绝对值尽量大**、SiN 刻蚀量的**绝对值尽量小**、两者比值的**绝对值尽量大**。默认用 `pareto` 方式权衡：保留不同的折中方向，没有预先把三个目标按某个固定比例加成一个总分。

“绝对值”就是去掉正负号。例如 `-10` 和 `10` 的绝对值都是 `10`。因此，当前默认目标不是简单的“SiO2 正向刻蚀越多越好”：负刻蚀量也会按其大小参与绝对值目标。原始正负号仍会保存。

## 2. 给出的预测能删掉吗

**当前版本没有删除已保存实验、推荐批次或旧预测的界面按钮，也没有对应的命令行删除命令。** 先分清你想处理的是哪一种东西：

| 你指的“预测” | 当前实际行为 | 能怎么处理 |
| --- | --- | --- |
| “预测 / 趋势图”页面临时算出的结果 | 只做分析，不新增实验记录，不保存为推荐批次。 | 再次分析会更新显示；关闭项目会清空该页面。单独保存的 PNG 文件仍在所选文件夹中。 |
| “计算并保存下一批实验”生成的待做实验 | 计算成功后自动保存，没有额外的“是否保存”预览步骤。 | 不准备做的实验可以改为“取消”；记录仍保留。 |
| 已保存实验附带的旧预测 | 是当时那版数据和模型给出的估计。 | 更正、回填或取消实验时仍保留；没有单独清除按钮。 |
| 一整个历史推荐批次 | 保存在项目数据库里，用于追溯。 | 没有删除批次入口；重新计算会新增批次，而不是覆盖旧批次。 |
| 正在计算、还没保存的推荐 | 仍是后台任务。 | 点击“取消计算”停止任务；已经提交的批次不会因此撤销。 |

**取消一条不做的计划：** 到“实验记录”选中那一行 → 点击“更正选中实验 / 回填” → 将“实验状态”改为“取消” → 保存。没有测量结果就保留空白，不要用 `0` 代替没测。

取消后有三个影响：

1. 它仍显示在记录表中，原建议、旧预测和修改历史仍保留。
2. 它不再算待做／进行中，也不会作为完成的测量数据参与模型训练；下次重新拟合时生效。
3. **普通的新条件推荐仍会避开所有历史上出现过的相同条件，包括取消或失败的记录。** 取消不等于“清除这组条件的历史”。

已有“完成”或“部分结果”的实验，可以填写“复测实验编号”来明确安排同条件复测。只有取消记录、没有可复测的完成记录时，可以手动录入同条件的新实验；交叉布局也有自己的重复检查规则，见第 7 节。

如果只是想先看看下一批、不保存，当前图形界面没有这个开关；命令行支持预览：

```bash
python cli.py recommend 项目.sqlite examples/batch.json
```

只有加上 `--commit` 才写入项目。这个示例请求使用基准实验 `1`，实际使用前需把 JSON 中的编号和设置改成自己项目的内容，并先保存比值策略。

如果你要的是“彻底删除”或“隐藏取消记录”，那是当前尚未实现的功能。本文说明现有行为，不代表已经新增了这些按钮。

## 3. 八个实验条件和四个测量值

### 3.1 实验条件：做实验前设置

在“允许变化的字段”、交叉布局 JSON、预测 JSON、趋势图变量中，需要填写下表的**内部字段名**，例如 `cl2_sccm`，不是中文名称。

| 界面名称 | 内部字段名 | 白话意思 | 单位 | 内置范围，含两端 |
| --- | --- | --- | --- | --- |
| Cl2 | `cl2_sccm` | 氯气的流量设置 | sccm | 0–100 |
| BCl3 | `bcl3_sccm` | 三氯化硼的流量设置 | sccm | 0–100 |
| Ar | `ar_sccm` | 氩气的流量设置 | sccm | 0–100 |
| ICP | `icp_w` | ICP 源的功率设置 | W | 100–1500 |
| RF | `rf_w` | RF 功率设置 | W | 0–100 |
| 腔室压力 | `pressure_mt` | 腔室压力设置 | 界面记作 mT | 5–50 |
| 电极温度 | `electrode_temp_c` | 电极温度设置 | °C | 0–40 |
| 刻蚀时间 | `etch_time_s` | 这次刻蚀持续多久 | s | 10–300 |

这些是模板允许的输入范围，不是软件验证过的最佳工艺窗口。内置模板没有额外配置总气体流量等联动限制；项目有这类限制时，需要明确写入模板。

内置八个条件都按可以带小数的数值处理，默认没有执行步长限制。例如软件不会自动假定功率只能填整数。要限制到 `1 W`、`0.5 sccm` 等步长，需配置执行精度。

### 3.2 原始测量：仪器实际测到什么

| 界面名称 | 内部字段名 | 要填的内容 |
| --- | --- | --- |
| SiO2初始厚度 | `sio2_initial_nm` | 刻蚀前 SiO2 的厚度，nm。 |
| SiO2剩余厚度 | `sio2_remaining_nm` | 刻蚀后 SiO2 的厚度，nm。 |
| SiN初始厚度 | `sin_initial_nm` | 刻蚀前 SiN 的厚度，nm。 |
| SiN剩余厚度 | `sin_remaining_nm` | 刻蚀后 SiN 的厚度，nm。 |

测量可以留空，表示还没测。这里的初始厚度参与刻蚀量计算，但内置模型没有把初始厚度当作额外输入变量。

### 3.3 软件自动算出的指标

为解释比值，下面把两种刻蚀量暂时简称为 `A` 和 `B`：

```text
A = SiO2 初始厚度 − SiO2 剩余厚度
B = SiN 初始厚度 − SiN 剩余厚度
原始比值 = abs(A / B)
```

| 指标 | 内部字段名 | 例子 |
| --- | --- | --- |
| SiO2刻蚀量 | `sio2_loss_nm` | 初始 100、剩余 90 → A = 10 nm。 |
| SiN刻蚀量 | `sin_loss_nm` | 初始 100、剩余 99 → B = 1 nm。 |
| 刻蚀量比值绝对值 | `selectivity_abs` | 上面的例子得到 10，没有单位。 |
| 稳定化比值 | `selectivity_stable` | 选择稳定化策略后另外计算，公式见下一节。 |

如果剩余厚度比初始厚度大，刻蚀量会是负数，软件不会自动改成零。`B = 0` 时原始比值没有定义；分母测量区间跨过零时，原始比值会被标为不稳定。有效的 A、B 仍可用于建模。

## 4. 比值目标和 epsilon

### 4.1 epsilon 是什么

`epsilon` 读作“艾普西隆”，也可写作 `ε`。在这个项目里，可以理解为：**你为“分母太小了”设的一条界线。** 单位是 **nm**，针对的是 `abs(B)`，即 SiN 刻蚀量的绝对值。

例如 A 都是 10 nm：B 为 1 nm 时比值是 10，B 为 0.1 nm 时比值变成 100。分母非常小时，一点点测量波动就可能让比值变化很大。

epsilon 不是概率、不是百分比，也不是自动读取的仪器精度。使用它的策略要求填一个**大于零的有限数值**。应根据测量分辨能力、重复测量表现和项目对“小到无法可靠区分”的定义来确定；软件不会替你计算这个数。以下 `epsilon = 1 nm` 仅用于算术演示。

### 4.2 “比值目标”四个选项

| 界面选项 | 白话意思 | epsilon 怎么用 |
| --- | --- | --- |
| 需要设置分母策略 | 还没决定怎么处理接近零的分母。内置项目初始是这个状态。 | 此时含比值目标的下一批推荐会被阻止；仍可录入数据，有足够数据时可做预测分析。 |
| 有效区域内原始比值 | 只把 `abs(B) ≥ epsilon` 的结果视为满足分母条件，在那里优化原始比值。 | epsilon 是有效区域的边界。模型通过结果样本评估可行性，不是保证下一次实测一定越过这条边界。 |
| 稳定化比值（不同于原始比值） | 分母太小时，按 epsilon 来算，避免因为分母接近零而把目标无限放大。 | 优化 `abs(A) / max(abs(B), epsilon)`。不会把小分母区域直接排除。 |
| 移除比值目标 | 选下一批时不再把比值作为追求的目标。内置模板仍追求 A 绝对值大、B 绝对值小。 | 不需要填；保存时 epsilon 设为空。原始比值记录／预测仍可能显示。 |

**选完后要点击“保存目标策略版本”。** 只改下拉框或输入框不会更新项目的计算配置。保存会产生新模板版本并重算记录中的派生指标；旧批次预测仍保留当时的结果，不会跟着重写。

### 4.3 用同一组数字比较

假设 A = 10 nm、epsilon = 1 nm：

| B | 原始比值 `abs(A/B)` | 有效区域策略对这个结果的判断 | 稳定化比值 |
| --- | --- | --- | --- |
| 2 nm | 5 | 满足分母条件 | 5 |
| 1 nm | 10 | 满足分母条件，位于边界 | 10 |
| 0.1 nm | 100 | 不满足分母条件 | 10 |
| 0 nm | 无定义 | 不满足分母条件 | 10 |
| −0.1 nm | 100 | 不满足分母条件 | 10 |

这张表只讨论给定 A、B 的算术值。预测时 A、B 有不确定性，因此软件会用很多组可能结果来估计比值分布和可行概率。

有效区域策略中，优化内部还会对区域外的分母做数值保护，并把分母条件用于推荐评分。页面展示的原始比值分位数仍是**未按有效区域筛选**的统计，因此不能仅凭比值很大就认为这组条件可行，要一起看 `feasibility_probability`。

如何按自己的意图理解选择：

- 只想先比较两种刻蚀量：选“移除比值目标”。
- 接受把比值重新定义成一个更平稳的评分：选“稳定化比值”，并确定 epsilon。
- 必须使用原始比值、且只认可分母足够大的区域：选“有效区域内原始比值”。

如果你的目的正是让 SiN 刻蚀量接近零，要意识到“有效区域”又要求它的绝对值至少达到 epsilon，这两点会形成权衡。epsilon 越大，有效区域越窄；在稳定化策略中，epsilon 越大，越多的小分母会被按同一个下限计算。

## 5. 下一批实验的所有设置

| 界面项目 | 白话解释 | 填法或实际行为 |
| --- | --- | --- |
| 比值目标 | 选如何处理比值及小分母。 | 见第 4 节，选择后保存。 |
| epsilon (nm) | 小分母的界线。 | 有效区域／稳定化时必须为正数。 |
| 保存目标策略版本 | 把比值策略正式写入当前项目。 | 同时增加模板版本和数据版本。 |
| 数值模型 | 用哪一种方法学习历史数据。 | 三种选择见下表；“预测 / 趋势图”也使用这里选的模型。 |
| 本轮新增总数 n | 本轮最多安排多少条新实验记录。 | 1–100，界面默认 6。复测、交叉布局基准组都算在里面。 |
| 变化模式 | 每条新条件允许如何偏离基准。 | 见第 6、7 节。 |
| 基准实验 | 变化前的参考配方。 | 程序取选中记录的 `actual` 条件，不取旧的建议条件。新待做记录的 `actual` 初始与建议相同。 |
| 允许变化的字段 | 指定哪些条件允许动。 | 英文逗号分隔，如 `cl2_sccm,rf_w`；其他条件固定在基准值。填写后必须选基准。 |
| 复测实验编号 | 明确安排哪些旧条件再做一次。 | 如 `3,8`；只能选“完成”或“部分结果”的记录，不是批次编号。 |
| 双变量模式恰好改变两项 | 把“双变量”的限制从一项或两项变为必须两项。 | 只在双变量变化模式生效。 |
| 交叉布局的两个新值 (JSON) | 指定两个变量各自的新水平。 | 只在交叉布局模式使用，见第 7 节。 |
| 交叉布局包含基准复测 | 交叉布局是否把原配方也再做一次。 | 默认勾选：4 组；不勾选：3 组。其他模式不使用这个开关。 |
| 计算并保存下一批实验 | 计算建议并自动保存为待做记录。 | 数据在计算期间被修改时，旧版本的结果不能提交。 |
| 取消计算 | 停止尚未完成的计算。 | 不删除已经保存的实验。 |
| 批次说明与预测 | 显示最近一次已保存批次的详细结果。 | 是只读输出，不是输入框。 |

**n 不是模型训练次数，也不是每个变量各做 n 次。** 例如 n = 6，复测编号填 `3,8`，这两次复测先占 2 个名额，通常还可推荐 4 条新条件。合法候选不足时，返回数可以小于 n，软件会给出原因。

手动指定的复测按旧实验完整条件安排，不受“单变量／恰好双变量”的新条件变化数量限制。即使只复测，也需要满足当前推荐入口的目标策略与模型能力检查。

### 三个数值模型

| 选项 | 白话理解 | 当前实现的特点 |
| --- | --- | --- |
| 默认 GP / RBF | 依据附近的历史条件推测结果，倾向于得到很平滑的变化关系。 | 可以拟合非线性；RBF 是模型使用的一种相似度规则。 |
| GP / Matérn 2.5 | 同样依据条件之间的相似性预测，允许关系比 RBF 的假设更不平滑。 | `2.5` 是核函数的平滑度参数，不是软件版本或“准确率倍数”。 |
| 贝叶斯线性回归（非 GP） | 把结果看成各条件影响的相加，并估计这些影响有多不确定。 | 当前是截距加各输入的一次项，没有自动加入两个数值变量的乘积项或平方项。 |

GP 是“高斯过程”的简称。三个模型都给出带不确定性的估计；切换模型不会改变已经测到的数据，也不会重写旧批次。下一次推荐或分析时才按新选择拟合。

每个基础响应至少有 2 条有效数据，程序才进入模型驱动推荐。少于这个数量时，只给初始化条件，`prediction` 为 `null`；直接分析则提示数据不足。**两条只是代码允许计算的最低门槛，不代表已经能可靠预测八个输入的影响。**

## 6. 变化模式和双变量模式

这里的“单变量／双变量”说的是**输入条件改变了几项**，与同时预测多少个结果无关，也与批次里有几条实验无关。

先假设基准条件中 Cl2 = 20、RF = 30，其他六项条件固定。

| 变化模式 | 每条新建议是什么样 | 是否需要基准 |
| --- | --- | --- |
| 全范围探索 | 在模板允许的范围内找条件，没有“只能改变一两项”的数量限制。 | 不限制字段时可以不选。若填写允许变化字段，就必须选。 |
| 相对基准恰好改变一项 | 每条新建议只改变一个条件，其余不动。 | 必须选。 |
| 相对基准最多改变两项，未勾“恰好” | 每条新建议改变一项或两项。当前实现不会把零项变化当成新建议。 | 必须选。 |
| 双变量模式且勾选“恰好改变两项” | 每条新建议必须有两个条件都不同于基准。 | 必须选，且应有至少两项可实际变化。 |
| 基准 / 单 A / 单 B / AB 交叉布局 | 按你给定的两个新值，排出固定的 3／4 组组合。 | 必须选。 |

如果“允许变化的字段”填 `cl2_sccm,rf_w`：

| 新条件（其他六项不变） | 单变量 | 双变量，最多两项 | 双变量，恰好两项 |
| --- | --- | --- | --- |
| Cl2=25，RF=30 | 允许，改了 Cl2 | 允许 | 不允许 |
| Cl2=20，RF=35 | 允许，改了 RF | 允许 | 不允许 |
| Cl2=25，RF=35 | 不允许 | 允许 | 允许 |
| Cl2=20，RF=30 | 不作为新条件 | 不作为新条件 | 不作为新条件 |

**每条实验都和同一个基准比较，不是和上一条推荐比较。** 所以单变量模式的一整个批次里，有的行改 Cl2、有的行改 RF，是正常行为。如果整批都只想改 Cl2，就只填 `cl2_sccm`。

“允许变化”不等于“必须变化”。例如最多两项模式允许 Cl2 和 RF 两项，但程序可以给一条只改 Cl2 的条件。勾“恰好两项”才要求两项都变。

留空“允许变化的字段”表示程序可从所有可控条件中选择，不代表全部固定。在双变量模式留空时，各行可能改变不同的两项。

“全范围探索”选择了基准，也不会自动变成基准附近的小步搜索；即使单／双变量模式，改变的那几项也可跨越模板允许的整个范围。当前没有“最多增加 5”“只在基准上下 10% 内搜索”的专用输入框。

变化数量根据执行值判断：有执行网格时按网格值比较；没有网格的数值，代码忽略相对于范围非常微小的浮点差别。这不是另外一个需要填写的 epsilon。

## 7. 交叉布局怎么用

交叉布局用于比较：只改第一个条件、只改第二个条件、同时改两个条件，结果分别如何。**这一节的“单 A / 单 B”指第一个／第二个输入变量，与前面简称 A、B 的两种刻蚀量不是同一件事。**

假设选中基准实验：Cl2 = 20、RF = 30，其余六项条件不变。

“交叉布局的两个新值 (JSON)”填写：

```json
{"cl2_sccm": 25, "rf_w": 35}
```

这里的 25 和 35 是**新值**，不是“增加 25”“增加 35”。需要英文双引号、冒号和逗号，且恰好两项。

| 组别 | Cl2 | RF | 改了什么 |
| --- | --- | --- | --- |
| 基准复测，可选 | 20 | 30 | 什么都不改，再做原配方。 |
| 单 A | 25 | 30 | 只改第一个变量。 |
| 单 B | 20 | 35 | 只改第二个变量。 |
| AB | 25 | 35 | 两个一起改。 |

每个新值都必须不同于对应基准值，并满足范围、执行精度和输入约束。这些值是你指定的，模型不负责自动挑选；数据充足时会为这些组合给出预测。

- 勾选基准复测：需要 4 个名额，n 至少为 4。
- 不勾选：需要 3 个名额，n 至少为 3。
- 如果另外指定 2 条复测，勾选基准时 n 至少为 6。
- n 填 10 不会自动填满 10 条：当前只返回完整交叉组和额外指定的复测，其余名额空着，并说明原因。

交叉布局直接根据这两个新值组装条件；“双变量恰好”不影响它，“允许变化的字段”也不负责选择它的两项。使用交叉布局时把“允许变化的字段”留空，直接用 JSON 指定，最容易核对。

交叉组如果与已有“待做／进行中”条件相同，会报错要求先完成或取消原计划。已有完成、失败或取消的同条件记录不会被这项检查阻止。另行填写的复测编号会单独计数，不会自动与交叉基准组合并去重。

## 8. 录入回填状态和测量误差

### 8.1 录入和回填有什么区别

“录入实验”是新增一条记录。“更正选中实验 / 回填”是修改已有记录，包括把软件给出的待做实验补上实际结果。

条件要填**实际执行的值**。例如原建议 RF = 30，但实验实际用了 32，回填时应改为 32；模型以后使用实际值，原建议仍另外保留。

| 输入框 | 意思 |
| --- | --- |
| 每个实验条件后的“参数备注” | 记录该条件的说明，例如实际执行偏差。备注文字不参与数值建模。 |
| 每项原始测量的数值 | 实测厚度；留空为未测，`0` 表示确实测得零。 |
| ± 值 | 这项测量的不确定程度，和该测量使用相同单位；不需要输入 ± 符号。 |
| ± 值右侧的含义选项 | 告诉程序这个数字代表什么，见下一表。 |
| 测量备注 | 记录这一项测量的情况，不参与数值建模。 |
| 实验状态 | 这条实验做到哪一步，以及结果是否参加训练。 |
| 整组备注 | 描述整次实验，例如样品、日期或异常情况。 |

### 8.2 “± 值”的几个选项

| 选项 | 白话意思 | 软件怎么用 |
| --- | --- | --- |
| 含义未指定 | 还不知道误差该怎么解释。 | 即使填了 ± 数字，也不会自动把它当标准差或零误差。 |
| 标准不确定度 1σ | 这个数字本身就是一个标准不确定度。 | 当作标准误差尺度使用，已知噪声建模时使用其平方作为方差。 |
| 均值标准误 SEM | 测量值是多次测量的平均值，这个数字描述平均值有多不确定。 | 直接使用你给出的 SEM；程序没有次数输入框，不会替你从标准差除以次数的平方根。 |
| 确定误差界限 | 你给的是上下误差边界，例如 100 ± 2 表示 98–102。 | 默认保留为界限，不会自动把 2 当作标准差；导入／接口明确给出均匀分布时才可转换。 |
| 保留已保存的区间/非对称设置 | 这条记录已有更复杂的误差信息。 | 编辑时保留原有设置；不是普通新记录默认提供的选项。 |

例子：初始厚度 100 ± 1 nm、剩余厚度 90 ± 1 nm，两项都填写为标准不确定度，且误差相互独立，那么刻蚀量为 10 nm，标准不确定度约为 `sqrt(1² + 1²) = 1.414 nm`。不能直接断言差值的标准不确定度还是 1 nm。

留空误差表示未知。对**同一个基础响应**，当前模型不能混合处理“有些记录误差已知、有些记录误差未知”；会明确报错。应核实和统一真实的测量口径，不能为了运行而把未知项填成零。

### 8.3 实验状态

| 中文状态 | 内部值 | 会不会拿来训练模型 |
| --- | --- | --- |
| 待做 | `pending` | 不会；推荐成功后自动生成这个状态。 |
| 进行中 | `running` | 不会；仍作为尚未完成的计划考虑。 |
| 完成 | `completed` | 使用其中有效且非空的响应数据。 |
| 部分结果 | `partial` | 哪个响应有有效结果，就可为哪个响应提供数据。 |
| 失败 | `failed` | 不会，已有填写的数据也不因此作为训练结果使用。 |
| 取消 | `cancelled` | 不会；记录和旧预测仍保留。 |

录入／更正对话框的可选状态中没有“待做”。打开一条待做记录时，状态下拉框当前会落到“完成”，因此保存之前要主动核对：如果尚未做完，改为“进行中”；不做则改为“取消”。

模型判断数据有效还会检查数值是否存在、派生计算是否有效；仅把状态改成“完成”不会凭空产生测量结果。

## 9. 预测和趋势图怎么看

### 9.1 这个页面的所有输入

| 项目 | 白话解释 |
| --- | --- |
| 从选中实验复制条件 | 先在“实验记录”选中一行，再点此按钮，把实际条件复制到 JSON 输入框。修改这里不会修改那条实验记录。 |
| 完整输入条件 JSON | 写你想预测的完整一组条件，内置模板需要八项齐全。只填一个功率值不够。 |
| 趋势图变量（1 或 2 项） | 留空只预测；填 `cl2_sccm` 画一维图；填 `cl2_sccm,rf_w` 画二维图。其他条件固定为 JSON 中的值。 |
| 趋势图响应/指标 | 决定画什么结果。默认 `sio2_loss_nm`；也可填 `sin_loss_nm`、`selectivity_abs`，稳定化策略下可填 `selectivity_stable`。 |
| 按“下一批实验”所选模型预测 / 绘图 | 重新拟合并分析，不会新增实验记录。画图时会先询问 PNG 的保存位置。 |
| 取消分析 | 停止尚未完成的分析，不撤销已保存的实验或已经生成的文件。 |

这是一组完整条件的格式示例，数值仅用于演示：

```json
{
  "cl2_sccm": 20,
  "bcl3_sccm": 10,
  "ar_sccm": 10,
  "icp_w": 300,
  "rf_w": 30,
  "pressure_mt": 5,
  "electrode_temp_c": 20,
  "etch_time_s": 60
}
```

这里输入的是八个条件组成的对象；命令行预测请求则把对象放在 `conditions` 列表中，格式见 [examples/prediction.json](examples/prediction.json)。

趋势图变量为空时，“趋势图响应/指标”不负责筛选文本结果，分析仍会返回能计算的各项预测。不要把 `sio2_remaining_nm` 当作可直接预测的响应；当前内置模型预测刻蚀量，尚未实现包含初始厚度条件及相应误差传播的剩余厚度预测。

### 9.2 预测结果里的字段

| 输出字段 | 白话意思 |
| --- | --- |
| `sio2_loss_nm` / `sin_loss_nm` | 两种材料刻蚀量的预测统计；基础响应保留正负号。 |
| `selectivity_abs` / `raw_selectivity_abs` | 原始比值的统计；内置模板下指向同一个原始比值口径。 |
| `selectivity_stable` | 稳定化后的比值统计，仅稳定化策略下另行提供。 |
| `mean` | 模型抽取的结果样本的平均值。原始比值的这个字段特意留为 `null`，不是漏算。 |
| `quantiles` | 三个数依次是 2.5%、50%、97.5% 分位数；中间是中位数，两端形成中央 95% 区间。 |
| `interval_kind: latent_response` | 区间描述模型对潜在结果的估计，不自动包含下一次仪器量测的额外误差。 |
| `source: joint_posterior_samples` | 根据模型抽取一批可能结果，再用同一批样本计算绝对值和比值。 |
| `moment_notice` / `notice` | 对这项统计口径的说明，例如原始比值不报告均值。 |
| `feasibility_probability` | 抽样中满足已配置输出条件的比例，包括有效区域策略的分母条件。不是“预测准确率”。 |
| `objective_predictions` | 按目标口径算出的预测，例如 `abs(A)`、离零的距离；与带符号的 A、B 本身有区别。 |
| `samples` | 用来估计这些统计量的模型抽样数量，当前默认 512；不是实际做过 512 次实验。 |
| `seed` | 随机种子，用于尽可能复现同样的抽样过程；不是工艺参数。 |
| `revision` / `template_version` | 这份分析使用的数据版本和模板版本。 |
| `notices` | 模型对噪声、响应独立性等假设的说明。 |

例如 `quantiles: [8, 10, 13]`，可以读作：“模型估计中位数是 10，中央 95% 的模型样本落在 8–13。”这不等于“下一次实测保证在 8–13”，也不等于“准确率 95%”。区间只反映当前模型及其假设。

原始比值可能受接近零的分母影响，普通平均数／方差未必有良好定义，所以项目只报告有限抽样得到的分位数，不声称它有有限均值。不要把 `mean: null` 当成零。稳定化策略下，`objective_predictions` 中比值目标的统计按稳定化口径计算，即使目标定义里的名字仍叫 `selectivity_abs`；要一起看 `ratio_policy`。

没有设置输出约束、也没有启用有效区域分母约束时，`feasibility_probability` 可以是 1；这仅表示没有这些条件要违反，不表示结果一定好。

### 9.3 图上的线和颜色

一维图：横轴是选定输入，实线是预测中位数，阴影是潜在响应的中央 95% 区间，竖虚线标出输入 JSON 中的基准值。

二维图：横、纵轴是两个输入，点的颜色表示预测中位数，红色叉号是基准位置。当前二维图没有同时展示每个点的区间宽度。

图是在模板范围内取点、固定其他条件后计算的“切片”，并非已经实测的曲线。桌面版每个轴默认取 15 个位置；执行取整、固定值和约束会导致重复位置合并或非法点被跳过。图变量与“下一批实验”的允许变化字段相互独立。

### 9.4 批次说明里另外出现的字段

| 字段 | 意思 |
| --- | --- |
| `stage: initialization` | 有效基础响应数据不足；给初始探索条件，不给虚构预测。 |
| `stage: model_driven` | 已拟合模型，按模型安排这批实验。 |
| `request` | 本次用到的 n、变化模式、基准、模型等设置。 |
| `candidates` / `conditions` | 建议的实验列表，以及每条的完整条件。 |
| `prediction` | 这条建议当时附带的预测；初始化时为空。 |
| `arrangement` | 安排类型：`new` 新建议、`initialization` 初始化、`repeat` 复测、`cross` 交叉组。 |

## 10. 模板公式和先验里的参数

日常录入不需要修改这一页。它相当于整个项目的“规则表”：定义能输入什么、怎么算结果、要追求什么。

“编辑项目模板”打开 JSON 编辑器；保存时会校验并自动增加 `template_version`。“查看修订历史”显示更正和模板等变更记录，不是自动撤销按钮。

### 10.1 常见字段和精度设置

| 参数 | 白话解释 |
| --- | --- |
| `schema_version` | 模板格式版本，当前要求 2。不是实验编号。 |
| `template_id` / `name` / `definition_source` | 模板标识、显示名称和定义来源。 |
| `template_version` | 这一套规则修改到了第几版。桌面保存自动递增；命令行导入新模板版本时需自行递增。 |
| `parameters` / `measurements` / `derived_metrics` | 分别装可控条件、原始测量、公式指标。 |
| `name` / `label` / `unit` | 内部字段名、给人看的名字、单位；单位 `1` 表示无量纲。 |
| `value_type` | `float` 可带小数；`int` 整数；`category` 规定选项；`bool` 是／否；`text` 文字。文字不能当可控数值条件。 |
| `bounds` | 最小值和最大值，例如 `[0, 100]`。 |
| `values` | 明确列出允许取哪些值，不是在中间任意取。 |
| `fixed_value` | 固定条件，生成建议时不能改成别的值。 |
| `role` / `is_measurement` / `is_auxiliary_record` | 描述字段是条件、测量还是辅助记录；这些标签不等于开启模型输入。 |
| `measured_at` | `before` 实验前可知道；`after` 实验后才知道；`unknown` 时点不明。事后测量不能冒充未来已知输入。 |
| `use_as_model_input` | 是否让模型使用这个输入。当前引擎只支持可控条件作为输入，额外实验前测量／派生输入尚未接入。 |
| `is_response` / `model_base` | 是否作为结果；`model_base: true` 表示直接建模，`false` 表示由基础响应推导。 |
| `expression` | 计算公式，如 `sio2_initial_nm - sio2_remaining_nm`。 |
| `propagate_uncertainty` / `uncertainty_enabled` | 模板描述的误差处理标记；当前记录处理统一尝试传播误差，并非把标记改成 false 就能保证关闭所有处理。 |
| `undefined_policy` | 指标未定义时的处理标记；内置原始比值指向 `ratio_policy`。 |
| `note` | 配置说明文字。 |
| `display_digits` | 只控制显示保留几位小数；空值表示不强制。不会改变原始记录精度。 |
| `execution_rounding` | 约束推荐／预测条件允许落在哪些数值上，见下面的模式。实际回填记录允许保留执行偏差。 |
| `modeling_rounding` | 建模前另做取整的配置；当前未实现，启用会报能力限制。 |

执行精度 `execution_rounding` 的选项：

| 参数或取值 | 意思 |
| --- | --- |
| `mode: "none"` | 不设执行网格；此时 `digits`、`step` 应为空。 |
| `mode: "digits"`，`digits: 1` | 按小数位数设置网格，此例相当于步长 0.1。`digits: 0` 是整数，`digits: -1` 是十位。 |
| `mode: "step"`，`step: 0.5` | 按指定步长取值，例如 0、0.5、1、1.5…… |
| `origin` | 网格起点，默认 0；例如步长 0.5、起点 0.1，则取 0.1、0.6、1.1…… |

同时填写位数和步长时，两者必须一致。需要取整时采用十进制“半数远离零”，例如 1.25 保留一位为 1.3，−1.25 为 −1.3。显示精度和执行精度是不同设置。

在已有项目里修改参数／测量的字段名、类型、单位、范围、离散集合或固定值，会被阻止；当前没有结构迁移功能。需要先导出模板，修改后“从模板新建”。修改公式／目标等允许保存的内容，会重新计算现有记录的派生值，但保留旧批次预测。

### 10.2 目标和约束

| 参数 | 意思 |
| --- | --- |
| `objectives[].metric` | 要优化哪个指标。 |
| `direction: "maximize"` / `"minimize"` | 越大越好／越小越好。 |
| `transform: "identity"` | 直接使用这个指标。 |
| `transform: "abs"` | 使用绝对值。 |
| `transform: "absolute_distance"`，`target` | 使用离目标值的距离；例如 target=0 且 minimize，就是尽量接近零。 |
| `optimization.mode: "pareto"` | 同时比较多个目标，寻找不同折中方案。 |
| `optimization.mode: "single"` | 只优化一个明确保留的目标。与“单变量变化模式”无关。 |
| `optimization.mode: "weighted"` | 先按尺度缩放各目标，再按权重相加。 |
| `weights` / `scales` | 各目标的重要程度／归一化尺度；对应当前实际参与优化的目标，权重非负且不能全为零，尺度必须为正。移除比值后要同步核对数量。 |
| `reference_point` | 手动给 Pareto 内部有向目标空间的参考点；不填写时程序生成并保存在批次中。 |
| `reference_point_policy` | 参考点要可见并记录版本的描述；当前自动生成规则由代码实现。 |
| `input_constraints` | 对输入的线性限制；`coefficients` 是各条件的系数，`op` 为 `<=` 或 `>=`，`rhs` 是右侧阈值。 |
| `outcome_constraints` | 对结果的限制；`metric` 基础响应名、`op` 比较方式、`bound` 阈值。当前不支持任意派生结果约束。 |

输入约束的意思例如“Cl2 + BCl3 + Ar ≤ 某个上限”；这个上限必须由项目明确配置。输出约束的意思例如“SiN 刻蚀量 ≤ 某个阈值”；它通过模型估计是否满足，不能保证实测结果。

### 10.3 先验：把已有经验告诉模型

`knowledge_priors` 默认是空列表。每一项描述某个输入与某个基础响应之间已有的经验。

| 参数 | 意思 |
| --- | --- |
| `enabled` | 这条经验是否启用，省略时按启用处理。 |
| `input` / `response` | 指向哪个可控输入、哪个基础响应。 |
| `relation` | 经验关系的种类，见下表。 |
| `coefficient` | 估计的影响系数：输入每增加一个单位，响应大约改变多少；正负号代表方向。 |
| `strength` | 希望这条经验对模型有多强的影响；大于零。不是百分比置信度。 |
| `source` | 经验来源说明，必须填写。 |
| `strict` | 是否要求严格成立。当前除无关关系外，不支持严格比例或全范围形状保证。 |
| `range` | 经验适用的局部范围；当前局部范围先验未接入，填入非空范围会被阻止。 |

| `relation` 取值 | 白话意思 | 当前限制 |
| --- | --- | --- |
| `independent` | 认为这个输入与这个响应无关。 | 对该响应移除相应输入特征；不是把这个输入在实验中固定。 |
| `linear` | 认为它大致按线性关系影响结果。 | 给线性模型的系数经验，或给 GP 加一个软趋势；不是严格物理定律。 |
| `proportional` | 认为它大致按比例影响结果。 | 也是软先验，不能据此声称模型严格过原点。 |
| `monotonic` | 认为大方向应随输入增加而增加或减少。 | 当前仅线性模型支持，是系数先验，不是严格单调约束。 |
| `weak` | 认为这个输入影响较弱。 | 当前仅线性模型支持；默认系数中心为零。 |

### 10.4 误差高级字段和配置说明

测量不确定度还可通过导入／接口保存这些信息：

| 参数 | 意思 |
| --- | --- |
| `kind` / `amount` | 误差类型／误差大小；常见类型见第 8 节。 |
| `kind: "interval"` | 给定覆盖口径的区间；明确 normal 分布及覆盖因子／置信水平后才转换成标准不确定度。 |
| `kind: "asymmetric"`，`lower`、`upper` | 下侧和上侧误差大小不一样；两者填非负的偏差大小，不是区间端点。 |
| `distribution` | 如何理解误差分布，例如 `uniform` 均匀、`normal` 正态。 |
| `coverage_factor` | 区间半宽是几个标准不确定度；转换时用 amount 除以该因子。 |
| `confidence` | 区间置信水平，例如 0.95；不是填 95。 |
| `source` | 共享误差来源标识。当前跨实验／跨响应共享误差的相关噪声建模未适配，不能随意填成同一来源。 |

内置模板还有一批描述性配置。**不要以为 JSON 中存在一个键，修改它就一定会改变界面或算法。** 当前行为如下：

| 配置 | 意义与当前情况 |
| --- | --- |
| `ratio_policy.mode` / `epsilon_nm` | 比值策略与阈值，实际控制第 4 节所述行为。 |
| `original_metric` / `stable_metric_name` / `keep_original_metric` | 原始／稳定化指标的命名及保留意图；当前内置处理仍保留原始指标，部分代码使用固定 ICP 字段名，不能靠改这些名字任意改造比值系统。 |
| `modeling.base_responses` | 描述基础响应名单；实际模型选择依照字段的 `is_response`、`model_base` 标记。 |
| `derived_response_prediction` | 说明由基础响应的共同样本计算派生预测；当前不是可切换的算法菜单。 |
| `unspecified_cross_output_correlation` | 未配置跨响应相关性时采用独立假设并提示；不代表已经学出了两种刻蚀量的相关性。 |
| `context_assumptions` | 保存场景假设及来源，例如初始厚度不作为模型输入；说明文字本身不会增加模型输入。 |
| `uncertainty_entry` | 描述默认误差语义、是否允许非对称等意图；当前误差对话框和引擎还有各自固定支持范围。 |
| `batch_defaults` | 保存期望的默认批次数、复测数、搜索方式、基准等；当前桌面控件和 `BatchRequest` 使用代码默认值，不会完整读取这一节。 |
| `default_model_preset` / `allowed_model_presets` | 模板对模型选择的描述；当前桌面三个模型选项由代码固定提供。 |
| `field_note_enabled` / `condition_note_enabled` | 备注配置标记；当前界面固定提供参数／测量／整组备注框。 |

高级配置的实际支持边界另见 [功能对照与已知限制](docs/coverage.md)。

### 10.5 仅命令行／Python 接口中的补充参数

| 参数 | 意思 |
| --- | --- |
| `baseline` / `baseline_id` | 直接传完整基准条件／引用已有实验编号；指定编号时程序以那条记录的实际条件为基准。 |
| `variables` / `exact_two` / `repeat_ids` | 允许变化字段列表／双变量是否恰好两项／复测编号列表，对应界面同名功能。 |

| `variables`，用于分析请求时 | 要画图的 1／2 个变量，和推荐请求中的同名参数含义不同。 |
| `metric` / `points` | 画哪个指标／每个图轴的采样点数；分析接口 points 默认 15，允许 2–30。 |

## 11. 保存导入导出和备份

可直接填写的 [CSV 模板](examples/import_templates/实验记录导入模板.csv)、[Excel 模板](examples/import_templates/实验记录导入模板.xlsx) 已提供；逐列填法、误差设置和合成示例见 [导入模板说明](examples/import_templates/README.md)。

| 按钮 | 实际作用 |
| --- | --- |
| 新建项目 | 创建新的 `.sqlite` 文件，使用内置模板；不会覆盖已存在的项目文件。 |
| 打开项目 | 打开已有 `.sqlite` 项目，也可打开一致性备份。 |
| 关闭项目 | 关闭数据库并清空页面显示，不删除项目文件。 |
| 导入 CSV / Excel | 读取历史条件与测量；先校验／预览，再点击保存才写入。 |
| 导出记录 | 导出 CSV、XLSX 或 JSON；显示取整不会改变导出的原始精度。 |
| 一致性备份 | 复制完整数据库内容，包含实验、批次和修订历史；用于迁移／恢复。目标需是新文件。 |
| 模板导出 | 只导出规则配置，不包含实验记录。 |
| 从模板新建 | 用选定模板创建新项目，不会自动带入旧项目数据。 |

导入映射是“你的列名 → 软件内部字段名”，例如：

```json
{"氯气流量": "cl2_sccm", "氧化硅初始厚度": "sio2_initial_nm"}
```

`{}` 表示按模板内部名称和显示名称自动匹配。点击“校验并预览”后，只有没有错误才可保存；修改映射后需要重新预览。单位不同要先明确换算，软件不会把所有导入单位自动互转。

导入时提供 `external_id` 或 `experiment_id` 可用于识别重复导入；同一外部编号但内容冲突会要求使用更正功能，而不是自动覆盖。CSV／Excel 不是无损恢复整个项目的格式，部分复杂误差信息不能完整往返导入。

JSON 导出保存项目当前模板和实验记录的快照，**不包含完整批次表和修改历史**。需要完整迁移时用“一致性备份”，不要把“导出记录”当成完整数据库备份。

记录／模板保存和批次提交后，数据已经写入 `.sqlite`，不需要再按一个全局“保存项目”按钮。修改了预测页面的 JSON 或尚未保存的设置，则不等于修改项目数据库。

## 12. 可以照着做的操作示例

以下只演示如何操作，不代表这些数值是推荐工艺。

### 12.1 只想看一组条件的预测

1. 打开已有实测数据的项目，每个基础响应至少有两条有效数据。
2. 在“下一批实验”选择数值模型。
3. 在“实验记录”选一行，去“预测 / 趋势图”点“从选中实验复制条件”。
4. 根据需要修改条件 JSON，保持八项完整。
5. 趋势图变量留空，点击预测按钮。
6. 看两种刻蚀量、分位数和模型说明。这不会新增待做实验。

### 12.2 下一轮只改 Cl2，其他都不动

1. 在“下一批实验”先选择并保存比值策略。若这轮不追求比值，选“移除比值目标”，无需 epsilon。
2. 选择基准实验。
3. 变化模式选“相对基准恰好改变一项”。
4. “允许变化的字段”填 `cl2_sccm`。
5. n 填 4；复测编号留空。
6. 点击“计算并保存下一批实验”。有足够合法候选时保存 4 条待做记录，每条只有 Cl2 不同于基准。

### 12.3 下一轮每条同时改变 Cl2 和 RF

1. 保存本轮使用的比值策略并选择基准。
2. 变化模式选“相对基准最多改变两项”。
3. 勾选“双变量模式恰好改变两项”。
4. “允许变化的字段”填 `cl2_sccm,rf_w`。
5. 设置 n 后计算。每条新的搜索建议都会同时改变这两项；若另外指定复测，复测仍按旧条件完整安排。

如果不勾“恰好”，则可能有些行只改 Cl2 或只改 RF。若想明确做“基准、只改 Cl2、只改 RF、两个都改”的四组对照，使用第 7 节的交叉布局。

### 12.4 推荐出来但不想做了

选中待做记录 → 更正／回填 → 状态改“取消” → 保存。它会从待做数量里移出，但不会从表格或历史中消失；普通推荐也不会因此自动重新推荐相同条件。

## 13. 常见提示和代码依据

| 提示或现象 | 含义和处理方向 |
| --- | --- |
| 需要设置分母处理方式 | 先选比值策略，按需要填 epsilon，再点“保存目标策略版本”。 |
| 分母策略需要大于零的 epsilon | 有效区域／稳定化策略的阈值未正确填写。 |
| 此模式需要完整基准条件 | 单变量、双变量或交叉布局没有选基准。 |
| 指定变化变量时需要基准 | 填了允许变化字段，但没有指定其余条件固定在哪里。 |
| 变化变量名称无效 | 检查是不是内部字段名、是否重复；用英文逗号分隔。 |
| 总配额不足以容纳完整交叉布局 | n 减去额外复测数之后，不足以安排完整的 3／4 组。 |
| 交叉布局的新值不能与基准相同 | 两项都要真正换到新水平。 |
| 复测只能选择已有有效实验 | 复测编号必须存在，且状态为完成／部分结果；这项检查本身不保证所有测量齐全。 |
| 有效数据不足两条 | 至少一个基础响应的有效记录数不足；补录真实测量，或先生成初始化条件。 |
| 混合已知/未知观测噪声尚未适配 | 同一响应的测量误差口径不齐；不能用假零误差绕过。 |
| 结果少于 n | 看 `shortfall`；可能是候选池、约束或历史去重限制，也可能是交叉布局剩余名额不补齐。 |
| 输入条件字段不完整或含未知字段 | 预测 JSON 缺条件，或用了错误字段名／额外字段。 |
| 项目已修改，请基于最新数据重新计算 | 计算或导入预览期间项目发生变化，需要重新计算／预览。 |
| 把目标改了，旧预测怎么没变 | 旧预测作为历史保存；想看新目标／新数据下的估计，需要重新分析。 |
| 取消之后记录还在 | 当前取消是状态修改，不是删除。 |
| `Arm already exists with name experiment_...` | 旧版把同条件的不同实验错误地命名为不同配方，复测或重复条件会触发。2026-09-21 已修复；更新 Python 版源码并重启，打开原项目重新计算即可，不必删除记录或人为改动真实条件。 |
